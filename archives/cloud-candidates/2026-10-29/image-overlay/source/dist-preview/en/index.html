How do I read the difference?

Each image is composited onto white first. Difference mode takes the absolute difference of each RGB channel. Black means equal colors on white; brighter channels mean larger differences. Overlay uses these same white-backed images.

A visual proofing aid, not an authenticity test. Hidden transparent colors, transparency differences invisible on white, original file bytes and metadata are not compared. Browser decoding and color conversion can affect results; print color accuracy is not guaranteed.

Cancel prevents stale results from appearing, but native image decoding may not stop immediately. New work waits for the previous decoder rather than overlapping. Reload the page if the browser remains unresponsive.
