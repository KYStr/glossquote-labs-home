# Eight existing cloud candidate sources — preservation only

This archive preserves the eight approved existing candidate source sets and technical evidence for source preservation only. It does not deploy a website, merge a product, transfer responsibility, grant a new software license, or declare acceptance.

## Scope

- Products: image contact sheet, audio cue notes, image overlay, flashcards, tournament scheduler, project backplan, contact cards, and agenda conflicts.
- Six product folders preserve the previously prepared source/preview/technical-verification package bytes. Two preserve existing candidate files under source/. Missing product specifications are supplemented from original product documents, with exact original hashes and excerpt boundaries.
- Historical receipts retain their original date and scope. Their descriptions such as PRIVATE_PACKAGE_NOT_PUBLISHED describe the earlier packaging event; this GitHub archive is now publicly readable source preservation, not runtime deployment. Historical pass counts are not a new test run or quality score.
- Runtime code, package files, tests, and build scripts are unchanged. One image-overlay README line was replaced with "Independent review: pending." to exclude an internal reviewer identifier. FILE-MANIFEST.json records the before/after identity.
- Private conversations, task/actor/ownership metadata, private boards, credentials, raw internal reviewer receipts, and binary/audio/screenshot evidence are not included. Existing cleaned technical summaries retain original receipt hashes without disclosing private receipt contents.
- No product tests, browser/native workflows, deployment, or scoring were performed during preservation. Existing NOT_RUN limitations remain historical evidence, not newly added acceptance requirements.

## Reading

Each product retains a separate source root; do not combine products in one runtime web root. Preview/dist/test-product files are preserved static artifacts only and are not hosted by this operation.

FILE-MANIFEST.json records every archived source/evidence file's byte count, SHA-256, and Git blob SHA-1. Cross-environment comparison and responsibility mappings are not included in this public archive. No integration or compatibility result is asserted.

The archive excludes new actor confirmations, ownership assertions, claims, and reconciliation state. Those are separate processes and are not implied by source preservation.
