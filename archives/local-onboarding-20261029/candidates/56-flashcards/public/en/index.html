How it works

Are answers graded automatically?

No. Reveal the answer and assess your own recall.

Can I save progress?

Export JSON to save the deck and known-card IDs, then import it later. This page does not save automatically. Clearing it does not delete downloaded files or guarantee secure memory erasure.

Can I print cards?

Download the numbered question sheets and answer key as HTML, then print it yourself. Duplex alignment is not guaranteed.

What CSV format is supported?

Use UTF-8 (an initial BOM is allowed), commas, double quotes and LF or CRLF record separators, with up to 30 columns. Columns are identified by number even when headers match. Control characters other than Tab, CR and LF, and malformed Unicode, are refused.
