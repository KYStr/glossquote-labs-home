使用說明

為什麼不用我輸入開始日？

工具先求出 DAG 最長工期，再由截止日倒數，以該日作為所有根任務的最早起點。

週末或假日截止會怎麼處理？

截止日向前退到上一個你設定的工作日，並在結果中同時顯示原日期和調整後日期。

關鍵路徑代表一定會延遲嗎？

不代表。它只標示本模型中 slack 為 0 的工作；不估算人力、風險、任務中斷或其他資源限制。
