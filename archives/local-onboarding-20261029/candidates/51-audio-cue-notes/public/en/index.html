    How it works

    Is my recording uploaded?

    No. The candidate selects and plays a local file in the browser.

    Can it play every audio file?

    No guarantee. Playback depends on the current browser’s supported formats; this tool does not convert audio.

    Does it transcribe speech?

    No. You enter every note yourself.

    Does an export include audio?

    No. JSON contains only a source title, duration metadata, and notes.

    Are exports size-limited?

    Markdown and JSON are each capped at 4 MiB; an oversized export creates no partial download.

    Does switching language keep my work?

    No. Export first or the current workspace will be lost.
