    使用說明

    會把錄音上傳嗎？

    不會，候選只從本機選取檔案並用瀏覽器播放。

    所有音訊都能播放嗎？

    不一定；能否解碼取決於目前瀏覽器支援的格式，本工具不轉檔。

    筆記會自動轉錄嗎？

    不會，所有文字都由你輸入。

    匯出檔會包含音訊嗎？

    不會，JSON 僅含來源標題、長度 metadata 與筆記。

    匯出有大小限制嗎？

    Markdown 和 JSON 各最多 4 MiB；超出時不會建立部分下載檔。

    語言切換會保留目前工作嗎？

    不會；先匯出，否則切換後工作區會遺失。
