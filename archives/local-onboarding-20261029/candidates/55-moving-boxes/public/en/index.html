        How to use

        Are boxes saved automatically?

        No. Download the project JSON to restore it later. There is no account, cloud sync or automatic saving.

        What if search finds nothing?

        The inventory is retained and the empty result is clearly shown. Search also checks box IDs, rooms and notes.

        Can I move an item to another box?

        Yes. A move preserves its ID and does not duplicate it. Items with the same name can still be recorded separately.

        Do I need a label printer or network service?

        No. Exports are text lists and project JSON, without addresses, weight pricing or printer integration. This tool needs native JavaScript modules, Blob downloads and FileReader. Unsupported browsers stop safely.
