# 品牌規格：文字分段與字數限制

狀態：SPEC_ONLY。尚無視覺實作或使用者測試。

繁中名稱「文字分段與字數限制」，英文 “Text Chunker with a Code Point Limit”。此工具明確讓使用者自己決定上限；不可用可能變動的平台規則做賣點。品牌語氣準確、清楚、尊重原文。

標語草稿：繁中「按你設定的長度分段，原文保持原樣。」英文 “Split to a limit you choose. Keep the source intact.”

不可使用「適合所有平台」「精準計算社群字數」「emoji 算一字」等無證據表達。畫面辨識元素是片段對片段的連續閱讀與可見 code point 數；不使用彩色文字或每段等高卡片取代文字本身。沿用 Gloss Tools shared design system。
