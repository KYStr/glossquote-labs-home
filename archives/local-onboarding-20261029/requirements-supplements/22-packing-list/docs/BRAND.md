# 品牌規格：行李清單與重量試算

狀態：SPEC_ONLY。尚無實作、品牌視覺或使用者測試證據。

產品名稱繁中「行李清單與重量試算」，英文 “Packing List & Weight Planner”。系列署名 Gloss Tools by GlossQuote。用語聚焦整理與估算，不使用「智慧打包」「不會超重」「航空合規」等無證據承諾。

產品標語草案：
- 繁中：把要帶的東西列清楚，重量未知就先留白。
- English: Keep your packing list clear, and leave unknown weights unknown.

語氣直接、冷靜、讓使用者保留決定權。包裝重量由使用者輸入，工具只加總；可見數字是清單估算，不是秤重器或航空規定。每次顯示重量限制時同時指出「此上限由你設定」。

使用 Gloss Tools 共通精確工作表設計契約；產品自身的辨識元素是可讀清單列與「已知 / 未知」重量狀態，不把全頁做成同質卡片。酸綠只表示已選/完成，不可表示航空安全。
