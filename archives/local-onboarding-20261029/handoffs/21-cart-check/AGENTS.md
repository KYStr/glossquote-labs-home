# 折扣與免運試算專案規則

產品僅 SPEC_ONLY。遵循根 AGENTS.md、全域 Windows 防護、Gloss Tools 家族規格。要求模型不得寫成已確認模型。

## 允許所有權

- 只可依 TASKS.md 修改本產品明列的 M1 內容。
- 專用證據只寫到孵化器根 .runs/cart-check/，不得保存用戶購物資料或付款個資。
- M2 staging 僅 .runs/github-publish/glossquote-labs-cart-check/，且先由主代理明確放行。
- 不碰根 git、首頁、兄弟目錄、部署/DNS、付費服務或憑證。不得讀瀏覽器保存資料。
- 使用 Node.js 24 ESM 和內建模組；禁止不經授權新增依賴。

## 不變的計算和產品界線

- 價格只接受 ASCII 十進位字串，轉整數 cents，禁止 Number 浮點金額運算。
- 金額順序為行小計加總、全籃百分比折扣按 half-up 四捨五入至 cents、固定券再扣且商品淨額不低於零、最後決定運費。運費不打折。
- 免運門檻可選折前 subtotal 或百分比+固定券後商品淨額；預設折後。空門檻代表沒有免運方案，不是 0。
- 加購為一件/一組自填價格，加入原籃後折扣與運費全部重算；必須顯示原實付、加入後實付、加購成本與包含加購成本的淨差。
- 不含稅、匯率、店家/平台規則、運費折扣、會員券、API 或商家整合。
- 修改任何欄位立即清空結果並停用 copy；不儲存、不上傳、不分析。

## 停止條件

公式、折扣套用順序、threshold basis、最大值出現未定義衝突時停止向主代理回報。需要新增稅率、匯率、店家查詢、上傳、storage、網路、秘密或付費服務也停止。不得自行推測特定商家的規則。
