# 行事曆檔產生器
這是規格，尚未實作。

收到聊天中的活動時間，不想在不同日曆重打一次：填入單次活動，先確認當地時間、時區與結束時間，再下載可匯入的 `.ics` 檔。支援定時或全天活動，輸出可帶走，不需帳號。

這與活動流程時間表不同：不排多段流程，專注於帶完整日期、時區的單一事件。使用情境是個人課程、聚會、預約、跨時區線上活動；不是會議邀請系統。需求是假設的具體工作，尚無使用量或市場研究證據。

中等難度：時區、夏令時間重複/不存在時刻與 UTF-8 ICS 序列化。零套件、原生 Intl/HTML/ESM，Node24 測試。瀏覽器時區資料版本不同須明示不能解析則退出，不能默默改時間。

非目標：自然語言解析、讀取聊天/帳戶、寄邀請、提醒、重複活動、同步、匯入既有 ICS、多人 RSVP。不聲稱已自動加入任何日曆。
