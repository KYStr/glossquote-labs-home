# 行李清單與重量試算

狀態：SPEC_ONLY（2026-10-13）。本資料夾是待實作規格；M1、測試、GitHub、正式主機及外部驗收皆為 NOT_RUN。真實進度只可由後續任務追加至 [HANDOFF.md](HANDOFF.md)。

這個單頁工具讓準備出門的人列出要帶的物品、數量、每件重量與打包狀態，並在知道所有重量時計算總重量及與自訂上限的差距。它面向週末旅行、搬宿舍前整理或出門購物打包；不代替航空公司規定，也不猜測未量出的重量。

主要替代方案是紙本清單、手機備忘錄或試算表。此工具把清單、已打包、重量估算放在同一畫面，且可自願下載 JSON 帶走；它不要求帳號或雲端同步。價值是待驗證假設，尚無搜尋量或使用者研究證據。

MVP 是靜態雙語頁面，資料只在目前分頁記憶體；工具明確提醒重新載入會遺失資料，下載 JSON 是保存方式。難度中等：匯入預覽與嚴格格式驗證比單純清單複雜。無 runtime 套件；Node 24 僅用於開發、測試與產生預覽建置。

非目標：多行李箱/多人協作、航空公司或行李規定資料、價格購物、條碼、登入、雲端、localStorage、背景同步、提醒、估算物品重量、讀取照片、遙測及伺服器端處理。沒有重量的列必須清楚標成未知，不能當成零。
