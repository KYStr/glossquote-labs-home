二進位記錄欄位檢視

貼上測試 fixture 的十六進位 dump 與欄位表，對照同一組 bytes 的兩種 endian 與 signed 讀值。所有計算都在本機進行，不上傳、不儲存。

以空白、Tab 或換行分隔 token；每個 token 為偶數個十六進位字元，不支援 0x 前綴或位址；最多 4,096 bytes。

每列「標籤 ⇥ 偏移 ⇥ 型別」，以 Tab 分隔；最多 64 列。型別：u8、i8、u16le、u16be、i16le、i16be、u32le、u32be、i32le、i32be、u64le、u64be、i64le、i64be。

已載入範例，請按「讀取指定欄位」執行。

型別寬度說明

u64le / u64be8 bytes無號 64 位，小端／大端
i64le / i64be8 bytes有號 64 位，小端／大端

限制

  • 十六進位 bytes 最多 4,096 bytes；欄位配置最多 64 列。
  • 標籤以英文字母開頭，最多 24 字元，不可重複。
  • 偏移從 0 開始；欄位不可超出 bytes 末端。
  • 兩欄可以共用 bytes；讀值不會改寫來源。
  • 下載的報告為固定檔名 binary-record-inspector-report.json。
偏移從哪裡算？
第一個 byte 的偏移是 0。
兩欄可以共用 bytes 嗎？
可以，讀值依每欄指定型別，不會改寫。
