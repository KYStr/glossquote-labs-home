Formulas and how results are judged (this page audits itself)

  • BMI = weight (kg) ÷ height (m)², computed from unrounded values.
  • Categories are judged on the unrounded BMI, not on the displayed one-decimal value: a displayed 18.5 can still be underweight, and a displayed 25.0 can still be normal.
  • WHO bands: underweight < 18.5; normal 18.5–<25; overweight 25–<30; obese class I 30–<35; obese class II 35–<40; obese class III ≥ 40. Band names are range names, not a diagnosis.
  • Healthy weight range = [18.5 × height², 25 × height²); the upper bound is “stay below” that value (it is exclusive).
  • BMR uses the Mifflin-St Jeor equation: men = 10×weight (kg) + 6.25×height (cm) − 5×age + 5; women = 10×weight + 6.25×height − 5×age − 161.
  • TDEE = unrounded BMR × activity multiplier (1.2 / 1.375 / 1.55 / 1.725 / 1.9): an estimate of the daily energy needed to maintain current weight.
  • Unit conversion: 1 inch = 2.54 cm; 1 lb = 0.45359237 kg; internally everything is computed in unrounded metric values.
  • Information only (not a category verdict): Asia-Pacific public-health action points are BMI 23.0 and 27.5; the categories above still use the WHO bands.
