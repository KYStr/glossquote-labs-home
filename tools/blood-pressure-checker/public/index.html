分級方式與固定規則

分級表採 AHA/ACC 2017：正常為收縮壓 < 120 且舒張壓 < 80；偏高為收縮壓 120–129 且舒張壓 < 80；第一期高血壓為收縮壓 130–139 或舒張壓 80–89；第二期高血壓為收縮壓 ≥ 140 或舒張壓 ≥ 90；高血壓危象為收縮壓 > 180 及/或舒張壓 > 120（嚴格大於，180/120 本身為第二期）。收縮壓與舒張壓落在不同級時取較高者；判定順序（危象 → 第二期 → 第一期 → 偏高 → 正常，先中即停）即實現該規則。

常見問題

單次量測就能診斷高血壓嗎？
不能；分級以單次量測對照，高血壓診斷需多次量測與醫師評估。
收縮壓與舒張壓落在不同級時取哪一級？
取較高者。
180/120 算高血壓危象嗎？
不算；危象是收縮壓高於 180 或舒張壓高於 120（嚴格大於），180/120 本身為第二期。
