## What was built

Per the handbook file contract and the run 2–3 house pattern
(mirrored from the accepted-pattern candidate layout):

- `package.json` — Node ≥24, ESM, zero runtime dependencies; scripts
  `test`, `check`, `build:preview`, `check:generated:preview`, `dev`.
- `public/js/core/zodiac.mjs` — the pure core: the SPEC's fixed
  12-sign tropical table, strict schema validation (exactly the
  string fields month/day/year, own data properties only), per-field
  validation in the SPEC's order (INPUT_LIMIT → UNICODE → EMPTY →
  INTEGER_FORMAT → RANGE; field order month → day → year; year skips
  EMPTY), the cross-field DATE_INVALID existence check with the
  Gregorian leap rule, integer `md` lookup with the Capricorn
  year-wrap, the cusp rule with cycle neighbours, and canonical-JSON
  report serialization (sorted keys, one trailing LF, 2 MiB cap).
  No imports, no DOM, no `Date`.
- `public/js/controller.mjs` — draft/work-state machine (empty,
  dirty, busy, success, error, cancelled) with a generation guard:
  late Worker replies can never revive an old result; editing,
  cancelling, resetting, or re-running terminates the old Worker.
- `public/js/app.js` — DOM wiring using textContent/value only;
  bilingual strings; renders symbol + bilingual sign name, the date
  range, element · modality in both languages, and the pinned cusp
  copy with the neighbouring sign; the fixed download
  `zodiac-sign-report.json` is created only on an explicit click and
  its Blob URL is revoked within 30 s or on invalidation.
- `public/js/worker-source.mjs` — GENERATED by `scripts/build.mjs`:
  the core source embedded verbatim plus a fixed onmessage handler;
  the page creates a module Worker from this string via a Blob URL.
- `public/index.html` (zh-Hant) and `public/en/index.html` (en) —
  static bilingual pages with the SPEC's exact lang/title/
  description/H1, the pinned year hint and FAQ wording, same-language
  home links via `../../`, robots noindex, and — per the SPEC's
  candidate rule — NO production canonical, hreflang, or sitemap.
- `public/styles/app.css` — house paper/ink tokens and layout.
- `scripts/build.mjs` — reproducible preview build: regenerates the
  worker source, copies `public/` into `dist-preview/`, adds a
  deny-all robots.txt, writes `BUILD-MANIFEST.json` (path/bytes/
  SHA-256, sorted, no timestamps). Production mode is refused (no
  approved production origin).
- `scripts/check.mjs` — static checks: package contract, syntax of
  all JS, forbidden capabilities in shipped sources, core purity,
  the bilingual HTML contract (including canonical/hreflang ABSENT),
  the SPEC CSP string in serve.mjs, worker-source freshness.
- `scripts/check-generated.mjs` — verifies `dist-preview/` against
  `BUILD-MANIFEST.json` byte-for-byte, no extra files.
- `scripts/serve.mjs` — loopback-only static server (GET/HEAD,
  traversal/symlink escape refused, SPEC security headers).
- `test/` — `fixtures.mjs` vendors the 16 literal cases VERBATIM from
  the fixed spec fixtures.json (the spec PR is not yet merged into
  the base branch, so the cases are copied here with their source
  recorded; expectations were never derived from this tool's code);
  `core.test.mjs` (13 core fixtures deep-equal, an independent
  366-pair coverage audit against a test-local transcription of the
  SPEC table, leap-year 1900/2000/2100, schema/grammar/range edges,
  report bytes + SHA-256), `controller.test.mjs` (the 3 controller
  fixtures with a hand-controlled fake Worker, plus worker-failure
  and edit-during-busy cases), `worker.test.mjs` (the generated
  worker source executed end-to-end via a data: URL), and
  `html.test.mjs` (both pages' metadata/links/FAQ contract).
