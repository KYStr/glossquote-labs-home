UTM 連結產生器

輸入目標網址與 UTM 參數，產生可直接貼用的追蹤連結：編碼與既有查詢合併方式皆已釘版。全部在本機計算，不上傳。

常用範本 / Presets

範本只填來源與媒介、清空關鍵字與內容，活動名稱保持原值不動；填入後須手動執行才產生連結。

請輸入目標網址與 UTM 參數，或載入範例。

本工具只在你的網址後面加上追蹤參數，不檢查目標網址是否存在，也不會上傳或儲存你的網址與參數。

編碼與合併規則、限制
  • 目標網址必填，最多 2048 個字元；每個 UTM 值最多 200 個字元，去空白後最多 100 個字元。長度一律以 UTF-16 code units 計。
  • 來源、媒介、活動必填；關鍵字、內容選填，去空白後為空時不輸出該參數。值不轉小寫、不做 slug 化，大小寫原樣保留再編碼。
  • 每個值以 encodeURIComponent 編碼：空格一律編為 %20，絕不用 +；不編碼的字元僅限 A–Z a–z 0–9 - _ . ! ~ * ' ( )；其餘一律百分比編碼，包括 / → %2F、? → %3F、& → %26、= → %3D、# → %23、+ → %2B；非 ASCII 字元先轉 UTF-8 再編碼，十六進位用大寫；值內的 % 不先解碼，直接編為 %25。
  • 既有查詢字串原樣保留在前，UTM 參數以 & 接在其後，固定順序為 source、medium、campaign、term、content；既有查詢為空時不留空段。既有 fragment 原樣保留在 UTM 參數之後。輸出不補斜線、不做大小寫正規化。
  • 目標網址已含任何 utm_* 參數時直接拒絕，不覆寫。網址須為 http 或 https、有主機、不得含帳號或密碼；本工具不造訪或驗證目標網址。
  • 資料只保留在目前頁面草稿；離開或切換語言即丟棄，不儲存、不上傳。

常見問題

空格會編成 + 嗎？

不會，空格一律編為 %20。

目標網址本來就有查詢參數怎麼辦？

原樣保留在前，UTM 接在後面；若已含 utm_* 參數會直接拒絕，不覆寫。

這會縮短網址或追蹤成效嗎？

不會，只產生連結；不發送請求、不縮短、不記錄。

範本會改掉我填的活動名稱嗎？

不會，範本只填 source 與 medium、清空 term 與 content，campaign 保持原值。
