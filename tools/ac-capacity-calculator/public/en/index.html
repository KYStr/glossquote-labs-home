AC Capacity Calculator

Estimate the cooling capacity a room needs (kcal/h, BTU/h, kW) from its size in ping or square metres plus west sun, top floor, large windows, kitchen heat and occupants, and match it to common model sizes; tonnage is a Taiwan retail rule of thumb. How it is calculated, and the input format

The base load is fixed at 500 kcal/h per ping (a Taiwan residential retail convention). An area entered in m² is first converted with the fixed divisor 1 ping = 3.3058 m², and the converted fraction is not rounded before use. Adjustments add onto the base, they never compound: west-facing sun +10%, top floor +15%, large windows +10%, kitchen / heat source +10%, and +3% for each occupant above 2; 2 occupants or fewer add nothing and never subtract.

Conversions are fixed: BTU/h = kcal/h × 3.968; kW = kcal/h ÷ 860. The model-size table is fixed at 2.2, 2.8, 3.6, 4.5, 5.0, 6.3, 7.1, 8.0, 9.0, 10.0 kW; the recommendation compares the exact unrounded kW and takes the smallest size at or above it, with the next size up alongside. An exact kW above 10.0 yields no recommendation and shows the over-range note instead. The displayed kW is rounded to two decimals and can differ from the exact value used for the comparison.

Tonnage is only a labelled estimate under the Taiwan retail rule of thumb 1 ton ≈ 2,500 kcal/h; the refrigeration ton (1 RT = 3,024 kcal/h) and mixed rules such as “tons ≈ kW × 0.355” are not used. The downloaded report is always named ac-capacity-report.json and holds the result as compact JSON with object keys sorted recursively by UTF-16 code units and one trailing newline. This tool is a pre-purchase estimate, not an installation assessment.

Frequently asked questions

Do I have to buy the recommended size?
It is the smallest common model size at or above the required kW; one size smaller may struggle on the hottest days.
Why not convert with the refrigeration ton?
One refrigeration ton (3,024 kcal/h) is a refrigeration-engineering unit; the air-conditioner “ton” in Taiwan retail is a rule of thumb — here 1 ton ≈ 2,500 kcal/h — so size by kW instead.
