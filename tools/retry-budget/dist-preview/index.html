重試時間預算試算

工程師調整批次任務的 retry timeout 時，先在假設每次都耗完整 timeout 的條件下，確認可在時間預算內完成幾次、何時第一次超界。這是時間模型，不會實際發出重試。

計算方式與格式說明

第一次嘗試沒有間隔，從 0 毫秒開始，結束時間為單次逾時。第 i 次（i ≥ 2）嘗試的間隔是初始間隔乘以倍率的 i−2 次方，再取與間隔上限的較小值；間隔加在前一次結束時間之後。第一次結束時間超過總預算的嘗試不會被保留，該次的等待時間也不扣掉；結束時間恰好等於總預算算容納。未使用時間是總預算減去最後一次被保留嘗試的結束時間；一次都沒有保留時為 0。

所有欄位只接受 ASCII 十進位整數字串，不含空白、符號、小數或指數，每欄最多 8 位數字。下載的報告檔名固定為 retry-budget-report.json，內容是結果的精簡 JSON，鍵按 UTF-16 碼元升序排列，結尾一個換行。
