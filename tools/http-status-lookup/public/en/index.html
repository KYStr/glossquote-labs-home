How classes are decided

The class comes from the first digit: 1xx Informational (Request received, continuing process), 2xx Success (The action was successfully received, understood, and accepted), 3xx Redirection (Further action must be taken in order to complete the request), 4xx Client Error (The request contains bad syntax or cannot be fulfilled), 5xx Server Error (The server failed to fulfill an apparently valid request). Class summaries are quoted from the IANA registry notes.

418 is listed as (Unused) in the current IANA registry and RFC 9110; the old name "I'm a teapot" came from the RFC 2324 April Fools' joke and is not in the current registry. 413 and 422 use the current RFC 9110 names "Content Too Large" and "Unprocessable Content". 104 is a temporary registration that expired 2026-11-13, though the registry entry remains; 510 is OBSOLETED.

Frequently asked questions

What if a code is not assigned?
A code inside 100–599 with no assignment shows the unassigned note; interpret it only by its class.
Does it request a URL?
No. This tool only looks up the built-in status code table and makes no network requests.
Is 418 "I'm a teapot"?
No. The current IANA registry and RFC 9110 list 418 as (Unused); "I'm a teapot" came from the RFC 2324 April Fools' joke.
