分類方式與固定規則

分類由狀態碼第一個數字決定：1xx 資訊（請求已收到，繼續處理）、2xx 成功（請求已成功接收、理解並接受）、3xx 重導向（需要進一步動作才能完成請求）、4xx 客戶端錯誤（請求語法錯誤或無法完成）、5xx 伺服器錯誤（伺服器無法完成看似有效的請求）。分類摘要逐字取自 IANA 登記註記。

418 在現行 IANA 登記與 RFC 9110 列為 (Unused)；舊稱「I'm a teapot」出自 RFC 2324 愚人節玩笑，不在現行登記中。413、422 採用 RFC 9110 現行名稱「Content Too Large」、「Unprocessable Content」。104 為暫時性登記，已於 2026-11-13 到期，但登記列仍在；510 已廢止（OBSOLETED）。
