路由樣式交疊檢查

API 維護者新增一條靜態或參數路由前，想找同一方法下可能同時匹配的既有樣式，拿到實際可複算的 path witness。

切換語言或離開本頁會失去目前草稿。

輸入

每列一條路由：HTTP 方法、一個 Tab、再接路由樣式。例如 GET、一個 Tab、/users/:id。

允許的參數與尾段語法

路由樣式以 / 開頭，最多 8 段，不可有尾斜線。literal 只能用小寫字母、數字、- 與 _（例如 users、new、v2）。參數寫成 :名稱（例如 :id），尾段寫成 *名稱且只能放在最後一段（例如 *rest，會匹配至少一段）。同一樣式內參數與尾段名稱不可重複。方法只接受大寫 GET、HEAD、POST、PUT、PATCH、DELETE、OPTIONS；GET 與 HEAD 不會互相交疊。
