設計間距 Token 對照

設計或前端同事拿到版面標註值，想知道每筆量測最接近哪個設計間距 token，並交付超出可接受偏差的列。所有資料只留在這個頁面，不會上傳或儲存。

切換語言或離開頁面會遺失草稿。

每列「名稱 + Tab + px」，1–64 列。例如：large⇥12

每列「名稱 + Tab + px」，1–100 列。例如：gap⇥10

0–2048 的數字，最多三位小數，預設 1。

輸入格式

每列以一個 Tab 分隔名稱與 px。名稱以英文字母開頭，可含英文字母、數字、底線與連字號，最多 32 個字元；同一份表內不可重名。px 是 0–2048 的無符號十進數，最多三位小數，不可帶單位、空格、逗號或指數。每份表最多 8,192 個字元。

每筆量測會找出絕對差最小的 token；等距時取 px 較小者，數值仍相同時取表內較前列。偏差為量測減去 token：為 0 是「相符」，絕對值在容許偏差內是「容許內」，否則是「超出」。

報告檔名固定為 spacing-token-audit-report.json，內容是結果的 compact JSON，鍵按 UTF-16 排序，末尾一個換行。
