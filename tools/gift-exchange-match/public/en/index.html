Gift Exchange Match

Enter participant short names and blocked directions to find a match where everyone gives one gift and receives one. Recipients start hidden, revealed one card at a time.

Participants

3–16 people. Give each person a short name (1–24 characters, starting with a letter or digit); names must be unique.

Blocked directions

Up to 240 rows. Each row is “giver → does not give to”; fill two rows for a two-way block. Giving to yourself is already excluded, so do not add it.

The sample is fixed placeholder data (A, B, C, no blocks). Press “Match gift exchanges” after loading to compute it.
