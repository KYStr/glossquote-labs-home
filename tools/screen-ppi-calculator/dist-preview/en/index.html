Pixel density and physical size

How it is calculated, and formats

PPI = √(horizontal pixels² + vertical pixels²) / diagonal (inches). The physical width, height and dot pitch are derived from the unrounded PPI: width = horizontal pixels / PPI × 2.54 cm, height likewise; dot pitch = 25.4 / PPI mm. Total pixels = horizontal pixels × vertical pixels / 1,000,000. The aspect ratio is reduced by the greatest common divisor, shown in width:height order, as a reference label only — it never solves for a side.

Displayed values use fixed decimals: PPI 1 place, width and height 1 place, dot pitch 3 places, total pixels 2 places, zero-padded. The report JSON carries the same rounded numbers. The downloaded report is always named screen-ppi-report.json; its content is the result as compact JSON with object keys sorted by UTF-16 code units recursively, ending in one line feed.

FAQ

Why aren't the width and height derived from the displayed PPI?
They are computed from the unrounded PPI; the rounded PPI is for reading only, and deriving from it would make the dimensions disagree with the diagonal.
Can I solve for a missing side from the aspect ratio?
This tool does not solve; the ratio is a reference label only. To solve a missing side from a ratio, use the aspect ratio calculator.
Should the diagonal include the bezel?
Use the viewable diagonal and the panel's native resolution from the spec sheet; a marketed size that includes the bezel, or a non-native resolution, shifts the result.
Are dot pitch and PPI the same thing?
Dot pitch is the distance between adjacent pixel centres in mm, the reciprocal of PPI (25.4 / PPI); a smaller pitch means a finer image.
