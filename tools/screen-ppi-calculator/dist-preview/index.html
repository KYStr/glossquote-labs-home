像素密度與實體尺寸

計算方式與格式說明

PPI = √(水平像素² + 垂直像素²) / 對角線（英寸）。實體寬高與點距由未捨入的 PPI 推導：寬 = 水平像素 / PPI × 2.54 公分，高同理；點距 = 25.4 / PPI 公釐。總像素 = 水平像素 × 垂直像素 / 1,000,000。長寬比以最大公因數約分，依寬:高順序顯示，只作參考標籤，不做求解。

顯示固定小數位：PPI 1 位、寬高 1 位、點距 3 位、總像素 2 位，不足補零。報告 JSON 帶捨入後的數值本身。下載的報告檔名固定為 screen-ppi-report.json，內容是結果的精簡 JSON，物件鍵按 UTF-16 碼元升序遞迴排列，結尾一個換行。

常見問題

寬高為什麼不用畫面上顯示的 PPI 來算？
寬高由未捨入的 PPI 推導，四捨五入後的 PPI 只供閱讀；用顯示值反推會讓寬高與對角線對不起來。
可以由長寬比反推缺少的一邊嗎？
本工具不做求解，長寬比只是參考標籤；要由比例與一邊求另一邊，請用長寬比計算工具。
對角線要用含邊框的數字嗎？
請用規格表上的可視對角線與面板原生解析度；市售標示若含邊框或非原生解析度，結果會跟著偏差。
點距和 PPI 是同一個東西嗎？
點距是相鄰像素中心的距離（mm)，與 PPI 互為倒數關係（25.4 / PPI)；點距越小畫面越細緻。
