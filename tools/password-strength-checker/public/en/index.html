How strength is scored

Base entropy is the password length (in Unicode code points) times log2 of the character-set size, rounded half away from zero to 1 decimal place. The set size sums the pools of the classes present: lowercase 26, uppercase 26, digits 10, symbols 32, other characters (including spaces and non-ASCII) 32. Pattern penalties are then subtracted: common password −30, dictionary word −12 each (at most 2), repeated run −8, sequence −8, keyboard row −8, year −6, repeated segment −10, shorter than 8 characters −10, single character class −8; the penalty total is capped at 40 bits. Final entropy is base entropy minus penalties (never below 0). Bands: below 28 very weak, 28–35.9 weak, 36–59.9 fair, 60–79.9 strong, 80 and above very strong.

Crack time is 2 to the power of final entropy guesses divided by the attack rate: online unthrottled 10 guesses per second, offline fast hash 10¹⁰ guesses per second (the two public attack rates from zxcvbn; this tool does not implement zxcvbn). This tool does no leet decoding, generates no passwords, and queries no external database.

All computation runs locally on this page. Nothing is uploaded, stored, or logged. The results area and the report never quote your password or any substring of it.

Frequently asked questions

Is this band a guarantee?
No — it is an estimate under this page's published model.
Is my password sent or stored?
No. All computation runs locally in your browser; nothing is sent, stored, or written to the URL or logs.
Why is `P@ssw0rd!` only “fair”?
This tool does no leet substitution (`@` is not read as `a`); at 9 characters across four classes its base entropy is 59.0 bits, inside the 36–59.9 “fair” band.
