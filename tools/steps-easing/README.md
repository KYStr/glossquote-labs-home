# Steps Easing Explorer

Version 0.1.0, 2026-11-01. Static bilingual zh-Hant/English explorer for CSS steps(N, jump-position), exact before-boundary semantics and selectable CSS. No animation, clipboard API, storage or upload feature.

## Run interfaces
Node>=24, nativeESM, no dependencies or install step. `npm test`, `npm run check`, `npm run build`; `npm run preview` serves the generated dist at127.0.0.1:4180. The supported shared Sites preview uses the static `.openai/hosting.json` dist artifact on its managed4173. Managed preview is not evidence of the source server's HTTP headers. No deployment or production origin is configured.

Source core is exact rational/BigInt parsing and step/table formatting; controller commits one snapshot across graph/table/tracks/CSS. Static entries contain complete bilingual defaults; language toggle retains raw state while direct-language link opens defaults. Input edits/visibility/pagehide invalidate output. Exact k/N mode bootstraps its finite selector after Generate. Select CSS only selects text, never calls clipboard APIs.

## Scope and limitations
N1–100; jump-none requiresN>=2; decimal unit progress up to6places or exact k/N. Four explicit jump names; before flag selects a boundary side, not global decrement. Not an animation timing/phase simulator. See TEST-PLAN.md and AUTHOR-CHECK.md for actual checked and NOT_RUN coverage. Same-candidate nonauthor review remains required. No product quality score is self-assigned.
