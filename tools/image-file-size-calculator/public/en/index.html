How the estimate works and the fixed rules

Uncompressed bytes = width × height × bit depth ÷ 8, rounded up to a whole byte when the total bit count is odd at 1-bit. Estimated bytes = effective bytes × format factor (rounded half-up). GIF caps the effective bit depth at 8-bit. 1 KB = 1024 bytes and 1 MB = 1024 KB. Estimates under 1024 bytes are shown in bytes, under 1 MB in KB, and the rest in MB.

Format factors (all typical estimates): uncompressed 1.00, JPEG 0.10, PNG 0.40, WebP (lossy) 0.07, WebP (lossless) 0.30, GIF 0.25, AVIF 0.05. All computation happens locally on this page; nothing is uploaded, stored, or recorded.

Frequently asked questions

Are estimates accurate?
Actual file size depends on image content, encoder and quality settings; this tool gives a typical estimate, not the actual file size.
Is 1 KB 1000 or 1024 bytes?
This tool uses 1 KB = 1024 bytes and 1 MB = 1024 KB.
Can I use it for video?
No. Video size is estimated from bitrate × duration; this tool is for still images only.
