圖片檔案大小估算

輸入圖片寬×高像素、色彩深度與格式，估算一張靜態圖片的檔案大小，並對照未壓縮原始大小。全部計算都在這個頁面本機進行，不上傳、不儲存、不記錄你的輸入。

估算方式與固定規則

未壓縮位元組 = 寬 × 高 × 色彩深度 ÷ 8，1-bit 且總位元數為奇數時進位到整數位元組。估算位元組 = 有效位元組 × 格式係數（half-up 取整）。GIF 的有效色彩深度上限為 8-bit。1 KB = 1024 bytes、1 MB = 1024 KB。估算大小未滿 1024 位元組時以位元組顯示，未滿 1 MB 時以 KB 顯示，其餘以 MB 顯示。

格式係數（皆為典型估算值）：未壓縮 1.00、JPEG 0.10、PNG 0.40、WebP（有損）0.07、WebP（無損）0.30、GIF 0.25、AVIF 0.05。全部計算都在這個頁面本機進行，不上傳、不儲存、不記錄你的輸入。

常見問題

估算值準嗎？
實際檔案大小依圖片內容、編碼器與品質設定而異，本工具給的是典型估算值，不是實際檔案大小。
1 KB 是 1000 還是 1024 bytes？
本工具 1 KB = 1024 bytes、1 MB = 1024 KB。
影片可以用嗎？
不行。影片大小以位元率 × 時長估算，本工具只算靜態圖片。
