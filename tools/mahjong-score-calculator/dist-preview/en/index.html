Mahjong Score Calculator

Tick the patterns and circumstances of one winning hand and the tool applies one fixed rule set — Taiwan 16-tile mahjong, common family-game conventions — to list every tai: a concealed self-draw combines into 3 tai, Big Three Dragons does not stack the dragon pungs again, dealer tai joins the total, and the cap applies last. It then works out the payout from the base and the per-tai amount: what each opponent pays on a self-draw, and what the discarder pays on a discard win. There is only this one table; patterns outside it never score. The tai for All Sequences, All Five Categories, Heavenly/Earthly Ready, Flower Set, each honor flower, and Three/Four Kongs can be edited next to each item. Data stays on this page; no real money is involved.

    Frequently asked questions

    Why is a concealed self-draw 3 tai, not 2?

    Under the common family rules used here, concealed hand and self draw combine into a single 3-tai item instead of 1 + 1.

    What if our house counts differently?

    The tai values for All Sequences, All Five Categories, Heavenly/Earthly Ready, Flower Set, each honor flower, and Three/Four Kongs can be edited next to each item; all other items follow the fixed table in this spec.
