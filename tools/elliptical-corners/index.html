    尚未產生結果。可先選「重疊範例」，再產生結果，觀察同比例縮小。

    瀏覽器原生預覽——大型矩形請在框內捲動。

    指定半徑 → 調整半徑（CSS px）
    角落指定 x / y調整 x / y ≈形狀

    調整值顯示至小數點後兩位。計算使用精確分數，而非畫面上四捨五入的係數。

    CSS 保留指定半徑，不輸出寬高；套用到不同尺寸的方塊時，形狀可能改變。

    選取文字後，使用作業系統的複製指令。本工具不會自動複製。

    重疊如何調整

    八個半徑乘上同一係數。係數取 1 與各非零半徑總和對應「邊長 ÷ 半徑總和」的最小值。任一軸半徑為零時，該角為方角。
