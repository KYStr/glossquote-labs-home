Classical Cipher Lab

Pick a classical cipher, type some text, and watch it change. The rules are fixed on this page: only the letters A–Z and a–z transform, case is preserved letter by letter, and digits, punctuation and every other character pass through unchanged.

Read this first: these are classical ciphers from before modern cryptography. They can be broken in seconds and must never be used to protect real information. For real security, use modern, publicly reviewed encryption instead. Every cipher here is for learning and puzzles only.

Direction

ROT13 is the Caesar cipher at shift 13; encrypting and decrypting are the same operation.

Shift 0 = no change: the output equals the input.

The key repeats letter by letter and advances only when a letter is transformed; punctuation and spaces never consume key letters.
