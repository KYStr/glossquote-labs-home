Steps Converter

Convert a step count to distance with a measured stride or a height-based estimate, plus an optional weight-based walking calorie estimate. Stride and calories are estimates, not precise measurements.

Distance and stride

ItemValue

Stride and calories are estimates. The height-based stride uses 0.414 × height; calories use 0.75 kcal per kg per km (gross, including resting metabolism). Actual values vary with pace, terrain and the individual.

How it is calculated, and the input format

All calculation uses exact rational arithmetic, with no floating-point intermediates. The height-based stride is height × 207/500 (that is, 0.414); distance in km is steps × stride in cm ÷ 100,000; calories in kcal are 3/4 × weight in kg × the unrounded distance in km. Each output is rounded half-up once, from the exact value: stride to 1 decimal place, distance to 2 decimal places, steps per km to a whole number, calories to a whole number; the display-rounded values never feed back into any calculation.

Inputs accept ASCII digits and one decimal point only: commas, spaces, signs, exponents and full-width digits are format errors, and the tool never guesses. Steps must be a whole number; a leading zero (for example 007) is not accepted. The downloaded report is always named steps-converter-report.json; its content is the result as compact JSON with object keys sorted recursively by UTF-16 code units and one trailing newline.

Frequently asked questions

Where does the stride estimate come from?
Height mode uses stride = height × 0.414 (an ACSM regression average; individual values run about 0.413–0.415 and vary with pace). If you know your stride, measured mode is more accurate.
How accurate is the calorie figure?
It is a gross estimate (0.75 kcal/kg/km); MET tables put ordinary walking at about 0.73–0.77, and the net cost above resting is about 0.5. Individual error can reach ±20%; treat it as a rough guide.
Why does my watch show a different distance?
Watches use their own stride calibration or GPS. This tool uses exactly the stride shown, so a different stride gives a different distance.
