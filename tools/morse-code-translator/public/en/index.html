Morse Code Translator

Turn text into International Morse code (ITU), or decode pasted Morse back into text. This is a translator, not a radio: playback is local audio only and nothing is transmitted. Everything runs on your device — no network, no storage, and your text never appears in the URL.

Translate

Supports A–Z (either case), 0–9, the punctuation in the table below, and the tagged prosigns <SOS>, <AR>, <AS>, <KN> and <SK>. An unsupported character is named by position and the whole input is refused — never silently skipped.

Separate letters with one space and words with " / " or a run of two or more spaces. Write prosigns in tagged form, e.g. <...---...>. Unrecognised tokens are listed and shown as � — never dropped.

    Timing model and rules

    A dot is 1 unit, a dash 3 units, the gap between elements inside a character 1 unit, the gap between letters 3 units, and the gap between words 7 units; no trailing gap is counted after the final element. Speed follows the PARIS calibration: the word PARIS, including its trailing word gap, occupies exactly 50 units, so one unit = 1200 ÷ WPM milliseconds (PARIS on its own, without the trailing gap, measures 43 units). The duration shown above and the actual playback are computed from this same timing table.

    Morse has no letter case: lowercase input is encoded as uppercase, and decoded output is uppercase. Accented letters (such as É or ß) are not supported in this version — they are named by position and the whole input is refused, never approximated or expanded (ß never becomes SS). Prosigns count only in tagged form: an untagged run-together token that matches a character code decodes as that character with a note; one that matches no character is listed as unrecognised with a hint naming the prosign.
