摩斯碼翻譯器

把文字翻成國際摩斯碼（ITU），或把貼上的摩斯碼解回文字。這是翻譯工具，不是無線電：播放只在本機用音效產生，不會發送任何訊號。所有處理都在你的裝置上進行，不連網、不儲存、文字不會進到網址裡。

翻譯

支援 A–Z（不分大小寫）、0–9、規格內的標點，以及標記式通訊簡語 <SOS>、<AR>、<AS>、<KN>、<SK>。不支援的字元會指出位置並拒絕整段，不會默默跳過。

符號之間以一個空格分隔字母、以「 / 」或兩個以上空格分隔單詞。通訊簡語寫成標記形式，例如 <...---...>。無法辨識的符號會列出並以 � 標示，不會被丟掉。

    播放與計時

    此瀏覽器不支援 WebAudio，無法播放聲音；翻譯與時長顯示不受影響。

    文字
    摩斯

    播放中修改速度或音高，會在下一次播放才生效，不會改到正在播的訊號。就算靜音，總時長與上方高亮進度也能讓你跟上播放。

    計時方式與規則

    點 = 1 單位、劃 = 3 單位、同一字元內符號間隔 = 1 單位、字母間隔 = 3 單位、單詞間隔 = 7 單位；訊息結尾不計尾隨間隔。速度以 PARIS 標準校準：PARIS 一詞連同其後的單詞間隔共佔 50 單位，所以每單位 = 1200 ÷ WPM 毫秒（單獨計算 PARIS 本身、不含尾隨間隔時是 43 單位）。上方顯示的總時長與實際播放使用同一份計時表。

    摩斯碼本身不分大小寫：小寫字母會以大寫編碼，解碼結果也是大寫。重音字母（如 É、ß）在此版本不受支援 — 它們會被指出位置並拒絕整段，不會被近似或展開（ß 不會變成 SS）。通訊簡語只有標記形式才算數：未標記的連送符號若與字元代碼相同，會解成該字元並附註提醒；若不對應任何字元，會列為無法辨識並提示對應的簡語。
