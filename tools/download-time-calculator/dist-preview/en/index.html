Time needed and finish time

Details

This is a fixed-speed estimate, not a download guarantee; the actual time depends on the server, peak congestion, and your home network.

How it is calculated

The file size is first converted to bytes (1 byte = 8 bits): SI units multiply by 1000 per step, IEC units by 1024 per step, and the two families are separate choices, each exact. Seconds needed = file bytes × 8 ÷ (rated speed × efficiency ÷ 100), computed as an exact rational number throughout. The displayed total seconds are rounded half-up; the finish time is derived from the unrounded exact duration (whole seconds only), so the two can differ by under a second.

Duration format: H:MM:SS at or above one hour (hours may exceed 24 and never roll into days), M:SS below one hour, 0:SS below one minute. A finish on a later day is marked +Nd. The report file download-time-report.json contains this run's result as fixed-format JSON.

Frequently asked questions

Why isn't a 100 MB file done in 1 second at 100 Mbps?
Speed is measured in bits and file size in bytes; 1 byte = 8 bits, so it takes about 8 seconds.
What is efficiency?
Protocol overhead and real-world conditions make the effective speed lower than the rated one; 90 uses 90% of the rated speed. The default is 100, no reduction.
