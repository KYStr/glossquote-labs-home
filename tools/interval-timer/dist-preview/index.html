間歇計時器

先把一整份多段節目算清楚：準備幾秒、每回合運動與休息幾秒、共幾回合、最後一回合後是否再休息。節目表建好後，同一份節目表驅動計時：暫停期間不計時，段落切換時提示。

節目設定

準備秒數，0–3,600 秒；0 表示不設準備段。

每回合運動秒數，1–3,600 秒。

每回合休息秒數，0–3,600 秒；0 表示不設休息段。

回合數，1–99。

最後一回合後是否再休息一段。預設不含。

請輸入節目設定，或載入範例。

    節目表與計時方式說明

    節目表先放準備段（準備秒數大於 0 時），再依序放每一回合的運動段與休息段；休息段只在休息秒數大於 0、且該回合不是最後一回合、或最後一回合休息選「含」時才出現。零長度段一律省略。總時長等於準備秒數加上回合數乘以運動秒數，再加上休息段數乘以休息秒數。

    計時核心只吃「活動毫秒數」：暫停期間不計入，繼續後從暫停時的讀數接續。剩餘秒數一律無條件進位顯示，段內剩餘永不提前顯示 0；讀數恰等於段界時屬於下一段。下載的報告檔名固定為 interval-timer-report.json，內容是結果的精簡 JSON，物件鍵按 UTF-16 碼元升序遞迴排列，結尾一個換行。

    常見問題

    最後一回合後要不要休息？
    由「最後一回合休息」選項決定，預設不含；選「含」會在最後一回合後再加一段休息。
    暫停時計時會繼續嗎？
    不會。計時核心只吃活動毫秒數，暫停期間不計入；繼續後從暫停時的讀數接續。
    段落切換時會有提示嗎？
    會。段落切換時畫面會顯示新段落名稱並播報，裝置允許時也會發出短提示音；節目結束時提示音較長。
