重要聲明

本工具依你輸入的平均週期長度推算，所有日期都是估計，實際週期會受壓力、作息、疾病、藥物等因素影響而變動。本工具不能作為避孕依據，也不是醫療建議；若週期長期不規則、經血量異常或有任何疑慮，請諮詢婦產科醫師。

計算方式與格式說明

模型釘版：假設黃體期固定 14 天，排卵日 = 週期開始日 +（週期長度 − 14）；易孕期 = 排卵日 −5 天至排卵日 +1 天（含頭尾，共 7 天）；經期結束日 = 週期開始日 + 經期長度 − 1。一次列出四個週期：本次與接下來三次，間隔固定為你輸入的平均週期長度。這是消費型週期工具的常見估算慣例，實際排卵日與來潮日都會變動。

日期以整數 Julian Day Number 運算，不讀裝置時鐘或時區，四種時區環境下結果相同。輸入只接受 ASCII 數字與連字號組成的 YYYY-MM-DD 日期，以及不帶小數、符號或前導零的整數天數；工具不會替你猜格式。

下載的報告檔名固定為 period-cycle-report.json，內容是結果的精簡 JSON，物件鍵按 UTF-16 碼元升序遞迴排列，結尾一個換行。

常見問題

排卵日怎麼算？
本工具假設黃體期固定 14 天，排卵日 = 週期開始日 +（週期長度 − 14）。這是常見的估算慣例，實際排卵日會變動。
可以用來避孕嗎？
不可以。易孕期只是依平均值推算的估計，不能作為避孕依據；需要避孕請諮詢醫師並使用可靠的避孕方法。
我的週期不在 21–35 天怎麼辦？
本工具只接受 21–35 天。FIGO 將 24–38 天列為正常頻率範圍；週期長期落在接受範圍外或不規則時，請諮詢婦產科醫師，本工具的估計不適用。
