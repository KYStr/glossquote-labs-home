Groups

Names are shuffled with the seed and dealt round-robin: everyone lands in exactly one group, group sizes differ by at most one, and the same list and seed always give the same groups.

How grouping works, and the download formats

The list is shuffled with a seeded mulberry32 generator (a full Fisher–Yates shuffle, exactly one draw per position), then dealt round-robin: shuffled position t goes to group (t mod K) + 1. Group sizes differ by at most one, the larger groups always come first, and in “By group size” mode no group exceeds the requested size. Each line is one name; spaces, tabs and full-width spaces are trimmed from both ends, blank lines are skipped, and duplicate names are kept.

The report is always named group-generator-report.json: the result as compact JSON with object keys sorted by UTF-16 code units recursively and one trailing line feed. The text list is always named group-generator-groups.txt: one heading and its members per group, exactly one blank line between groups and no trailing line feed.

Frequently asked questions

Do the same list and seed give the same groups?
Yes. The shuffle depends only on the seed, so reruns and other devices match.
What about two people with the same name?
Duplicate names are kept as separate people and grouped independently; they are never merged or dropped.
What if I leave the seed blank?
The app generates a seed and shows it, so you can reproduce the same groups later.
