VO2 Max Calculator

Enter the distance of a Cooper 12-minute run, or the time of a 1.5-mile run, to estimate maximal oxygen uptake (VO₂max). Optionally add your age and sex to see the Cooper Institute fitness rating. The result is an estimate, not a laboratory measurement.

Estimate: a field-test estimate, roughly ±10% against laboratory gas analysis — good for tracking change, not a medical measurement. How it is calculated, and the input formats

Cooper 12-minute run: VO₂max = (distance in metres − 504.9) / 44.73 (Cooper 1968). 1.5-mile run: VO₂max = 483 / time in minutes + 3.5 (the ACSM published form). The result is rounded half-up to one decimal place, once only; the rating lookup uses the rounded value. Below 504.9 metres the Cooper equation returns zero or negative values, which are meaningless as fitness estimates, so the tool reports the distance as below the estimable range.

The rating uses the Cooper Institute age/sex norms (as tabulated in Heywood 1998; approximate), in six bands: Very poor, Poor, Fair, Good, Excellent, Superior. A rating is shown only when both age and sex are entered; entering only one asks for both together. The downloaded report is always named vo2max-report.json and holds the compact JSON of the result, with object keys sorted recursively by UTF-16 code unit and one trailing newline.

Frequently asked questions

Is this a lab measurement?
No. It is a field-test estimate, roughly ±10% against laboratory gas analysis — good for tracking change, not a medical measurement.
Why does a short distance fail?
Below 504.9 m the Cooper equation returns zero or negative values, which are meaningless as fitness estimates, so the tool reports the distance as below the estimable range.
How exact are the ratings?
The bands are Cooper Institute population norms and are approximate — reproductions vary slightly. Treat the rating as a reference, not a medical cut-off.
