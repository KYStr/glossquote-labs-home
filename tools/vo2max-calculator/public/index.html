準備就緒

估算結果

估算值：實地測驗公式的估算，與實驗室氣體分析相比誤差約 ±10%，適合追蹤個人變化而非醫學判斷。分級來自 Cooper Institute 常模，為群體近似值，不同出版品略有差異；請把等級當作參考，不要當成醫療門檻。

計算方式與格式說明

Cooper 12 分鐘跑：VO₂max =（距離（公尺）− 504.9）/ 44.73（Cooper 1968）。1.5 英里跑：VO₂max = 483 / 時間（分鐘）+ 3.5（ACSM 發布形式）。結果四捨五入（半數進位）到小數 1 位，只捨入一次；分級查詢使用捨入後的值。距離 504.9 公尺以下時 Cooper 公式會給出 0 或負值，沒有體適能意義，工具會直接指出距離超出可估算範圍。

分級來自 Cooper Institute 年齡／性別常模（Heywood 1998 轉載，近似值），共六級：非常弱、弱、普通、良好、優秀、卓越。只在年齡與性別都填寫時才分級；只填一個時工具會要求兩個一起填。下載的報告檔名固定為 vo2max-report.json，內容是結果的精簡 JSON，物件鍵按 UTF-16 碼元升序遞迴排列，結尾一個換行。

常見問題

這是實驗室測量嗎？
不是。這是實地測驗公式的估算值，與實驗室氣體分析相比誤差約 ±10%，適合追蹤個人變化而非醫學判斷。
為什麼距離太短會無法估算？
Cooper 公式在 504.9 公尺以下會給出 0 或負值，沒有體適能意義，所以工具會直接指出距離超出可估算範圍。
分級表有多精確？
分級來自 Cooper Institute 常模，是群體近似值，不同出版品略有差異；請把等級當參考，不要當成醫療門檻。
