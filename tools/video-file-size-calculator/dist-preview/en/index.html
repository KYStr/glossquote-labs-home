How it is calculated, and the units

File size = (video bitrate × codec factor + audio bitrate) × duration in seconds ÷ 8; bitrates are in bits per second (bps).

Sizes are shown in both decimal (MB/GB, 1 GB = 10^9 bytes) and binary (MiB/GiB, 1 GiB = 2^30 bytes) units; each of the four numbers is converted from the unrounded exact value and rounded half-up to two decimals. Recordable duration mode divides the target capacity by the total bitrate and floors to whole seconds, so that many seconds never exceeds the target.

The preset table holds typical H.264 values; a custom bitrate is treated as an H.264 baseline too, and the codec factor applies to both sources. This tool never reads a real video file and does not model container overhead.

FAQ

Why does the estimate differ from my real file?
Presets and factors are rules of thumb; real sizes vary with picture content, encoder and container, and this tool never reads your files.
What is the difference between GB and GiB?
A GB is 10^9 bytes (how storage is marketed); a GiB is 2^30 bytes (how operating systems often display it), so the same file shows a smaller number in GiB.
