Integer Representation Inspector

One bit pattern, two interpretations. Choose the input rules, then compare mathematical value with its fixed-width encoding.

Processed only in this page’s memory. No storage, transmission or clipboard access. Reload restores defaults. Browser memory is not a secure-erasure guarantee.

1 · Define the input

Input range

Changing base preserves the text and changes its next interpretation; it does not convert the previous result’s notation. Range and width changes never wrap or truncate.

Up to 80 raw characters. Optional minus and digits for the selected base; no +, prefixes, separators or decimals. Only surrounding ASCII whitespace is ignored. Hex e is a digit: 1e2 = 482; 0b10 is also a valid hex number, not a parsed prefix.

2 · Exact result

Mathematical representations keep a minus sign; fixed-width bits encode negatives in two’s complement. Byte groups are displayed most-significant-byte first, not machine memory order or a file format.
