Before using it on a real page

Contain ≠ scale-down

Contain keeps the whole source, but may enlarge it. Cover fills the box and produces zero or negative offsets on cropped axes. Position percentages align corresponding locations of source and box.

Dimensions have different jobs

Exported width and height describe the CSS content box, not source resolution. Apply fit-image to an img with the supplied ratio; check existing max-width, minimum sizes, important declarations and container rules.

No image file processing

No photos, URLs or EXIF are read; no cropped image is exported. Source dimensions are assumed to be correctly oriented. Coordinates are continuous geometry, not integer pixel-cropping instructions.
