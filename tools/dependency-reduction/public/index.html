模組依賴冗餘檢查

工程師維護少量 build modules 時，要看哪一條直接依賴已有間接路徑可覆蓋，並找到阻止任何排序的循環。資料只保留在目前頁面草稿，不會上傳或儲存。

每列一個模組，最多 100 個。名稱以英文字母開頭，僅含英文字母、數字、底線、連字號或句點，最多 32 字元；大小寫視為不同模組。

每列一條邊，格式為「前置>後續」，兩端都必須是已登記的模組，不可重複，最多 400 條。空白表示沒有邊。自環是合法輸入，但會被報為循環。

格式說明

模組最多 3,300 字元、100 列；邊最多 26,400 字元、400 列。輸入尾端的一個換行會被忽略。驗證順序：先檢查大小與字元，再檢查空內容、列數、名稱格式與重名；邊依序檢查格式、未知端點與重邊。第一個錯誤會指出欄位與列號。

檢查結果會顯示依賴層（同一層的模組彼此沒有依賴先後）、每條冗餘邊的替代路徑，或阻止排序的循環。報告下載為 JSON 檔案。
