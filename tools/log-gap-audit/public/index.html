記錄序號與時間缺口檢查

貼上一段序號與相對毫秒，找出相鄰記錄之間的序號缺口、序號倒退或重複、時間倒退，以及超過門檻的時間間隔。資料只留在目前頁面，不會上傳或儲存。

輸入格式與限制

每列恰為「序號 + Tab + 毫秒」，例如 10⇥0。序號與毫秒皆為 0 或非零開頭、最多 18 位的整數，不接受小數、符號或空白。最多 1,000 列、65,536 個字元；結尾一個換行會自動忽略。報告保留貼上順序，每筆只和前一筆比較，不會先排序；也不解析 ISO 日期或時區。

門檻預設 1000 ms；時間差嚴格大於門檻才列為時間缺口。SEQ_GAP 是兩數之間的整數缺口。

每列：序號、一個 Tab、毫秒。貼上測試資料或從檔案載入。

0 至 999999999999999999 的整數，預設 1000。

選擇 .tsv 或 .txt 檔案，內容會填入上方記錄欄。檔案只在本機讀取。

異常與兩個來源列

SEQ_GAP 是兩數之間的整數缺口；其他列可能包含遲到資料。報告不推斷事件有無到達。
