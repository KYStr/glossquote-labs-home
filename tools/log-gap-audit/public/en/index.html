Log Sequence and Time Gap Audit

Paste a run of sequence numbers and relative milliseconds to find sequence gaps, sequence reversals or repeats, time reversals, and time gaps over your threshold between adjacent records. Data stays on this page; nothing is uploaded or stored.

Input format and limits

Each row is exactly “sequence + Tab + elapsed-ms”, for example 10⇥0. Both numbers are 0 or a non-zero-leading integer of at most 18 digits; decimals, signs, and spaces are not accepted. At most 1,000 rows and 65,536 characters; one trailing newline is ignored. The report preserves pasted order and compares each row only with the previous one — it never sorts first, and it does not parse ISO dates or time zones.

The threshold defaults to 1000 ms; a time gap is listed only when the time delta is strictly greater than the threshold. SEQ_GAP is the integer gap between two numbers.

One row per record: sequence, one Tab, elapsed-ms. Paste test data or load it from a file.

An integer from 0 to 999999999999999999; default 1000.

Choose a .tsv or .txt file; its contents fill the records field above. The file is only read locally.

Findings and source row pairs

SEQ_GAP is the integer gap between two numbers; other rows may contain late data. The report does not infer whether any event arrived.
