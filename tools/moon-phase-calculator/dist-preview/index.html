月相計算機

輸入西元日期，查看當天（UTC 正午）的月齡、照亮比與八階段月相名稱，並推算下一個朔與下一個滿月各落在哪一天，同時給 UTC 日期與你所在偏移的當地日期，方便安排觀月、拍攝與露營行程。全部以固定平均朔望月在本機計算，不連線、不查曆表。

日期與時區

西元日期，格式 YYYY-MM-DD，範圍 1900-01-01 至 2100-12-31。

格式 +HH:MM 或 −HH:MM，分鐘須為 00、15、30 或 45，範圍 −12:00 至 +14:00。只影響下一個朔／滿月的「當地日期」顯示，不影響評估時刻與其他輸出。

尚未計算。輸入日期，或載入範例。

月相結果

本工具以平均朔望月推算，實際朔望時刻可相差數小時；月相以所選日期 UTC 正午為準。

計算方式

評估時刻固定為所選日期的 12:00 UTC。月齡以固定朔望月 S = 29.530588853 天與參考朔 JD 2451550.1 推算：age = (JD − 2451550.1) mod S（正餘數，落在 [0, S)）。八個月相每段寬 S/8、以正規時刻為中心分段；照亮比 = (1 − cos(2π × age / S)) / 2。下一個朔／滿月由未捨入的月齡推得，事件日期再依你輸入的 UTC 偏移換算當地日期。月齡、照亮比與天數以四捨五入（half-up）至小數一位顯示；月相判定與事件日期一律用未捨入值。日期與儒略日換算只用整數演算法，不使用 Date 物件，不受本機時區影響。

常見問題

月相以哪個時刻為準？
所選日期的 UTC 正午；同一晚前半夜與後半夜可能跨段，日期級結果是代表值。
為什麼和農民曆的滿月差了一天？
本工具以平均朔望月推算，實際朔望時刻可相差數小時，跨過午夜就差一天。

全部計算都在這個頁面本機進行，不上傳、不儲存、不記錄你的輸入。
