Stopwatch with Laps

Press Start, then press Lap at the end of each round. Every lap time is derived from split readings on one clock, so the laps always add up exactly to the last split. Time spent paused for a break never counts.

The display shows centiseconds, truncated from millisecond timing (never rounded up). This is not officiating or photo-finish grade accuracy.

Keyboard shortcuts

  • Space: start / pause / resume
  • L: record a lap (while running only)
  • R: reset
