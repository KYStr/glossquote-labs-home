Rules and limits
  • Number format: a decimal number such as 12.5. No thousands commas, exponents, plus signs, or leading/trailing decimal points.
  • Each field holds at most 24 characters; the absolute value is at most 999,999,999,999.
  • The page rounds the exact result to two decimals and trims trailing zeros; the downloadable report keeps the ten-decimal exact value.
  • A share whose whole is 0, or a change whose starting value is 0, cannot be calculated and returns a fixed error.
  • Data stays in the current page draft only; leaving or switching language discards it. Nothing is stored or uploaded.

FAQ

How is percentage change calculated?

(new − start) ÷ start × 100; a starting value of zero cannot be used.

Why does the page show two decimals?

The page rounds the exact result to two decimals and trims trailing zeros; the downloadable report keeps the ten-decimal value.
