SemVer 版本順位比較

比較兩個 Semantic Versioning 2.0.0 版本，看哪一個順位在先、差異出在哪一個識別符。全部計算都在本機進行，不會上傳或儲存你輸入的內容。

切換語言或離開頁面會失去草稿。比較結果只對目前輸入的快照有效；輸入一改，舊結果與下載立即失效。

請輸入兩個版本，或載入範例。

順位與決定它的識別符

逐欄比對
欄位左側版本右側版本說明
輸入限制
  • 每個版本最多 256 個字元；不修剪空白，開頭或結尾的空白都會被拒絕。
  • 格式為 主版本.次版本.修訂版本，可選 -prerelease 與 +build；不接受 v 前綴。
  • 主欄每欄最多 32 位數字，不可有前導零（0 本身除外）。
  • prerelease 與 build 各最多 16 個識別符，每個識別符最多 32 個字元，僅可含 0-9 A-Z a-z -。
  • 純數字的 prerelease 識別符不可有前導零；build 識別符可以。
  • build metadata 不參與順位比較。
常見問題

rc.10 和 rc.2 哪個較新順位？
相同前綴下，10 依數值大於 2。

+build.2 會比 +build.1 順位高嗎？
build metadata 不參與順位比較。
