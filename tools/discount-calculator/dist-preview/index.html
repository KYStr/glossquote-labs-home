折扣計算機

逐步算出兩重折扣、折價券與折扣後稅金的每步價格，看最終單價、總價、實際省下多少與約幾折。兩重折扣是連乘，不是相加：八折再九折是付 72%，不是付 70%。

原價（單件）

20% off＝八折、10% off＝九折。金額：整數最多 7 位、小數最多 2 位，範圍 0.01–9,999,999.99。

第一重折扣 %

折扣百分比：八折填 20、九折填 10；0 表示沒有這重折扣。最多兩位小數，範圍 0–100。

第二重折扣 %、折價券

與第一重折扣連乘，不是相加；0 表示沒有這重折扣。最多兩位小數，範圍 0–100。

定額折價券，在兩重折扣之後、計稅之前抵扣；券額超過折後價時只實際抵到 0。0 表示不用券。金額格式同原價。

稅率 %（折扣後加計）、數量

對折扣與折價券之後的價格計稅。最多兩位小數，範圍 0–100。本工具不提供或驗證任何法定稅率，稅率由你輸入。

整數，範圍 1–999。

尚未計算。請輸入價格與折扣，或載入範例。

計算方式與格式說明

計算順序固定：原價先連乘第一重與第二重折扣，再抵折價券，最後對折後價按稅率加稅。金額一律以整數分、百分比以 basis points（萬分之一）計算，每一步都四捨五入（half-up）到整分；五步明細中，折扣為 0 或不用券時該列仍在、金額為 0。折價券超過折後價時只實際抵扣到 0，價格不會變成負數，明細會如實列出實際抵扣額。

共省金額、有效折扣 % 與約幾折都以稅前的折後價計算：稅不是折扣，不列入省下金額。約幾折是折後價占原價的比例（付 72% 即約 7.2 折；折後價與原價相同是 10.0 折，折後價為 0 是 0.0 折）。稅率由你輸入，本工具不提供、不驗證任何法定稅率表。

輸入只接受 ASCII 數字與一個小數點：逗號、空白、正負號、指數與全形數字都是格式錯誤，工具不會替你猜。下載的明細檔名固定為 discount-calculator-report.json，內容是結果的精簡 JSON，物件鍵按 UTF-16 碼元升序遞迴排列，結尾一個換行。

常見問題

八折是什麼意思？
付原價的 80%，也就是折扣 20%。
20% 再 10% 是 30% 嗎？
不是。先付 80% 再付 90%，實付 72%，有效折扣 28%。
稅在折扣前還是折扣後算？
本工具固定在兩重折扣與折價券之後，對折後價計稅。

全部計算都在這個頁面本機進行，不上傳、不儲存、不記錄你的輸入。
