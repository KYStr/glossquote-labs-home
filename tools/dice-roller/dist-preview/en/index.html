Dice Roller

Dice and total

    Notation format and limits

    Notation is NdM with an optional +K or -K modifier, e.g. 2d6+3. With no count the count defaults to 1 (d20 is one 20-sided die); a capital D is accepted and normalized to lowercase d. Dice count 1–100, sides 2–1000, modifier between -10000 and 10000, seed an integer from 0 to 4294967295. Neither notation nor seed is trimmed: spaces or any extra characters are format errors.

    The tool uses the mulberry32 pseudorandom generator, drawing exactly once per die and reporting results in roll order; the face total is the sum of the dice, and the total is the face total plus the modifier, which may be negative and is never clamped. The downloaded report is always named dice-roller-report.json: compact JSON of the result with object keys sorted recursively by UTF-16 code units and one trailing newline.

    Frequently asked questions

    What does "d20" mean?
    With no count, the count defaults to 1 — one 20-sided die.
    Why does the same seed roll the same dice?
    The tool uses the mulberry32 pseudorandom generator; results are fully determined by the seed, so any roll can be reproduced and checked.
    What happens if the seed is blank?
    At run time a cryptographically random seed is generated and shown in the field; reuse it to reproduce the roll.
    Is this true randomness?
    No. It is deterministic pseudorandom output, fine for games, teaching and testing — not for gambling or security.
