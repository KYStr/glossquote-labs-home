    骰式格式與限制說明

    骰式為 NdM，可加 +K 或 -K 修正，例如 2d6+3。省略骰數時預設為 1 顆（d20 即 1d20）；大寫 D 亦接受，正規化為小寫 d。骰數 1–100 顆、面數 2–1000 面、修正值介於 -10000 到 10000、種子為 0 到 4294967295 的整數。骰式與種子都不修剪空白，空白或任何多餘字元皆為格式錯誤。

    本工具使用 mulberry32 假隨機產生器，每顆骰子恰取一次亂數，依擲出順序輸出結果；骰面總和為各顆點數之和，總和為骰面總和加修正值，可為負數，不夾限。下載的報告檔名固定為 dice-roller-report.json，內容是結果的精簡 JSON，物件鍵按 UTF-16 碼元升序遞迴排列，結尾一個換行。

    常見問題

    d20 是什麼意思？
    只寫 d 和面數時，骰子數量預設為 1，所以 d20 就是擲一顆 20 面骰。
    為什麼同一種子擲出同樣結果？
    本工具使用 mulberry32 假隨機產生器，結果完全由種子決定，方便重現與核對。
    種子留空會怎樣？
    執行時會以密碼學隨機產生一個種子並顯示在欄位中，之後可用同一種子重現。
    這是真隨機嗎？
    不是；這是決定性的假隨機，適合桌遊、教學與程式測試，不應用於賭博或安全用途。
