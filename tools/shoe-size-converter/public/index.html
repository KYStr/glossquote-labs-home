鞋碼換算

先選類別（男鞋、女鞋、童鞋），再輸入腳長，或挑一個你已知的鞋碼；所有系統的鞋碼都從同一份對照表的同一列讀出。腳長落在兩列之間時，依 ISO 慣例進位到下一列，結果會顯示該列的腳長，讓你核對進了多少。

此瀏覽器無法啟動換算工具。請在支援 JavaScript 模組的瀏覽器開啟。下方的對照表來源說明仍可閱讀。

輸入方式

站立量測腳跟到最長腳趾的距離；左右腳不同時以較大的為準。可輸入 10.0–35.0 公分。

任選一個系統的鞋碼，其他系統會從同一列讀出。

關於這份對照表

本工具的對照表整理自 Wikipedia「Shoe size」條目所收錄、以 ISO/TS 19407 為基礎的換算表（成人表 22 列、童鞋表 16 列），以資料檔形式隨附來源、列數與 SHA-256 驗證；頁面上的每個答案都來自同一列，不用公式推算。

鞋碼並未完全標準化：各品牌有自己的對照表，版型與楦頭也因品牌而異。換算結果只是試穿的起點，不能取代實際試穿；本工具不推薦購買尺寸，也不收錄任何單一品牌的對照表。
