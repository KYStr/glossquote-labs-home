Reading Time Estimator

Paste Chinese, English or mixed text to estimate how long it takes to read silently, and how long it takes to read aloud for a recording. Chinese characters are counted one by one, English is split on whitespace, and all four speeds can be set to your own pace. The result is an estimate, not a stopwatch reading.

Counts and time estimates

How it is calculated, and the display format

Chinese characters: a code point in U+3400–U+4DBF, U+4E00–U+9FFF, U+F900–U+FAFF or U+20000–U+2A6DF counts as 1. An astral character (such as U+20000) counts as 1 character. English words: tokens are split on whitespace; a token counts as 1 word when it contains at least one ASCII letter or digit — don't, 2026-11-09 and well-known each count as 1 word. One token can contribute to both counts at once. Times use exact rational arithmetic and are rounded half-up exactly once, on the total: silent seconds = 60 × Chinese characters / Chinese silent rate + 60 × English words / English silent rate, and likewise for speaking. Display is M:SS, switching to H:MM:SS at one hour; 0 seconds shows as 0:00.

Known limits: Japanese kana (U+3040–U+30FF) and Korean syllables (U+AC00–U+D7AF) are in neither the CJK ranges nor ASCII letters or digits, so pure kana or pure Korean text counts as zero; CJK punctuation (U+3000–U+303F) and full-width characters (U+FF00–U+FF60) likewise do not count. The downloaded report is always named reading-time-report.json; its content is the result as compact JSON with object keys sorted by UTF-16 code units, recursively, and one trailing newline.

Frequently asked questions

Why count characters instead of words for Chinese?
Chinese text has no spaces between words, so this tool multiplies the character count by an adjustable characters-per-minute rate. For per-word frequencies, use the frequency counter.
Can the speaking time guarantee my recording length?
No. It is an estimate from average rates; pauses and delivery change the real duration, and this tool never plays audio.
How are hyphenated English words counted?
Tokens are split on whitespace only, so well-known counts as 1 word; full-width letters and digits do not count as English words.
Where do the default speeds come from?
They are adjustable conventions chosen inside commonly published ranges, not constants of nature; set them to your own pace.
Why does Japanese or Korean text count as zero?
In v1 the character ranges cover ideographs only; kana and Hangul syllables are neither CJK ideographs here nor English words, and the page discloses this limit.
