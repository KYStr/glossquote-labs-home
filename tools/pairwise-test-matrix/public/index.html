兩兩覆蓋測試矩陣

測試工程師有幾個有限選項，需先挑一份能覆蓋任兩維選項配對的測試清單。成功是每個配對都有一個具體案例，且知道這份清單不證明更高階組合已測。

每行格式 name:a|b，一行一個維度；2–5 個維度，每維 2–6 個值。

格式與限制
  • 每行 name:a|b：維度名稱以英文字母開頭，可含英數、-、_，最多 24 字元；值以英數開頭，同樣最多 24 字元。
  • 輸入最多 1,024 字元；行內不得有空白；維度名稱與同維的值不可重複。
  • 全部維度值數乘積最多 2,048，超過不會列舉。
  • 結果以確定性 greedy 依新增覆蓋挑選案例，不保證案例最少；下載為 JSON 報告。
  • 全部計算都在本機進行，不上傳、不儲存。

案例和新增配對數

此為依新增覆蓋挑選的可重現案例集合，不保證案例最少，也沒有執行測試。

常見問題

這是最少案例的證明嗎？

它是依新增覆蓋挑選的可重現案例集合。

這代表每個組合都會測嗎？

每兩維的所有配對都會出現，完整的多維組合可能未列入。
