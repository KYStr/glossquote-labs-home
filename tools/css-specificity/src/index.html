CSS 選擇器 specificity 比較器

比較兩個選擇器的 specificity，逐節點看清每一分從哪裡來。

這個工具做什麼

輸入兩個選擇器，按「比較」得到各自的 (A,B,C) 三元組、先不同欄位，以及完整的節點貢獻樹。所有計算都在你的瀏覽器內完成，不傳送、不儲存。

注意：specificity 不是 cascade。本工具不執行選擇器、不比對 DOM，也不預測哪條規則會勝出；它只依下方支援子集計算 specificity 本身。

支援的語法子集（完整清單）

只支援以下語法；子集外一律回報為不支援或語法錯誤，不代表瀏覽器 CSS 的有效性。

  • 類型與萬用：ident（[A-Za-z_][A-Za-z0-9_-]*）或 *，只能在 compound 開頭。
  • 簡單選擇器：#id、.class、[attr]（僅屬性存在，括號內只有 ident）。
  • 一般偽類（單冒號）：hover、focus、focus-visible、focus-within、active、checked、disabled、enabled、root、empty、first-child、last-child、only-child。
  • 函數偽類：:is(...)、:not(...)、:where(...)，引數為逗號分隔的複合選擇器清單（1–8 個分支，函數最多巢狀 4 層）。
  • 偽元素（雙冒號）：before、after、first-line、first-letter，只能出現在最外層最後一個 compound 的結尾，前面必須先有類型、萬用或簡單選擇器。
  • 組合子：空白（後代）、>、+、~。最外層逗號不支援。
  • 每欄原始文字上限 1024 個 UTF-16 單位；核心不修剪、不正規化你的輸入，原文完整保留。
  • 計分：ID=(1,0,0)；class／屬性／一般偽類=(0,1,0)；類型／偽元素=(0,0,1)；*=(0,0,0)。:is/:not 取分支中字典序最大者（不逐欄取大、相同不加倍）；:where 貢獻恆為 0，但其子節點仍須合法且分數保留在樹中。比較先比 A、再 B、再 C，欄位間不進位。
