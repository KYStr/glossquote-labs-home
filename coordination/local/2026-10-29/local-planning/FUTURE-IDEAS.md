# 下一批候選工具

這些是建議研究方向，**還沒有完整藍圖，不能直接當成開發任務**。先完成首批的一款或數款，再挑選。列表不代表已完成市場調查；不承諾需求量、收入或技術支援範圍。

| 候選 | 主要工作 | 適合本機的部分 | 建立藍圖前需決定 |
|---|---|---|---|
| PDF 頁面整理 | 合併、拆頁、旋轉 | 本機讀寫文件 | parser/renderer、加密／表單／簽章範圍、授權與大檔上限 |
| QR Code 產生 | 文字／網址轉 QR | 本機編碼與下載圖片 | 編碼器、容錯等級、文字上限、勿自動開啟內容 |
| 字幕格式整理 | SRT／VTT 互轉與偏移 | 本機解析時間軸 | 重疊、非法時碼、樣式資訊損失與匯出規則 |
| 音訊裁切 | 選一段保留 | 本機解碼／編碼 | 格式、精度、記憶體、是否接受有損輸出 |
| 圖片去除中繼資料 | 產生可分享副本 | 解析與重編碼 | 必須驗證 metadata，不保證能消除可視的個資 |
| 像素圖樣產生 | 做重複背景與小圖樣 | 本機幾何繪製 | 有限樣式、SVG／PNG 下載、安全序列化 |
| 簡易流程圖 | 排列方塊與連線 | 本機圖形編輯 | 鍵盤替代拖曳、匯入 schema、列印及 SVG |
| Markdown 閱讀預覽 | 編輯／預覽說明文件 | 本機解析呈現 | HTML 禁用與消毒、安全連結、內容上限 |
| 正規表示式練習 | 測試匹配結果 | 隔離 Worker 計算 | 災難回溯、時間上限、取消；不在主執行緒直接跑 |
| URL 檢視整理 | 看懂 query 和編碼 | 純字串解析 | 不請求網址、不保存 token、不自動跟 redirect |
| 檔案校驗碼 | 算 SHA-256 等摘要 | 本機檔案計算 | 大檔串流、進度與取消；摘要不代表來源安全 |
| 批次重新命名預覽 | 產生新檔名規劃 | 本機列舉使用者指定檔 | 瀏覽器寫檔權限、衝突與撤回；先做預覽或匯出清單 |
| 時區重疊時間 | 找不同地區可開會時段 | 本機日期／時區換算 | IANA資料、夏令時間、模糊時刻；不接行事曆 |
| 日常支出試算 | 數個支出加總與分類 | 本機表單／計算 | 固定輸入幣別、四捨五入、不是投資建議或即時匯率 |
| 分帳計算 | 公平分攤一筆金額 | 純計算 | 最小貨幣單位、餘數分配、無轉帳與金流 |
| 打包檢查清單 | 依情境建立行前清單 | 本機清單編輯與匯出 | 使用者資料是否持久化、模板來源、不做預訂 |
| 習慣記錄 | 本機打卡與回顧 | 使用者控制的儲存 | 儲存／清除／匯出與損毀恢復、裝置間不自動同步 |
| 抽籤與分組 | 把假名或編號分組 | 本機洗牌與規則 | 公平性語義、隨機來源、重複名字、不宣稱公證 |
| 可列印標籤 | 編排小標籤頁 | 本機排版列印 | 紙張尺寸、瀏覽器邊界、文字溢出與字型 |
| 網頁用字級試排 | 試看標題與段落 | 本機排版 | 只用本機字型、長文排版、可讀性評估界線 |

## 升格為正式藍圖的準則

- 使用者能用一句話描述完成什麼。
- 可以限定 MVP，並給至少 12 個有預期結果的案例。
- 資料流、儲存、輸出與權限清楚，無隱藏雲端依賴。
- 核心演算法與必要函式庫有可核實來源；授權與成本路徑可交代。
- 即使免費提供，也有你願意負擔的維護範圍。
- 和已存在工具的主要工作不同；若只是同功能的另一個設定，先考慮原工具的小版本。

當候選升格時，複用品牌／工程原則，但重新設計該工具的工作區、任務順序、錯誤與案例；不要把其他工具的接受標準改名後直接貼上。
