# M2 release implementation

M1 public source files remain byte-identical. `scripts/m1-asset-lock.json` pins all 12 source assets against the reviewed preview. Production builds generate only a different HTML head, robots/sitemap and static hosting metadata in `dist-production/`; they never write `public/` or preview `dist/`. Both page bodies, CSS, calculator, report, renderer, copy/download state and listeners remain unchanged.

The two canonical pages have index/follow, reciprocal languages and x-default, their existing exact titles/descriptions, Open Graph metadata and one WebApplication JSON-LD record. Each record has an exact SHA-256 CSP allowance. The global static header rule is noindex; each canonical rule detaches inherited X-Robots-Tag/CSP before adding its own values. The offline header model implements the exact wildcard/exact-path subset used by this file and comma merging. It is not a replacement for deployed CDN verification.

The two root aliases redirect to the corresponding explicit index.html canonical using `_redirects` (301). Provider redirect rules precede custom headers. Unknown routes are real 404 pages, never a calculator SPA fallback. Production robots uses longest allow/disallow matching; every required JS/CSS path is actually evaluated by tests. The sitemap lists only the two canonical URLs.

The production model binds loopback 5212, serves immutable validated assets, supports GET/HEAD and rejects other methods. All URI ambiguity/traversal/query cases use 404; aliases are the only declared redirects. Port conflicts preserve the existing listener and use a system-assigned loopback port.

Wrangler configuration is static assets only, with no Worker main, binding, vars or secrets. The compatibility date is 2026-10-19. Logs/traces/observability, workers.dev, preview URLs and CLI metrics are disabled by the repository privacy contract. No Wrangler installation, account API, deployment or credential read is part of M2.

Official reference checks (2026-10-19): [static headers](https://developers.cloudflare.com/workers/static-assets/headers/), [static redirects](https://developers.cloudflare.com/workers/static-assets/redirects/), [HTML handling](https://developers.cloudflare.com/workers/static-assets/routing/advanced/html-handling/), [configuration](https://developers.cloudflare.com/workers/wrangler/configuration/). These documentation reads added no dependency or network call to the product. The Workers best-practices skill was used only to check configuration; repository restrictions on telemetry take precedence.

Release source is prepared in an independent reviewed copy. Local evidence, full Windows/Git snapshots and machine-specific HANDOFF history stay outside the public repository. The published HANDOFF, TASK-ENTRY and RELEASE-CANDIDATE use a portable release summary; their transformation is recorded in private publication evidence. Product/spec/test bytes are copied without transformation.

Production favicon correction (U19-32-RELEASE-R1): the primary deployed the initial source and found a missing implicit favicon.ico in the live Traditional Chinese console gate. The production builder now emits one fixed local `favicon.svg` and both production heads explicitly reference it. The vector contains only static svg/rect/path content, with no script, style, event handler or external resource. The SVG bytes live in the production builder, not M1/public. Production robots permits the exact asset and the local model serves image/svg+xml. CSP remains byte-identical, including img-src 'self' and the existing script/connect restrictions. Preview and all 12 original public sources remain unchanged; production now contains 16 files. Only the primary may deploy and rerun the native live console gate.
