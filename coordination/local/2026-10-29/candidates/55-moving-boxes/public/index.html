        清單與專案備份

        房間搬運清單列出各房間的箱號與開箱優先序；逐箱明細包含物品與數量。若要下次繼續編輯，請保存專案 JSON。

        若瀏覽器阻擋下載，可自行選取並保存預覽文字。

        恢復專案 JSON

        最多 8 MiB（8,388,608 bytes）。整份驗證後才顯示箱數與物品數；確認前不替換，取消或錯誤保留現有資料。

        或貼上專案 JSON

        最多 100 箱、總共 1,000 項物品紀錄。文字限單行；資料不會自動保存。清除本頁不會刪除先前下載的檔案，也不承諾安全抹除記憶體。

        使用說明

        會自動記住箱子嗎？

        不會；下載專案 JSON 才能下次恢復。本頁無帳戶、雲端同步或自動儲存。

        找不到物品會怎樣？

        顯示沒有符合項目，原清單保持不變。搜尋也會比對箱號、房間及備註。

        能移動物品到另一箱嗎？

        可以，選目的箱後一次移動，不複製出重複項。物品 ID 保持相同；同名物品仍可分別記錄。

        需要標籤印表機或網路服務嗎？

        不需要。匯出的是文字清單與專案 JSON，沒有地址、重量計價或印表機串接。本工具需要支援原生 JavaScript 模組、Blob 下載與 FileReader 的瀏覽器；不支援時會停止操作。
