Comparison rules and questions

Can I compare different dimensions?

Use images with the same oriented dimensions. Resize them beforehand if needed. This tool never aligns, resizes or shifts the images automatically.

Can JPEG create noisy differences?

Yes. Compression can change pixels; the threshold is a filter, not a quality score. Browser decoding and color handling may also affect pixel values.

Are images uploaded?

No. Processing stays in the current page. Clearing releases this page’s references; it does not promise secure erasure from the browser or operating system, and it does not delete downloaded files.

How are transparency and orientation handled?

The decoder applies EXIF visual orientation once, then each image is flattened onto white. Statistics compare the resulting 8-bit RGB. Transparency counts only when it changes the color after flattening.

How are the overlay and differences calculated?

The right image share is an integer from 0 to 100. Each weighted channel is rounded to the nearest integer. A pixel differs when its largest absolute RGB difference is strictly greater than the threshold. Difference mode highlights changes in red and fades unchanged left-image pixels to grayscale.

What if my device is too slow or cannot decode an image?

Cancel while processing. Work stops after 20 seconds so you can retry. Lower-powered devices may not handle images within the maximum limits; try smaller images with matching dimensions. There is no cloud fallback.
