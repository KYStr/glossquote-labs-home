      Before you export

      Will it split names into first and last names?

      No. The full name stays in the formatted name property; structured name parts remain empty.

      Will it add a country code or remove leading zeros?

      No. It preserves the text and checks only length and control characters; it does not verify whether a number can be dialed. Email receives a basic ASCII syntax check, without DNS, existence or deliverability checks. Unicode email addresses are not supported.

      Will the file import into every phone?

      That is not guaranteed. The tool creates a UTF-8 vCard 3.0 file; check the import steps in your contacts app. Downloading does not mean contacts were imported. The tool does not call device contacts APIs.

      Where are my file and contacts kept?

      The CSV, mapping and VCF remain in this page's memory. There is no upload or persistent storage. A downloaded file may contain personal information; keep it carefully. The tool cannot guarantee secure erasure of browser or operating system memory.
