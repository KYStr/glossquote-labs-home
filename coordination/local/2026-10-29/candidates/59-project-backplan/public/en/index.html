Slack is the number of workdays a task can move. ◆ Critical means zero slack. Every root task has the same early start at the project anchor. Parallel work is allowed; this tool does not allocate staff or guarantee on-time delivery.

How the plan works

Why is there no start-date field?

The tool finds the longest dependency path first, then counts back from the adjusted deadline to set the earliest start for every root task.

What happens when the deadline falls on a weekend or holiday?

It moves to the previous workday in your calendar. The result shows both the entered and adjusted dates.

Does the critical path guarantee a delay?

No. It marks tasks with zero slack under this model. It does not estimate staffing, risk, interruptions, or other resource limits.
