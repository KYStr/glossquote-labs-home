# 自訂文字遮蔽

狀態：SPEC_ONLY（2026-10-13）。此資料夾是待實作規格；產品、測試、GitHub、正式上線及外部驗收皆 NOT_RUN。進度見 HANDOFF.md。

使用者先貼要分享的文字，再明確列出要遮蔽的字串。工具只在本機逐字比對並以固定字串 [REDACTED] 替換，讓分享前有一份較少包含指定內容的副本。使用者需自己檢查輸出。

替代方案是手動搜尋與取代，或把文字交給線上服務。本工具的價值假設是少做重複搜尋、來源不必上傳。尚無搜尋量或訪談證據。它不會找出沒有指定的姓名、地址、密碼、帳號或其他個資。

MVP 是靜態雙語頁，所有文字只在頁面記憶體。使用者可複製遮蔽結果，或明確下載固定名稱的 TXT；不會保存或上傳。難度中高：需定義重疊規則、精確規則、超長輸入與輸出生命週期。無 runtime dependency。

非目標：AI/regex/自動個資偵測、PDF/圖片/OCR、文件批次、雲端/帳號、儲存、加密、稽核報告、任意 replacement、原文下載、格式化、或保證遮蔽成功。它只替換使用者列出的字串，結果不等於完整匿名化或安全審查。
