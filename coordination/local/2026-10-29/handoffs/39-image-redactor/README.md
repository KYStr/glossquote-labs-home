# 圖片敏感資訊遮蔽 / Image Redactor

狀態：SPEC_ONLY。這是產品規格，尚未實作。M1 本機候選、測試、建置、公開來源、網站部署與外部驗收均 NOT_RUN。

## MVP

選取一張本機 JPEG 或 PNG，在畫布上以不透明黑色矩形遮住指定區域，檢查實際匯出預覽，再下載扁平 PNG 副本。

## 使用者工作與價值假設

假設客服、支援或產品人員在分享問題截圖前，想遮掉畫面中的 email、訂單號、姓名或內部資訊，同時保留周圍上下文。這個情境合理但尚未經訪談或使用量資料驗證；本文件不宣稱需求量。

工具只會遮住使用者手動畫出的矩形。它不會自動尋找敏感資訊，也不保證使用者已遮住所有該隱藏的內容。匯出的 PNG 會把底圖、白色透明背景和黑色矩形合成到單一像素點陣圖；不保留可移動的遮罩圖層，也不嵌入原始檔案。這不代表能安全抹除瀏覽器記憶體，也不會刪除裝置上的來源檔。

## 產品邊界

- 一次一張本機靜態 JPEG 或 PNG；檔案最多 8 MiB，解碼後寬高各最多 8,192 像素、總像素最多 16,000,000。
- PNG 必須是靜態 PNG；遇到 APNG 動畫標記即拒絕。
- JPEG 支援 EXIF Orientation 1–8，預覽、座標和輸出採相同的正確視覺方向。
- 使用者可拖曳建立黑色矩形，也可用鍵盤輸入整數像素座標 x、y、寬、高。最多 50 個遮罩。
- 至少一個遮罩才可生成；生成後先查看匯出 PNG 預覽，再明確下載固定名稱的副本。
- 輸入或遮罩變更會立即撤銷舊輸出。可取消生成；離頁清理程式持有的檔案、Bitmap、Canvas 和 URL 參照。

## 環境與工程基線

正式產品是原生 HTML、CSS 和瀏覽器 ESM 靜態頁面；本機開發使用 Node.js 24+ 及內建 node:test。執行期零套件依賴。支援目標是 M1 驗收時安裝的最新穩定桌面 Chrome 與 Edge；不宣稱涵蓋所有瀏覽器。手機可嘗試預覽，但記憶體不足時必須明確退出，不能偷偷縮圖或遠端處理。

## 非目標

不做模糊、像素化、筆刷、OCR、自動偵測、裁切、調整尺寸、批次、SVG、動畫圖片、圖片網址、遠端上傳、帳號、雲端、可還原遮罩圖層、原生檔案系統寫入、EXIF 編輯器或安全認證。使用者必須檢查整張輸出；未遮罩區域仍可能含個人或機密資訊。
