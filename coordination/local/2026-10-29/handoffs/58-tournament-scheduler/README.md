# 循環賽賽程表

**這是規格，尚未實作。** 輸入 2–32 隊和可用場地數，產生單循環或雙循環賽程、輪空、各輪場地/時段及每隊對手表。每個對戰由固定 circle method 建立；場地不足時同一輪拆成連續時段，不會把同隊排進同一時段兩次。

M1 是 Node.js 24+、原生瀏覽器 HTML/CSS/ESM 的雙語靜態候選工具，零依賴、無帳號、雲端或外部 API。排程只在目前頁面記憶體；下載由使用者明確啟動。它不宣稱安排出最公平的休息時間，也不代表主客場場地。

正式網域待主代理的發布流程決定；M1 預覽必須 `noindex`。本工具尚未實作，不能把規格或 oracle 當成通過驗收。
