# 食譜份量換算專案規則

本產品目前只有 SPEC_ONLY 文件。根 AGENTS.md、Windows 安全契約和 Gloss Tools 家族交付條款持續適用；不得把要求模型值當成實際執行模型身份。

## 所有權和路徑

- M1 僅修改本產品 TASKS.md 列出的路徑。
- 證據限孵化器根 .runs/recipe-scaler/，不可寫食譜個資或使用者輸入。
- M2 staging 限 .runs/github-publish/glossquote-labs-recipe-scaler/，須等主代理明確放行。
- 不改根 git、共用首頁、兄弟產品、Cloudflare、DNS 或環境變數；不讀憑證或瀏覽器保存資料。
- 離線 Node.js ESM 和內建模組；除明確授權外不新增依賴。

## 產品不變條件

- 數量只接受 ASCII 十進位文字與最多 3 位小數，按 BigInt 有理數縮放；不使用浮點近似或 Number 作金額/數量算法。
- 原份數/目標份數皆 1–1000；食材最多 50 列。每列都要完整或切換成「適量」，不可跳過半空列。
- 不轉換 g/ml/cup 等單位；不換算時間、溫度、營養、卡路里或醫療建議。
- 「適量」是不縮放的原文字；不得嘗試推算。
- 任何欄位、列順序、列增刪、份數或適量狀態的編輯立即清除結果並停用複製。
- 沒有上傳、持久化、帳號、分析或外部網路。輸入只在本頁記憶體中。
- 使用 textContent 呈現任何名稱/單位；不把輸入拼成 HTML。

## 停止條件

若遇到算法案例矛盾、需要單位轉換或分數輸入、想更改精度/舍入規則、加入存檔/匯入/營養服務、加依賴、讀秘密或修改允許路徑，先停並回報主代理。
