## 使用者與工作

主持人、老師或召集人從聊天中收集每位參與者在同一天可出席的時段，再手動輸入共同時區／地點描述、每人的可用區間和會議長度。工具找出所有人都能出席、且足以容納完整會議的連續時間窗口。每段窗口同時標明最晚開始時間，讓召集人能直接比較候選時段。

MVP 一句話：在瀏覽器記憶體中整理 2–20 人的同日空檔，計算每位參與者都可用的會議窗口，不讀行事曆、不轉換時區、不替人聯絡。

## 價值與範圍

- 參與者的區間可重疊或相接；工具會先合併，再求所有人共同可用的連續區間。
- 不符合最短會議長度的交集會被排除；沒有合適交集是正常的空結果。
- 草稿和結果只存在目前頁面的記憶體。沒有帳號、雲端、同步、分析、外部 API 或使用者資料網路請求。
- 難度：中等。需正確處理精確輸入、多人區間合併／交集、雙語介面、鍵盤可操作的動態列和嚴格清除生命週期。
- 執行時零第三方依賴；以原生 HTML、CSS、瀏覽器 ESM 和 Node.js 24+ 內建模組開發及測試。

## 非目標

MVP 不連接或讀取行事曆，不傳送邀請、訊息或郵件，不解析自然語言空檔，不猜測共同時區，不做時區或夏令時間換算，不處理跨午夜區間，不提供多數決或「最佳」時間，不建立帳號／保存／分享 URL，不使用雲端或第三方服務，也不提供原生剪貼簿或下載按鈕。

## 使用環境限制

頁面需支援手機窄螢幕和大量動態輸入列。使用者自行輸入的時間是 ASCII HH:MM；行動裝置的數字鍵盤只是提示，無法保證鍵盤或輸入法只送出 ASCII。輸入欄須容許 IME 組字，不在組字中途覆寫文字；提交時依嚴格規則驗證。使用者可離線使用已載入的靜態檔案，但本規格不承諾快取行為或「永久離線」可用性。
