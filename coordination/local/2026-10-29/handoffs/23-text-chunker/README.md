# 文字分段與字數限制

狀態：SPEC_ONLY（2026-10-13）。本資料夾只有規格；實作、測試、GitHub、正式主機和外部驗收都是 NOT_RUN。進度見 [HANDOFF.md](HANDOFF.md)。

使用者把一篇太長的文字貼進工具，指定每段最多幾個 Unicode code points，選擇直接依嚴格上限切開，或在可行時優先切在換行處，然後逐段複製。適用情境包括把草稿分成容易審閱或貼上的小段；工具不宣稱符合任何社群、表單、AI 或通訊平台限制。

主要替代方案是手動分割、文字編輯器或其他分段網站。本工具的獨立價值假設是能保留原始文字、提供明確可重現的 code point 上限，並在瀏覽器本機處理。沒有搜尋量、平台相容性或使用者研究證據。

MVP 是雙語靜態頁；來源只留在分頁記憶體，明確說明重新載入會遺失。每段可單獨複製；提供每段完整文字預覽，不提供合併 TXT 下載。難度中：Unicode 計數、換行邊界、1000 段硬限制及剪貼簿等待競態需要精確驗收。無 runtime 依賴。

不做平台字數計算法、字形/emoji 圖形叢集計數、雲端上傳、帳號、保存、摘要、改寫、翻譯、分隔符插入、自動編號嵌入輸出或完整 TXT 拼接下載。資料和切出的原文不是伺服器請求。
