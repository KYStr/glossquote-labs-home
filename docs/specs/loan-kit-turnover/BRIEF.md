# 活動借用周轉檢查 / Loan Kit Turnover Check 製作簡報

預案 `spec-loan-kit-turnover-20261109` · 文件待獨立審查

活動承辦人有多種可重複借出的道具，已知各場領取與歸還時間。先把歸還後的整理時間也算在佔用內，找出在哪一段會缺幾件。

用桌面按道具查看借用時段、可用件數與短缺清單，從第一段短缺追到同時占用的借用代號。

在器材台用手機切換道具，先讀第一段短缺與需求，再展開對應的借用代號。

主要操作「找出道具短缺 / Check kit shortages」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
道具與借用清單   |   道具尖峰＋短缺時段清單

窄畫面（由上而下）
道具 → 借用 → 找出短缺 → 第一個短缺／全部區間
```

首個貫通案例用 `loan-kit-turnover.turnover-overlap`。4 件道具，A 借 2 件 00:10–00:30，B 借 3 件 00:30–00:50，整備 10 分。00:30–00:40 缺 1。

同日領取、歸還與各道具固定的周轉分鐘數，允許整理延伸到隔日最多兩小時。逐道具輸出尖峰、最多需增備件數與每個短缺區間。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/loan-kit-turnover/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
