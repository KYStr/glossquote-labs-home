## 概念備註查核

- 概念 #31 的尺寸例示「(4x6, 5x7, 8x10, A4...)」與 DPI 預設 300/240/150、自訂 DPI、預設 300，皆與本規格一致；尺寸表依任務簡報補全為 9 個（3×5、4×6、5×7、6×8、8×10、10×12、A5、A4、A3）。無概念與來源衝突需更正。
- 常數查核：1 in = 25.4 mm 為英寸的精確定義（127/5 mm），cm 換算 127/50 精確；A 系列 148×210、210×297、297×420 mm 為 ISO 216 標稱尺寸；相片尺寸英寸值為其標稱值。品質帶門檻（300／200／150）在 SPEC 中明示為一般觀看距離的常見經驗值、非業界標準，不冒充來源標準。

## Fixture 推導（雙重獨立計算）

全部 15 個成功結果先由作者依 SPEC 釘版規則以方法 A 推導，再以方法 B 獨立重算，逐值深度比對 **0 不一致**；10 個錯誤案例依釘版驗證順序（SCHEMA → mode ENUM → 欄序 pixelsW → pixelsH → dpi → sizeId，欄內容量 → UNICODE → EMPTY → 文法 → RANGE／ENUM，未啟用欄只查容量）手工判定；3 個 controller 案例沿用本組固定狀態語義。

- 方法 A：Python `fractions.Fraction` 精確有理數實作，尺寸表以 mm 有理數（英寸尺寸 ×127/5）建立，捨入為 `floor(x·10^k + 1/2)/10^k` 在有理數上執行，進位為有理數 ceil。
- 方法 B：Node.js 以 BigInt 分子／分母對另行實作（含獨立的小數字串剖析與以縮放整數 `floor((2n + d) / 2d)` 實作的四捨五入），與方法 A 程式路徑完全不同。
- 手算抽核（紙筆算術，與兩法一致）：
  - `need-a4-300`：長邊 297×5/127 = 1485/127 in，×300 = 445500/127 = 3507.87… → 進位 3508；短邊 1050/127×300 = 315000/127 = 2480.31… → 2481；3508×2481 = 8,703,348 → 8.70 → 8.7 百萬像素。
  - `need-a5-300-ceil` 短邊：740/127×300 = 222000/127 = 1748.03… → 進位 1749（四捨五入會給 1748，此案例即用來釘死 CEILING）。
  - `check-4k-a4`：長邊 3840×127/1485 = 487680/1485 = 328.404… → 328.4；短邊 2560×127/1050 = 325120/1050 = 309.638… → 309.6；小邊為短邊，309.6 ≥ 300 → excellent。
  - `max-24mp-300` 的 A3 列：長邊 DPI = 6000×127/2100 = 362.857… → 362.9；符合判定 需求長邊 ceil(2100/127×300) = ceil(630000/127) = ceil(4960.63…) = 4961 ≤ 6000、需求短邊 3508 ≤ 4000；A3 面積 420×297 = 124,740 mm² 為全表最大 → bestFitSizeId。
  - `check-band-200-exact`：1400/7 = 200、1000/5 = 200，有效 DPI 恰 200.0 → good（含下限）；`check-band-199-9`：1399/7 = 199.857… → 199.9 < 200 → acceptable。
  - `check-band-rounded-300`：A5 短邊 1748×127/740 = 221996/740 = 299.9946…，四捨五入為 300.0 → excellent；若改以未捨入值判定會落 good，此案例即為「品質帶以捨入後有效 DPI 判定」的區分案例。
  - `max-exact-4x6`：1800×1200 在 300 DPI 恰等於 4×6 需求（等號符合）；8×10 列有效 DPI = min(180, 150) = 150 → acceptable（含下限）。
- 捨入餘裕：全部成功案例的未捨入值與其捨入邊界的最小距離為 `max-24mp-300` 的 maxHeightIn（4000/300 = 13.3333…，邊界 13.335，距 0.0017 in）——因核心釘版精確有理數，此餘裕不構成風險；進位案例的最小整數餘裕為 1748.03…（距下整數 0.03）。無任何 fixture 值恰落在輸出精度的四捨五入恰半點上；恰半進位規則仍在 SPEC 釘版供實作遵循。
- 品質帶以「捨入後」有效 DPI 判定為釘版規則，`check-band-rounded-300` 為其區分案例（見上）。作者另驗算 200 帶界：九個尺寸的任一邊都不存在使未捨入有效 DPI 落入 (199.95, 200) 開區間的整數像素數，故 200 帶界上無區分案例，此為已揭露的覆蓋界限。
- fixtures.json 為 compact JSON、object keys 依 UTF-16 code units 遞迴排序；`err-unicode` 的未成對 surrogate 以 JSON 跳脫 `\ud800` 寫入，寫入後已重新剖析回讀驗證（值與案例數 28 一致）。
