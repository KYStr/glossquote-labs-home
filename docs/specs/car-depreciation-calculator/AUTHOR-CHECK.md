## 概念對照與釘版決定

- Run 5 概念 #27 原文寫兩種方法、費率表放在定率遞減之內；委派任務書明定三種模型並列。本文件依任務書釘版：`declining`＝單一固定年率的定率遞減；`straight`＝直線法至殘值下限；`table`＝逐年費率表（預設 20/18/15/12/10/8/8/6/6/5%，明示為常見二手車經驗法則示意值、非官方或鑑價機構標準，揭露原文釘版於 SPEC userFlow）。未更動概念的實質（同一組費率、同一直線＋下限），僅把費率表升為獨立模型以符合任務書。
- 捨入鏈釘版（任務書要求二選一並在差異重大時以案例釘住）：每年年末估值由「前一年已捨入的年末估值」迭代，不用未捨入閉合式。差異案例 `rounding-chain-pinned`：購入價 15、費率 10%、3 年，捨入鏈給 14→13→12；閉合式 15×0.9³＝10.935→11。兩者第 3 年差 1 元，案例已釘鏈結果 12。
- 金額釘版：整數新臺幣（無小數金額）；百分比輸入至多 2 位小數，先轉萬分率整數（ph），全程 BigInt 整數運算，`roundHalfUp(a,b)＝(2a＋b)÷(2b)` 整數除法，只在每年年末與下限／百分比輸出處捨入。
- 殘值下限三模型皆生效：`floored` 定義為未夾值 raw 嚴格小於 floorValue；恰等於下限（如 `straight-floor-before-life` 第 10 年）floored=false，次年起 raw 跌破才為 true。
- 費率表長度規則釘版：逐年表長度恆等於 `years`；行數不足時最後一行費率重複套用（`table-repeat-last`），行數多餘時超出列不使用但仍逐行驗證（`table-half-used`）。
- 估值揭露與經驗法則揭露皆雙語釘版原文（SPEC userFlow），常駐結果旁。

## 雙推導核對（手算／逐步 vs 獨立腳本）

第一法：作者以整數乘法逐步手算下列主案例（節錄關鍵步驟）。

第二法：獨立 Python 腳本（不共用產品程式）以兩種實作重算全部案例——(A) Fraction 精確有理數、`floor(x＋1/2)` 捨入；(B) SPEC 的整數公式 `(2a＋b)÷(2b)`——只讀 fixtures 的 input，輸出與 fixtures 的 expected 逐欄深度比對，並驗證 A 與 B 彼此一致；controller 案例另驗其 lateResult／錯誤與 `declining-basic` 核心結果及重設預設值一致。結果：14 核心＋3 controller 全數通過（TOTAL FAILURES: 0）。手算初稿曾有一處謄寫錯誤（straight-basic 第 3 年折舊誤寫為年末值），已於比對前修正並經腳本確認。
