# 優惠比價 / Deal Comparator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-deal-comparator-20261121`

消費者在賣場貨架前，同一款咖啡豆同時有買二送一、八折、折 30 元、三件 360 元四種寫法不同的優惠，手上只有手機和架上的標價，無法直接看出哪一種最划算。本工具把每個方案換算成統一單位價（每 100 g／每 100 mL／每件）再排名，告訴使用者哪一個方案真正最便宜、便宜多少。

MVP 範圍。同一商品 2–4 個優惠方案，四種型別（買 N 送 M、百分比折扣、定額折價、組合價）正規化成統一單位價再排名。非目標為單一商品折扣鏈、不同商品之間的比較、標價單位價的直接比較、即時價格查詢、把結果當商家報價保證。

首個可觀察案例。買二送一勝出，其餘三案單位價同為 24.00 以總價再以順序決勝負（`buy-n-get-m-wins`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
