# Word and Character Frequency Counter — preparatory BRIEF v0.1

Specification documentation only; no product claim, readiness event or implementation. Full normative contract is SPEC.md.

## 1. Goal
Writers, translators, teachers and researchers paste a draft, a transcript or a corpus sample and ask a simple question: what do I actually say most? Success: the user pastes text (English, Traditional Chinese, or mixed) and immediately sees a ranked frequency table computed by stated, reproducible rules — word counts for space-delimited languages, character and bigram counts for Chinese runs (with the honest explanation that Chinese has no spaces so "words" are not directly countable without a segmenter) — can filter stopwords and rare items, and exports the table as CSV for real work elsewhere.

## 2. Scope and functional distinction
Input up to a stated cap (200,000 characters). Tokenisation is normative and displayed on the page: word runs — maximal sequences of Unicode letters/digits **outside the CJK classes** (Latin, Greek, Cyrillic and all other scripts; not a Latin-only category) — are split into words allowing internal apostrophes (`don't` is one word; leading/trailing apostrophes trimmed), compared case-insensitively under **Unicode simple case folding** (the CaseFolding C+F mappings, pinned in the SPEC — explicitly not `toLowerCase()`, so Greek Σ/ς/σ merge) with the display form taken from the most frequent casing; numbers are tokens too but can be excluded by option. CJK runs (Han characters) are counted per character and as overlapping bigrams (two-character pairs), both tables offered, because bigram counts are the useful segmentation-free signal; kana and Hangul runs are counted per character with a note. Mixed text is processed run by run under these rules. Options: minimum count, minimum word length (Words table), stopwords on/off with a bundled editable list (common English function words and common Chinese single characters/particles — the list ships as visible data the user can edit in place for the session), include/exclude numbers. Output: ranked table (rank, item, count, percentage of total tokens) with deterministic tie-breaking (count descending, then first-occurrence order), totals (total tokens, unique items), top-N display with the full table scrollable, CSV export of the complete current table. Excluded: uploading files, lemmatisation/stemming (stated — `run` and `running` are different words here), sentiment or readability scoring, cloud corpora, and saving the text or the lists.

Existing tools: Text Workbench transforms text; Text Diff compares two texts; neither tokenises or counts. Subtitle tools handle timed text, not frequency. Initial catalog/spec/task scope contains no frequency counter; fresh registry/path/draft check remains mandatory before admission. Fixtures are tiny hand-countable texts in both languages plus one mixed paragraph, with counts derived by hand in the SPEC.
