# Aspect Ratio Calculator — preparatory BRIEF v0.1

Specification documentation only; no product claim, readiness event or implementation. Full normative contract is SPEC.md.

## 1. Goal
Anyone resizing a video, cropping a photo, setting a canvas or spec'ing a screen meets the same small arithmetic: what ratio is 1920×1080 really, and if the width must be 1000, what height keeps 16:9? Success: the user enters either a width×height pair or a ratio, and immediately sees the simplified ratio (exact, by gcd — not a guessed preset), the decimal form, and the solved missing dimension for any target width or height, shown both rounded for use and as an exact fraction when it does not terminate. The tool is honest about near-misses: 1366×768 simplifies to 683:384, *not* 16:9, and 2560×1080 is 64:27, not 21:9 — a calculator that rounds those into the famous ratios would be lying at exactly the moment it was consulted.

## 2. Scope and functional distinction
Three modes, one arithmetic core: (a) Dimensions → ratio: integer width/height (1–100,000) simplified by gcd, plus decimal ratio (4 places) and height-as-percentage-of-width; (b) Ratio + one dimension → the other dimension: ratio parts are positive numbers with up to 3 decimal places, scaled by 1000 and simplified before solving, so 2.39:1 is exactly 239:100 and 21:9 displays simplified as 7:3; the solved value displays rounded to 2 decimals and, when the exact value is a non-integer fraction, as a reduced fraction too; (c) Presets: a closed list (1:1, 3:2, 2:3, 4:3, 3:4, 5:4, 16:9, 9:16, 16:10, 21:9, 1.85:1, 2.39:1) that fills mode (b) — presets are inputs, never outputs: a computed ratio is never "snapped" to a preset, though the page may note the nearest preset and its exact difference when one is close. Excluded: image resizing/cropping itself, file handling, DPI/print sizing, CSS generation beyond showing the ratio values, and saving entries.

Existing tools: Print Size converts between pixels and physical print dimensions at a DPI (units and printers); Box Fit / object-fit geometry concerns fitting content into a container (placement and cropping geometry). This tool is pure ratio arithmetic — simplification, equivalence and missing-dimension solving — with no units, no images and no layout. Initial catalog/spec/task scope contains no aspect-ratio calculator; fresh registry/path/draft check remains mandatory before admission. Fixtures are computed in the SPEC and re-derived during drafting, including the two famous near-miss resolutions above.
