# 澆水補壺路線 / Watering Can Refill Route 製作簡報

預案 `spec-plant-watering-route-20261109` · 文件待獨立審查

有人已量好每盆要用的水量、知道澆水順序和沿途水龍頭，想用一把水壺少跑幾次補水。輸出是原路線上的補水位置、應補量及每盆後剩量。

桌面可按實際走向整理盆栽或苗盤代號並標記水龍頭。查看哪一段水量超出水壺容量。

在花園用手機按路線逐盆讀取，補水停點用文字標示，列出到站所需補到滿的量。

主要操作「排出補水點 / Plan refill stops」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
壺量／路線編輯   |   澆水路線與補水標記

窄畫面（由上而下）
壺量 → 路線各盆 → 排出補水點 → 逐站讀量
```

首個貫通案例用 `plant-watering-route.farthest`。1,000 ml 壺，A、B、C、D 各 350、300、300、500 ml，B、C 盆前有水。只在 C 前補 650 ml。

固定順序、出發滿壺，指定盆前可補到滿。每盆一次倒完、整毫升計量。在可完成的前提下用最少補水站。無法完成時顯示已可完成前綴與首個缺量。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/plant-watering-route/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
