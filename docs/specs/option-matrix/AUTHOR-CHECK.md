## 有限自查事實

1. 規格比較了登記來源中的既有用途，並實讀最相近的CSV整理、文字套版、隨機分組、權重決策與名單比對規格。笛卡兒積不是選欄、模板替換、分組、排名或集合合併；比較範圍不包括未登記私人工作。
2. 正文外部來源均使用固定40字元GitHub commit；包含brief、主頁baseline、catalog、registry與上述五份相近規格。原文件連結已逐一官方讀回，來源指紋保留在規格比較段落；不是產品已完成的證據。
3. 八節與九品質面向完整列出。公開文件不含真實使用者輸入、私人檔案路徑、憑證或內部對話識別；未分配新origin、repo、服務或費用。
4. 編寫時已把不適合每維≤12限制的「51列翻頁」例改為5×12=60，第二頁10列；2MiB輸出上限明示合法列數不保證最長字串亦可匯出。這是規格編寫修正，不是既有產品bug。
5. 2×3 expected由六個tuple手列；2000=10×10×10×2。所有容量錯誤整份拒絕，不截取前2000列；CSV風險停用與JSON備援分開。
