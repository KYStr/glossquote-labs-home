# 聚會回合計分表 / Game Night Scorecard 製作簡報

預案 `spec-game-night-scorecard-20261109` · 文件待獨立審查

朋友在同一場桌遊聚會輪流記分，要依約定的高分或低分勝出、棄掉固定場數最差回合、用最佳保留回合決勝。要能從結果回查被棄哪一局。

桌面按已打回合輸入每人分數，旁邊顯示總分、最佳保留分、棄局與同名次。

桌邊手機以回合群組逐人填分，完成後用排名列展開棄局。輸入錯誤可定位哪一人的哪一回合。

主要操作「更新回合排名 / Update round standings」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
參加者與回合分數格   |   排名／保留總分／棄局

窄畫面（由上而下）
人員與規則 → 逐回合分數 → 排名 → 展開棄局
```

首個貫通案例用 `game-night-scorecard.high-tiebreak`。高分制棄一局後，A 與 B 保留總分同為 16。A 的最佳單局 10 優於 B 的 8。

2–12 人、1–30 個已打回合、整數正負分、高／低分勝及最多棄三局。每人各自棄最差，排名依保留總分再最佳保留單局。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/game-night-scorecard/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
