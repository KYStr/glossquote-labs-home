## 雙重推導（每一個數字）

方法 A（Decimal）：Python Decimal，精度 50 位，年金因子以 Decimal 冪次 `(1+i)^(-n)` 計算，最高貸款向下取整（ROUND_FLOOR），上限金額與比率以 Decimal `ROUND_HALF_UP` 取整。
方法 B（獨立重算）：另寫的實作，全程精確有理數（`fractions.Fraction`），整數 half-up 公式 `(2p+q)//(2q)`，年金反推以精確分數 `(1-(1+i)^(-n))/i` 後取整數商（精確 floor），結構與方法 A 不同。
兩法對 10 筆有效核心案例的每一個數字逐位一致後，才寫入 fixtures.json。另以獨立腳本核對不變式：以年金公式（half-up 取整）重算最高貸款的月付，10 案皆恰等於最高月付（恆不超過），且每案皆滿足 maxHomePrice = maxLoanAmount + downPayment。

## 手算驗證（字面算術，非腳本輸出）

手算以對數／指數級數求年金因子（`ln(1+x) ≈ x − x²/2 + x³/3`，`e^y` 以級數展開），精度約 6 位有效數字；手算最高貸款與腳本值差 ±3 元以內（手算取整誤差），精確整數取兩法一致的腳本值。零利率與無貸款額度兩案為精確手算。

- 共用因子（利率 2%、30 年）：i = 1/600 ≈ 0.00166667；ln(1+i) ≈ 0.00166667 − 0.00000139 ≈ 0.00166528；×360 = 0.599501；e^0.599501 ≈ e^0.6 × e^−0.000499 ≈ 1.822119 × 0.999501 ≈ 1.821210；倒數 ≈ 0.5490857；因子 = (1 − 0.5490857) × 600 = 270.5486。
- `typical-taipei`：月收入 1,200,000/12 = 100,000；前端 100,000×28% = 28,000；後端 36,000；M = 28,000，前端綁定。L ≈ 28,000 × 270.5486 = 7,575,361（手算），腳本 7,575,358，差 3 元。房價 = 7,575,358 + 2,000,000 = 9,575,358。兩比率皆 28.0%。
- `debts-bind-back-end`：前端 28,000；後端 36,000 − 15,000 = 21,000；M = 21,000，後端綁定。L ≈ 21,000 × 270.5486 = 5,681,521（手算），腳本 5,681,518，差 3 元。房價 7,681,518。前端比率 21,000/100,000 = 21.0%，後端比率 36,000/100,000 = 36.0%。
- `zero-rate`（精確手算）：月收入 900,000/12 = 75,000；前端 75,000×28% = 21,000；後端 75,000×36% − 5,000 = 22,000；M = 21,000，前端綁定。L = 21,000 × 240 = 5,040,000；房價 6,040,000。前端比率 28.0%；後端比率 26,000/75,000 = 34.666…% → 34.7%。與 fixtures 逐位一致。
- `one-year-term`：月收入 600,000/12 = 50,000；前端 14,000；後端 18,000；M = 14,000。i = 0.005；ln(1.005) ≈ 0.005 − 0.0000125 ≈ 0.00498754；×12 = 0.0598505；e^0.0598505 ≈ 1 + 0.0598505 + 0.0017910 + 0.0000357 ≈ 1.0616772；倒數 ≈ 0.9419053；因子 = (1 − 0.9419053)/0.005 = 11.61894。L ≈ 14,000 × 11.61894 = 162,665.2 → floor 162,665，與腳本逐位一致。房價 662,665。
- `high-rate`：i = 1/150 ≈ 0.00666667；ln(1+i) ≈ 0.00666667 − 0.00002222 ≈ 0.00664454；×360 = 2.392034；e^2.392034 ≈ 7.389056 × 1.479982 ≈ 10.9357；倒數 ≈ 0.0914437；因子 = (1 − 0.0914437) × 150 = 136.2834。L ≈ 28,000 × 136.2834 = 3,815,935（手算），腳本 3,815,937，差 2 元。房價 5,815,937。
- `zero-down-payment`：與 typical-taipei 同一因子與月付，L = 7,575,358；頭期款 0，房價 = 7,575,358。
- `debts-exceed-back-cap`（精確手算）：月收入 50,000；前端 14,000；後端 18,000 − 20,000 = −2,000；M = max(0, −2,000) = 0，後端綁定，affordable 為 false。L = 0；房價 = 500,000（= 頭期款）。前端比率 0.0%；後端比率 20,000/50,000 = 40.0%。與 fixtures 逐位一致。
- `equal-caps`：前端 = 後端 = 30,000；M = 30,000，bindingCap 為 equal。L ≈ 30,000 × 270.5486 = 8,116,458（手算），腳本 8,116,455，差 3 元。房價 10,116,455。兩比率皆 30.0%。
- `custom-caps`：月收入 100,000；前端 25,000；後端 40,000 − 10,000 = 30,000；M = 25,000，前端綁定。i = 0.0025；ln(1.0025) ≈ 0.0025 − 0.00000313 ≈ 0.00249688；×240 = 0.599251；e^0.599251 ≈ 1.822119 × 0.999251 ≈ 1.820755；倒數 ≈ 0.5492226；因子 = (1 − 0.5492226)/0.0025 = 180.3110。L ≈ 25,000 × 180.3110 = 4,507,775（手算），腳本 4,507,772，差 3 元。房價 6,507,772。前端比率 25.0%；後端比率 35,000/100,000 = 35.0%。
- `income-not-divisible`：月收入 1,000,000/12 = 83,333.33 → 83,333；前端 = round(1,000,000 × 28/1200) = round(23,333.33) = 23,333；後端 30,000；M = 23,333。L ≈ 23,333 × 270.5486 = 6,299,910 + 12,800.5 = 6,312,710.5 → 6,312,710（手算），腳本 6,312,708，差 2 元。房價 7,812,708。前端比率 23,333/83,333 = 27.9996% → 28.0%；後端比率同為 28.0%。

## 概念筆記 vs 釘死的規則

- 概念筆記只列輸入與產出（收入、頭期款、利率、年期、其他債務、DTI 上限 → 最高房價＋最高月付），未規定上限金額的取整次序、最高貸款的取整方向、綁定判定、無貸款額度的結果形狀與比率小數位數；本 SPEC 全部釘死：上限金額以精確有理數一次 half-up 取整、最高貸款向下取整（保守）、bindingCap 為 front/back/equal（M 為 0 時仍判定）、affordable 為 false 時仍成功回傳（房價等於頭期款）、比率為 1 位小數 half-up。
- 概念筆記未提月付是否含稅費／保險；本 SPEC 釘死月付只計房貸本金加利息（P&I），稅金、保險、管理費列為非目標並寫進試算聲明與 FAQ。
- 概念筆記寫「DTI 上限（釘版規則，例如 28/36）」；已對照具名來源核實並更正見下節。

## 來源核實與更正

- 28/36 經核實為傳統經驗法則，不是法定上限：CFPB「What is a debt-to-income ratio?」（consumerfinance.gov）定義 DTI 為全部每月債務還款除以稅前月收入，並明言「Different loan products and lenders will have different DTI limits」；CFPB Your Home Loan Toolkit 稱 28% 為房貸經驗法則；Cornell LII（Wex）同樣記載 28%/36% 為傳統說法。本 SPEC 以 28/36 為預設值、可調範圍前端 10–50%、後端 20–60%，並在 SPEC 與 FAQ 明言不是法定上限。
- 舊的 43% 數字已不再是法定上限：原 General QM 的 43% DTI 上限已由 CFPB 2020 年 12 月 General QM Final Rule 改為價格制標準，強制適用日延至 2022 年 10 月 1 日。本 SPEC 不以 43% 為上限或預設，並在 SPEC 寫明此點。
- 各方案上限（Fannie Mae Selling Guide B3-6-02 人工核貸 36%、補償因素 45%、Desktop Underwriter 50%；FHA 31/43；VA 41% 參考值加剩餘收入；USDA 29/41）僅作背景寫進 SPEC，不進模型；可調範圍覆蓋上述各方案，但不宣稱任一方案的核貸結果。
- 取整次序的例證（SPEC implementation 節）：年收入 1,000,006 元時，精確前端上限為 23,333 元，先取整月收入 83,334 元再乘 28% 會得 23,334 元，差 1 元——故一律以精確有理數一次取整為準。此例以 Fraction 獨立驗算過。
