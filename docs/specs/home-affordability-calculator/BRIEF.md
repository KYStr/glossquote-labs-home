# 購屋能力試算 / Home Affordability Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-home-affordability-calculator-20261121`

準備買房的人，先輸入年收入、頭期款、房貸利率、年期與每月其他債務，依 28/36 負擔比率（預設前端 28%、後端 36%，可調）算出最高月付、最高貸款與最高房價，再決定要看哪個價位的房子。

MVP 範圍。固定年利率的等額本息反推：月收入取年收入除以 12，前端上限為月收入乘以前端比率，後端上限為月收入乘以後端比率再扣其他債務，取較小者為最高月付，再以年金公式反推最高貸款，加頭期款得最高房價。非目標為稅費／保險／管理費、房貸成數限制、逐月還款表顯示、即時利率查詢、多物件比較、賣房成本、把結果當財務建議或銀行核貸保證。

首個可觀察案例。典型情境：年收入 120 萬、頭期款 200 萬、利率 2%、30 年、無其他債務，最高月付 28,000 元、最高房價 9,575,358 元（`typical-taipei`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
