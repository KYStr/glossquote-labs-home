# 蛋白質攝取量計算機 / Protein Intake Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-protein-intake-calculator-20261109`

剛開始規律重訓的上班族，站在健身房更衣室用手機查「體重 70 公斤到底要吃多少蛋白質」。手邊只有自己的體重和訓練目標，網路文章各說各話（每公斤 1.2 到 2.2 克都有），也沒人告訴他分到三餐或四餐每餐大概是多少。他需要一個固定係數表算出的每日目標克數、上下區間，以及每餐分配，加總必須剛好等於每日目標，方便他照著準備餐點。

MVP 範圍。體重（公斤）乘上依目標／活動固定的 g/kg 係數（久坐 0.8、一般活動 1.0、規律運動 1.2、肌力訓練 1.6、高強度／備賽 2.0、減脂保肌 2.2，另可自訂係數），輸出每日目標克數、係數 ±0.2 的區間，以及 3 餐／4 餐的每餐分配（餘數規則固定，合計等於每日目標）。非目標為醫療建議或診斷、食物資料庫與菜單建議、熱量／TDEE 計算、體重或攝取紀錄追蹤、依疾病／懷孕／年齡調整係數。結果旁固定顯示一般營養資訊聲明。

首個可觀察案例。肌力訓練 70 公斤、四餐（`strength-example`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
