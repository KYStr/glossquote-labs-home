## 第二種方法：獨立 script 重算

以 Python 獨立實作同一模型（字元類別、池、扣分、觸頂、等級、破解時間格式化）重算全部 12 個核心案例，輸出與 fixtures.json 逐欄比對一致。Script 未使用產品程式，亦未由 fixture 反推。手算與 script 不一致之處有三，皆以 script 為準修正 fixture（見下節）。

## 手算錯誤更正（第二種方法抓出）

1. `sequence-weak`（`abcd1234`）：手算初稿只計 SEQUENCE −8，得 33.4。重算指出 `1234` 同時是 QWERTY 橫列 `1234567890` 的子字串，依 SPEC 兩項皆扣，KEYBOARD_WALK 再 −8，總扣 16，最終熵為 **25.4**（非常弱）。SPEC 已明寫此雙重扣分規則。
2. `non-ascii`（`Pässwörd€2024!`）：手算初稿數成長度 13。逐字重數為 14（P、ä、s、s、w、ö、r、d、€、2、0、2、4、!），基礎熵 14×6.9773＝97.6820→**97.7**，最終熵 **91.7**。
3. `common-keyboard`（`qwerty123`）：手算初稿將線上破解時間寫成「<1 秒」。重算：2^6.5＝90.5 次猜測，90.5/10＝9.05 秒→**「9.1 秒」**。
