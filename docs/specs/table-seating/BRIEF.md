# 同行群分桌 / Party Table Seating 製作簡報

預案 `spec-table-seating-20261109` · 文件待獨立審查

小型聚會接待員有數張固定桌和同行群。需要在不拆群的前提下，依座位容量、無階通行桌及指定桌得到一份可執行分桌表。

桌面可從場地桌單輸入容量與無階通行資訊，旁邊保留同行群短名與指定桌。成果以桌為單位顯示已坐與剩餘座位。

入口志工以手機看每桌的群名與人數，需要換桌時改指定欄後重算。清單可在同一頁上下掃視。

主要操作「安排同行群分桌 / Seat parties」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
桌容量清單／同行群表   |   逐桌配置＋剩餘座位

窄畫面（由上而下）
桌子 → 群組 → 安排分桌 → 逐桌清單
```

首個貫通案例用 `table-seating.backtrack`。先輸入可無階到達的四座桌與普通四座桌。當三人群先佔無階桌會阻擋後面的兩人群，搜尋回退，保留無階桌給有需要者。

最多 8 個完整同行群、4 桌。群可要求無階通行桌或指定桌。回傳按輸入序可重現的一份完整配置，或完整搜索後的無解提示。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/table-seating/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
