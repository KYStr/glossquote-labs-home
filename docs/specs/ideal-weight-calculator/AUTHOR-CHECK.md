## 查重與範圍界線

- 已讀本 repo 既有 `docs/specs/bmi-tdee-calculator/`（上層簡報稱其為 bmi-calculator，實際 slug 為 bmi-tdee-calculator，以 repo 為準）：該案收體重與年齡，輸出 BMI 值／WHO 分類／BMR／TDEE，健康範圍僅為輔助顯示。本案不收體重與年齡，只做「身高 → 體重」的反向問題，主輸出為四個具名公式並列。功能不重複，差異寫進 BRIEF 與 SPEC scope。
- 簡報轉述「bmi-calculator 使用台灣國健署 18.5–24 帶」與 repo 實況不符，先予更正：該案分類與範圍採 **WHO 帶**（正常 [18.5, 25)，範圍上端以 25 的排他界值顯示），另以資訊行揭露亞太行動點 23.0／27.5，並未採國健署帶。本案的處置：顯示範圍依上層指示釘 **WHO 公布的 18.5–24.9** 並標明 WHO；國健署成人健康體位帶（18.5 ≤ BMI < 24）只在 FAQ 以固定文字揭露關係，不作顯示範圍。三套界值（WHO 24.9／WHO 分類上界 25／國健署 24）互不冒充。

取捨一（Hamwi）：市面多數計算器用 kg 約略常數 48 + 2.7／45.5 + 2.2。原始發表為磅式；依「衝突時從原始發表值」原則，本案釘版磅原生計算後以 0.45359237 精確換算。兩者在 E = 10 英吋（男）時：磅原生 = 166 lb = 75.2963… kg → 75.3；約略式 = 75.0，相差 0.3 kg，不是顯示誤差而是常數差。故 fixtures 特別以 `female-147-below-five-feet`（Hamwi 40.5；約略式會給 40.8）與 `male-152-4-five-feet`（106 lb → 48.1）釘住此選擇，reviewer 可直接驗算。

取捨二（5 英尺以下）：有來源主張公式僅定義於 ≥ 5 英尺、以下應顯示不適用；多數臨床計算器（含常見 Devine 實作）則沿直線增減。本案釘版直線延伸（E 為負照算），理由：輸出保持全域連續、規則單一可驗，並以 FAQ 揭露公式原以 5 英尺前後成人為對象、矮個子結果屬粗略參考。身高下限 130.0 的另一理由：130 cm 時四式女性最低值（Devine 25.2 kg）仍為合理正數，再低則 Devine 女性線逼近不合理值。

取捨三（目前體重）：上層允許「清楚次要才可加，否則省略」——本案省略。不收體重使「距離範圍還差幾公斤」無從產生，也就不需要第二套判讀語言；要判讀目前 BMI 的使用者由 bmi-tdee-calculator 承接。`schema-extra-key` 案例（送入 age）把「不收年齡／體重」釘成可測行為。

取捨四（骨架調整）：Hamwi 原文的 ±10% 骨架建議僅附於該一式；其餘三式無對應規則，不存在可引的統一標準可套四式，故列非目標並於 FAQ 揭露，不提供調整欄位。

第二法（獨立重算）：另以 Python `fractions.Fraction` 精確有理數寫一份與手算獨立的驗證器（自行實作 SCHEMA → 逐欄 INPUT_LIMIT／UNICODE／EMPTY／文法／ENUM／RANGE 順序與全部公式），對 fixtures.json 的 16 個核心案例逐案深度比對：**16/16 完全一致**，含全部錯誤案例的 code／field。手算的 Hamwi 中間磅值與換算亦經此驗證器複核。

捨入邊界餘裕：全部成功輸出與最近的 .x5 捨入界線距離 ≥ 0.0124（最窄為女 147 的 Hamwi 40.5376，距 40.55 界線 0.0124），遠大於雙精度浮點誤差（約 1e-13 量級）；其中 low 三例（53.465／31.265／97.865）是精確十進值、在界線上方 0.015，精確算術實作必得釘版結果。英吋顯示（heightInches）同法核對（例：160 cm → 62.992126 → 63.0）。
