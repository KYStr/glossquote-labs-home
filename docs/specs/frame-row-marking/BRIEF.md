# 相框掛點定位 / Frame Row Marking 製作簡報

預案 `spec-frame-row-marking-20261109` · 文件待獨立審查

佈置者要在一段已量好的牆面掛一排不同寬高、掛鉤位置不同的相框。輸出是每一框的左上角與唯一掛點相對同一個基準角的讀數，便於用捲尺逐點標記。

桌面先抄下牆面可用寬、框外尺寸及實測偏心距，用列次序確定陳列。左右端一起納入等距留白，結果圖與毫米表互相對照。

手機放在牆邊，以直式單欄依序查看掛點 X、Y。逐列以基準角量尺。無相機權限或拖拉操作。

主要操作「算出牆上掛點 / Mark frame hooks」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
牆寬／對齊／相框列   |   比例牆帶圖＋掛點座標表

窄畫面（由上而下）
基準說明 → 牆寬 → 相框逐列 → 算出掛點 → X/Y 清單
```

首個貫通案例用 `frame-row-marking.center`。1,000 mm 牆上排兩框，中心對齊。顯示間距 166.7 mm，第二掛點距基準 683.3、70.0 mm。

支援單排框、等左右及框間留白、頂緣或中心高對齊、每框一掛點。可用上下移按鈕改列序。顯示不夠寬時的最少差額。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/frame-row-marking/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
