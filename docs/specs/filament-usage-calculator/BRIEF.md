# 3D 列印線材用量換算 / Filament Usage Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-filament-usage-calculator-20261109`

家裡用 FDM 印表機的使用者，切片軟體說下一件要 250 g 線材，手邊那捲 PLA 連軸秤起來 640 g；他只知道空軸大約 200 g，不確定剩下的料夠不夠印，也想順手知道這件的線材成本。手機或桌機打開本工具：選線徑 1.75 mm 與材料，輸入長度或重量即可互換；切到「線軸剩餘」輸入總重與空軸重，得到剩餘公克與公尺；切到「列印成本」輸入整軸價格與用量，得到成本。全部離線、當場算完。

MVP 範圍。線徑 1.75／2.85 mm、六種材料固定密度表、長度↔重量雙向換算、線軸剩餘估算、線材成本試算。非目標為讀取 G-code／切片檔、依擠出路徑或流量計算、支撐與裙邊估算、即時比價、幣別換算、儲存歷史紀錄。

首個可觀察案例。長度換重量（`length-pla-175`）：1.75 mm PLA、100 m → 298.3 g。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
