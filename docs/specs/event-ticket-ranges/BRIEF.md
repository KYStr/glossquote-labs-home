# 活動票本連號盤點 / Event Ticket Range Check 製作簡報

預案 `spec-event-ticket-ranges-20261109` · 文件待獨立審查

活動收桌時志工手上有多疊實體連號入場票，要和已知發放號段比對，找出哪些號碼缺失、在哪兩疊有重號及超出發放段的票號。

桌面按票疊輸入首尾，總覽同時看已覆蓋、缺號、重複張及超段張。點短區間再翻對應紙疊。

收票處以手機輸入印刷首尾號碼。結果的票號保留前導零、可從每段直接看到需要再點哪疊。

主要操作「核對票號區間 / Check ticket ranges」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
發放首尾／票疊列   |   缺號／重疊／超段與張數

窄畫面（由上而下）
位數 → 發放號段 → 票疊首尾 → 區間結果
```

首個貫通案例用 `event-ticket-ranges.mixed`。發放 0001–0010，三疊為 0001–0004、0004–0006、0008–0011。缺 0007，0004 重一張，0011 超段一張。

一個發放區間和最多 64 疊連續票段，統一固定寬度純數字。使用閉區間的實體張數，回缺段、重段與超段。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/event-ticket-ranges/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
