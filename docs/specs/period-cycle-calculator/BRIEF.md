# 生理週期計算 / Period Cycle Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-period-cycle-calculator-20261109`

使用者想安排旅行、運動賽事或就醫時間，手邊只有上次月經的開始日和自己平常的平均週期長度。輸入三個值即可看到本次週期與接下來三次月經的估計開始日、經期結束日、排卵日與易孕期，不必註冊、不必回報任何症狀，資料不離開目前頁面。

MVP 範圍。單一平均週期長度（21–35 天）與經期長度（1–10 天）的固定黃體期（14 天）估算模型；整數日曆日運算，結果為四個週期的日期表與固定格式報告下載。非目標為症狀／基礎體溫紀錄、多筆歷史週期平均、依實際回報調整預測、避孕指導、懷孕或疾病風險評估、提醒通知與任何資料儲存。

首個可觀察案例。28 天週期、上次開始日 2026-10-26：下一次月經估計 2026-11-23，本週期排卵日估計 2026-11-09，易孕期 2026-11-04 至 2026-11-10。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。所有日期僅為估計，本工具不能作為避孕依據，也不是醫療建議（完整聲明見 SPEC.md）。
