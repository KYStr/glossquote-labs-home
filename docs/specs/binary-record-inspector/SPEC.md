## goal

工程師拿到測試 fixture 的十六進位 dump 和欄位位置，需在寫解析器前驗證多個欄的 endian 和 signed 讀值。

- 桌面。桌面貼測試 header bytes 與欄位表，依 offset 對照同一組 bytes 的兩種 endian。
- 行動。手機檢查同事分享的短 dump，讀一欄 offset 和 signed decimal。

使用情境為設計假設。資料只保留在目前頁面草稿。

## scope

一段 hex bytes 及固定偏移的多欄整數描述，可重疊檢查同一片段。非目標為任意檔案或網路封包擷取、浮點、varint、位元欄、浮點 endian、自動推測格式、解密或修改 bytes。

已與 registry r807 的 130 份預案比對，最相近者的實質差異如下。

- 單整數 radix、定寬二補數，明排除 endian 檔案解析。此處解讀一段 bytes 的多個 offset、不同寬度和字節序。 [spec-integer-representation-20261101](https://github.com/KYStr/glossquote-labs-home/blob/3e93737ac8cf431d424a9814eea144ec10343a2c/docs/specs/integer-representation/SPEC.md)
- 整檔雜湊。這裡回報指定欄內容與整數值。 [spec-15-file-checksum](https://github.com/KYStr/glossquote-labs-home/blob/be197ea30d909b1353e7f77bdf16b1811ac41f71/coordination/local/2026-10-29/specs/15-file-checksum/SPEC.md)

判定規則由本文定義，無線上資料或外部服務依賴。

## userFlow

採 Gloss Tools Product App。遵守設計系統的 paper/ink、間距、焦點和斷點。寬版以輸入與結果相鄰，結果擁有最多空間。窄版依輸入、主操作、狀態、結果直排。首屏見主工作和常用設定，詳細格式用一層 disclosure。

- 欄位或說明「十六進位 bytes / Hex bytes」
- 欄位或說明「欄位名稱、偏移、型別 / Field label, offset and type」
- 「讀取指定欄位 / Read fields」是主要操作。「載入範例 / Load example」填入 [fixtures.json](fixtures.json) 第一個合成案例，明示範例並等待手動執行。
- 「來源 bytes 與整數讀值 / Source bytes and integer values」先摘要再列細節，長表在有 label 的區域捲動。超過 25 列採 25 列分頁、上下頁可鍵盤操作，完整匯出不截斷。成功才顯示「下載報告 / Download report」。文字可手動選取。

| 狀態 | 操作與結果 |
| --- | --- |
| empty | 初載／重設，無結果，提示輸入或載入範例。 |
| dirty | 任一輸入、選項、來源或範例改變，立即撤銷舊結果和下載。顯示「輸入已變更，請重新執行 / Input changed. Run again.」。 |
| busy | 明確執行時處理快照，顯示「處理中 / Working」及「取消 / Cancel」。無下載。編輯終止舊工作並回 dirty。 |
| success | 報告對應目前快照。空結果有說明。若含待修列，以文字及符號提示。 |
| error | 保留草稿，沒有結果。顯示本地化錯誤、欄位及適用列號。只有提交失敗才移焦首錯欄。 |
| cancelled | 保留草稿，終止並告知「已取消，可重新執行 / Cancelled. You can run again.」。舊結果仍無效。 |

「重設 / Reset」停止工作，復原預設 `{"hex":"","layout":""}` 並聚焦首來源欄。標籤不可只用 placeholder。用 aria-busy 和 polite 回報狀態，以 aria-describedby/aria-errormessage 連結錯誤。語言連結旁揭露切語或離頁會失去草稿。沒有登入或權限要求。頁面載入後可離線計算，Worker 失敗保留草稿供重試。

## inputsOutputs

核心 `run(input)` 為同步純資料轉換。參數含下列確切欄位的普通物件，只讀 own data。未知、缺欄、錯型別、accessor 皆 SCHEMA，field,row=null。JSON fixture 即介面。textarea 以 DOM 的 LF 值為準。明示檔案欄才處理原始 bytes。

- hex: string，最多 16,384 UTF-16 單元。只用 ASCII SP、HT、LF 分隔 token。每個 token 含一或多對 ASCII hex digits，不支援 0x、位址列或奇數 nibble，合計 1–4,096 bytes。
- layout: string，最多 4,096 UTF-16 單元，LF 1–64 列、去一個末尾 LF。每列 label HT offset HT type。label [A-Za-z][A-Za-z0-9_-]{0,23} 唯一。offset 為 0 或無前導零的 1–4 位 ASCII 整數。type 為 u8/i8 或 u/i + 16/32/64 + le/be，例如 i16le。

先容量、再 surrogate、再該欄文法，跨欄和逐列順序依下文。未另外指明時容量 INPUT_LIMIT、缺內容 EMPTY、超列 ROW_LIMIT、不成對 surrogate UNICODE。整份失敗回 `{ok:false,error:{code,field,row}}`，field 為欄位名或 null，row 為明示 1-based 來源列／操作序號或 null。成功僅為 `{ok:true,result}`。資源或 Worker 失敗用固定 INTERNAL/WORKER_ERROR，不回傳堆疊。

1. 先驗 hex 容量、Unicode、token 形狀，再驗 layout。空 hex/空 layout 為 EMPTY、奇數或未知 hex 字元 HEX_FORMAT、合計超量 BYTE_LIMIT。layout 欄數/label/offset 文法 LAYOUT_FORMAT。重複 label DUP_LABEL。未知 type TYPE。offset+width 大於 bytes.length BOUNDS，row 為 layout 原列。
2. byte index 從 0，8/16/32/64 位分別取 1/2/4/8 bytes。對 big endian 依 offset 正向，little endian 逆序，逐 byte 執行 n=(n<<8n)+BigInt(byte)，不使用 32-bit bitwise Number。unsigned=n。signed 若 n≥2^(bits−1) 就回 n−2^bits，否則 n。數值不捨入、不採 host byte order。
3. 各列 {label,offset,type,hex,value}，hex 按來源位元組順序，不按 endian 改寫，每 byte 兩位小寫連寫。value 是有符號或無符號的 ASCII 十進整數字串。結果 {byteCount,fields}。fields 依 layout 順序，合法重疊保留，不按 offset 排序。任何結構錯整份停止。

固定下載 `binary-record-inspector-report.json`。內容為 result 的 compact JSON、object own keys 按 UTF-16 code units 升序遞迴排列，array 順序不改，末尾一個 LF、UTF-8 無 BOM。字串用 JSON 字面轉義，不呼叫輸入的 toJSON。報告上限 2,097,152 bytes，超過 OUTPUT_LIMIT 並停用所有產物。其他副本只依上列精確規則。機器值不隨 locale 改。

## implementation

使用原生 HTML/CSS/ESM 與 Node 24 built-ins，零 runtime／建置依賴。候選目標 `tools/binary-record-inspector/`。src/core.mjs 放純驗證、推導、格式化。src/controller.mjs 管草稿、工作世代及資源。src/app.mjs 用安全 DOM API 綁表單。public/index.html 和 public/en/index.html 為兩個靜態入口。Node scripts 只建置工具 allowlist，不取線上檔、不發布。

- 工作開始先使舊結果失效並遞增世代號。Node 建置時從固定 source bytes 嵌入純核心及固定訊息處理器，頁面載入後從該固定字串建立 module Worker Blob URL。禁止使用者內容參與程式、eval、new Function 或動態 import。測試 import 同一份核心。
- Worker 每次只收目前快照及世代號。取消、換來源、重設、替換或 pagehide 時 terminate 並釋放結果及 URL。只收目前世代且 busy 的結果。成功後也停止 Worker。bfcache 回來重設。不能取消的 File.arrayBuffer 晚到也丟棄。明確點下載才建 Blob URL，30 秒內撤銷，結果失效即提早撤銷。
- 表格與預覽用 textContent/value。輸入不當標記、style、selector、href、src 或檔名。禁 fetch、XHR、WebSocket、beacon、analytics、遠端字型、上傳、帳號、剪貼簿、持久 storage、service worker。工作內容不進 URL、history、console、日誌或執行證據。離頁丟棄引用，無安全抹除承諾。
- 正式與預覽均用同源靜態資產。CSP default-src none、script-src self、style-src self、worker-src blob:、img-src self、connect-src none、object-src none、base-uri none、form-action none、frame-ancestors none。self/none 加單引號。另設 nosniff、no-referrer 並拒絕 camera/microphone/geolocation 權限。語言和首頁連結是固定導航。

## tests

驗收輸入見 [fixtures.json](fixtures.json)。7 個字面核心案例與 3 個 controller 案例。對每個 expected 深度比對，下載用獨立序列化驗 bytes 和 SHA-256。不得用產品程式產生 expected。

| 案例 ID | 驗證行為 |
| --- | --- |
| `endian-and-sign` | 共用前兩 bytes，比較不同 endian |
| `u64-precision` | 精確超過 Number safe integer |
| `last-byte` | 剛好取至末端且保留欄順 |
| `i32-minimum` | i32le 最小負值 |
| `split-nibble` | 不跨 token 拼成一 byte |
| `offset-oob` | 欄橫跨末端則拒絕 |
| `bad-type` | 拒省略 16-bit endian |
| `state-dirty-error` | 先產出真結果，再改為無效輸入，舊結果及所有下載立即失效。 |
| `state-cancel-late` | 延遲成功後取消，舊回傳不能復活，重設回預設值。 |
| `state-replace-late` | 新工作失敗後收到上一份工作的成功，保留目前錯誤。 |

狀態測例使用可控制完成時間的假 Worker。state-dirty-error 先 run initial，再 edit 成 edit 並重新執行。state-cancel-late 先 run draft、在回傳前取消、注入舊世代 lateResult，最後重設。state-replace-late 先掛起 olderDraft，再以 newerDraft 啟動新工作，先令新工作出錯，再注入舊世代 olderLateResult。每個 expected checkpoint 分別檢查畫面與下載。

另測合法上限、剛好超限、錯型別、額外欄、單獨 surrogate、惡意字串、快速改值及晚到訊息。驗證 0x80 signed 轉 -128、u64 安全整數以上、正負最大界與 offset 正好末端、大小端對稱重讀。測最大 4,096/4,097 bytes、64/65 欄及重疊欄。
