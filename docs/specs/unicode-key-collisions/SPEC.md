## goal

資料整理人員在匯入分類代碼前，要找出拼法不同、正規化後卻占用同一鍵值的列。成功是交給同事一份有原字、原列、碼點及規則的修正清單。

- 桌面。桌面從試算表複製一欄分類代碼，對照第一個碰撞群的列號回原表更正。
- 行動。手機貼上同事提供的短清單，展開單一群組讀分解碼點。

使用情境為設計假設。資料只保留在目前頁面草稿。

## scope

單欄資料的 NFC／NFKC 等價群、原字完全重複群及來源列。非目標為重寫來源、大小寫折疊、近似同形字辨識、通用清理、比對兩份翻譯、辨識真正的資料庫 collation。

已與 registry r807 的 130 份預案比對，最相近者的實質差異如下。

- 依清理選項處理空白／重複行與統計。此處保留所有原列並區分 NFC／NFKC 下不同字串的別名群。 [spec-01-text-workbench](https://github.com/KYStr/glossquote-labs-home/blob/be197ea30d909b1353e7f77bdf16b1811ac41f71/coordination/local/2026-10-29/specs/01-text-workbench/SPEC.md)
- 兩份翻譯 JSON 的鍵路徑、插值缺漏。此處單欄原字別名，沒有翻譯檔。 [spec-52-locale-check](https://github.com/KYStr/glossquote-labs-home/blob/be197ea30d909b1353e7f77bdf16b1811ac41f71/coordination/local/2026-10-29/specs/52-locale-check/SPEC.md)

## userFlow

採 Gloss Tools Product App。遵守設計系統的 paper/ink、間距、焦點和斷點。寬版以輸入與結果相鄰，結果擁有最多空間。窄版依輸入、主操作、狀態、結果直排。首屏見主工作和常用設定，詳細格式用一層 disclosure。

- 欄位或說明「待查鍵值（每行一筆） / Keys, one per line」
- 欄位或說明「正規化形式 / Normalization form」
- 「找出碰撞 / Find collisions」是主要操作。「載入範例 / Load example」填入 [fixtures.json](fixtures.json) 第一個合成案例，明示範例並等待手動執行。
- 「碰撞群與來源列 / Collision groups and source rows」先摘要再列細節，長表在有 label 的區域捲動。超過 25 列採 25 列分頁、上下頁可鍵盤操作，完整匯出不截斷。成功才顯示「下載報告 / Download report」。文字可手動選取。

| 狀態 | 操作與結果 |
| --- | --- |
| empty | 初載／重設，無結果，提示輸入或載入範例。 |
| dirty | 任一輸入、選項、來源或範例改變，立即撤銷舊結果和下載。顯示「輸入已變更，請重新執行 / Input changed. Run again.」。 |
| busy | 明確執行時處理快照，顯示「處理中 / Working」及「取消 / Cancel」。無下載。編輯終止舊工作並回 dirty。 |
| success | 報告對應目前快照。空結果有說明。若含待修列，以文字及符號提示。 |
| error | 保留草稿，沒有結果。顯示本地化錯誤、欄位及適用列號。只有提交失敗才移焦首錯欄。 |
| cancelled | 保留草稿，終止並告知「已取消，可重新執行 / Cancelled. You can run again.」。舊結果仍無效。 |

「重設 / Reset」停止工作，復原預設 `{"keys":"","form":"NFC"}` 並聚焦首來源欄。標籤不可只用 placeholder。用 aria-busy 和 polite 回報狀態，以 aria-describedby/aria-errormessage 連結錯誤。語言連結旁揭露切語或離頁會失去草稿。沒有登入或權限要求。頁面載入後可離線計算，Worker 失敗保留草稿供重試。

## inputsOutputs

核心 `run(input)` 為同步純資料轉換。參數含下列確切欄位的普通物件，只讀 own data。未知、缺欄、錯型別、accessor 皆 SCHEMA，field,row=null。JSON fixture 即介面。textarea 以 DOM 的 LF 值為準。明示檔案欄才處理原始 bytes。

- keys: string，LF 分隔 1–500 列，UTF-16 最多 32,768 單元，單列 1–64 個 Unicode scalar。最多去除一個結尾 LF 作終止符，保留內部空列供報錯。不 trim。空內容 EMPTY，列數 ROW_LIMIT。
- form: string，NFC 或 NFKC，預設 NFC，其他值 FORM。

先容量、再 surrogate、再該欄文法，跨欄和逐列順序依下文。未另外指明時容量 INPUT_LIMIT、缺內容 EMPTY、超列 ROW_LIMIT、不成對 surrogate UNICODE。整份失敗回 `{ok:false,error:{code,field,row}}`，field 為欄位名或 null，row 為明示 1-based 來源列／操作序號或 null。成功僅為 `{ok:true,result}`。資源或 Worker 失敗用固定 INTERNAL/WORKER_ERROR，不回傳堆疊。

1. 先檢查 form，再驗 keys 大小及 Unicode，拆列後由第 1 列逐列檢查。空列 EMPTY_KEY，超過 64 scalars KEY_LIMIT。含 U+0000–001F、007F–009F（不含做分隔的 LF）或 U+202A–202E、U+2066–2069 報 KEY_CONTROL。錯誤 field 為 keys，row 為實際列。
2. 用 String.prototype.normalize(form) 得 canonical。每列正規化後最多 256 scalars，否則 NORMALIZED_LIMIT。使用 Map 以 canonical 精確比較，沒有 collation、case fold 或任何捨入。順序依每群最早來源列，群內依來源列。單列群不輸出。
3. raw 全部相同的群標 exact，有兩種以上原字即 alias。codePoints 循 scalar 次序，以大寫十六進位、至少四位的 U+XXXX 呈現。以隔離方向的純文字顯示原字、另列碼點，原字中的空格不摺疊。
4. 結果 {form,rowCount,groups}。每群 {canonical,members,kind}，成員 {line,raw,codePoints}。沒有碰撞時 groups 為 []，行數保留。結果旁提示輸入系統使用的資料規則仍需使用者核對。

固定下載 `unicode-key-collisions-report.json`。內容為 result 的 compact JSON、object own keys 按 UTF-16 code units 升序遞迴排列，array 順序不改，末尾一個 LF、UTF-8 無 BOM。字串用 JSON 字面轉義，不呼叫輸入的 toJSON。報告上限 2,097,152 bytes，超過 OUTPUT_LIMIT 並停用所有產物。其他副本只依上列精確規則。機器值不隨 locale 改。

## implementation

使用原生 HTML/CSS/ESM 與 Node 24 built-ins，零 runtime／建置依賴。候選目標 `tools/unicode-key-collisions/`。src/core.mjs 放純驗證、推導、格式化。src/controller.mjs 管草稿、工作世代及資源。src/app.mjs 用安全 DOM API 綁表單。public/index.html 和 public/en/index.html 為兩個靜態入口。Node scripts 只建置工具 allowlist，不取線上檔、不發布。

- 工作開始先使舊結果失效並遞增世代號。Node 建置時從固定 source bytes 嵌入純核心及固定訊息處理器，頁面載入後從該固定字串建立 module Worker Blob URL。禁止使用者內容參與程式、eval、new Function 或動態 import。測試 import 同一份核心。
- Worker 每次只收目前快照及世代號。取消、換來源、重設、替換或 pagehide 時 terminate 並釋放結果及 URL。只收目前世代且 busy 的結果。成功後也停止 Worker。bfcache 回來重設。不能取消的 File.arrayBuffer 晚到也丟棄。明確點下載才建 Blob URL，30 秒內撤銷，結果失效即提早撤銷。
- 表格與預覽用 textContent/value。輸入不當標記、style、selector、href、src 或檔名。禁 fetch、XHR、WebSocket、beacon、analytics、遠端字型、上傳、帳號、剪貼簿、持久 storage、service worker。工作內容不進 URL、history、console、日誌或執行證據。離頁丟棄引用，無安全抹除承諾。
- 正式與預覽均用同源靜態資產。CSP default-src none、script-src self、style-src self、worker-src blob:、img-src self、connect-src none、object-src none、base-uri none、form-action none、frame-ancestors none。self/none 加單引號。另設 nosniff、no-referrer 並拒絕 camera/microphone/geolocation 權限。語言和首頁連結是固定導航。

## tests

驗收輸入見 [fixtures.json](fixtures.json)。7 個字面核心案例與 3 個 controller 案例。對每個 expected 深度比對，下載用獨立序列化驗 bytes 和 SHA-256。不得用產品程式產生 expected。

| 案例 ID | 驗證行為 |
| --- | --- |
| `nfc-alias` | 組合與預組碼點合併，重複列保留 |
| `nfkc-width` | 全形字只在相容正規化與 ASCII 進同群 |
| `nfc-width` | NFC 不折疊全形與大小寫 |
| `exact-and-final` | 末尾換行非第三列 |
| `internal-empty` | 空行保留列號並停止 |
| `hidden-control` | 控制字元拒絕 |
| `surrogate` | 拒不成對 surrogate |
| `state-dirty-error` | 先產出真結果，再改為無效輸入，舊結果及所有下載立即失效。 |
| `state-cancel-late` | 延遲成功後取消，舊回傳不能復活，重設回預設值。 |
| `state-replace-late` | 新工作失敗後收到上一份工作的成功，保留目前錯誤。 |

狀態測例使用可控制完成時間的假 Worker。state-dirty-error 先 run initial，再 edit 成 edit 並重新執行。state-cancel-late 先 run draft、在回傳前取消、注入舊世代 lateResult，最後重設。state-replace-late 先掛起 olderDraft，再以 newerDraft 啟動新工作，先令新工作出錯，再注入舊世代 olderLateResult。每個 expected checkpoint 分別檢查畫面與下載。

另測合法上限、剛好超限、錯型別、額外欄、單獨 surrogate、惡意字串、快速改值及晚到訊息。依序交換兩組來源列，報告群組順序跟著首列改變，成員不被去重。另測 64/65 scalars、500/501 列、帶方向覆寫控制的鍵及 NFKC 長度擴張。
