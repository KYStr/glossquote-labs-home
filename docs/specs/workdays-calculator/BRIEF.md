# 工作日計算機 / Workdays Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-workdays-calculator-20261109`

排交期、算請假或確認報價期限時，要嘛數兩個日期之間有幾個工作日（扣除週末與自己手上的假日），要嘛從某一天往前／往後加減 N 個工作日得到確切日期；本工具把這兩種算法的端點與假日語義一次釘死。

MVP 範圍。模式 A：兩日期間的工作日數，週末固定週六／週日，假日由使用者逐行輸入（去重、超出區間容忍）。模式 B：從起日加減 N 個工作日。端點規則為起日不計、訖日計入，與模式 B 互為反運算。非目標為內建任何官方假日表、自訂週末、半天／工時粒度、排班、多任務倒排，以及單純日曆天差（legacy date-calculator 已有，且明示無工作日／假日功能）。

首個可觀察案例。一週的基本計數與組成不變量（`basic-week`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
