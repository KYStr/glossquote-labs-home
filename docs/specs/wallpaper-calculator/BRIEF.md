# 壁紙用量計算 / Wallpaper Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-wallpaper-calculator-20261109`

自己貼壁紙的人量好房間周長（或逐面牆寬高）、手上有一款壁紙的捲寬、捲長與圖案重複長度，要先算清楚需要幾幅、每幅裁多長、共買幾捲才夠，才不會買少跑第二趟或買多浪費。

MVP 範圍。公制輸入、整數公分運算：周長模式或逐牆模式、幅數由寬度覆蓋向上取整、幅長加固定修剪裕度後向上取整到完整圖案重複、每捲可裁幅數取下限、捲數向上取整；門窗開口可選（尺寸清單或總面積皆用於顯示淨牆面積；採購量按全牆寬估算）、損耗百分比可選。非目標為實際排版模擬、斜牆／挑高／壁龕造型、橫貼或特殊對花方式、價格試算、品牌捲型資料庫、把估算當施工保證。

首個可觀察案例。周長 12 m、高 2.5 m、捲 0.53 × 10.05 m、無圖案重複：23 幅、每幅 260 cm、每捲裁 3 幅、共 8 捲（`basic-perimeter`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
