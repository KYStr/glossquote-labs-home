# 底片張數配置 / Film Roll Frame Budget 製作簡報

預案 `spec-film-roll-budget-20261109` · 文件待獨立審查

底片攝影者手上只剩固定可拍張數，想保留幾張給臨時場景，同時先滿足活動各段的最低拍攝張數。結果列出可拍目標及尚未覆蓋的期待。

出門前用桌面把活動時段寫成短名，在同一張清單查看最低、理想、優先和配置。

拍攝時用手機把相機剩餘張數改成實點值，重算後看到每段要留下幾張。用代號避免列個資。

主要操作「配置剩餘張數 / Allocate remaining frames」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
可拍總額／場景編輯   |   逐場景分配與未用張數

窄畫面（由上而下）
剩餘／保留 → 場景與優先 → 配置張數 → 可拍與差額
```

首個貫通案例用 `film-roll-budget.priority-rounds`。24 張剩餘、保留 4，三個場景得 9、7、4 張，高優先的兩個場景差一張理想額。

一卷的使用者實點剩餘張數，獨立保留額、固定場景序、三個優先級。最低額足夠時先分配最低，再逐級在同級輪流補理想額。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/film-roll-budget/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
