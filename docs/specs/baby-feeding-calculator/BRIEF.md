# 嬰兒奶量計算 / Baby Feeding Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-baby-feeding-calculator-20261109`

新手父母在半夜泡奶前，手機上只有寶寶最近一次量到的體重，想快速知道「一天大約要喝多少、分成幾餐一餐大概多少」，又不想被來路不明的數字誤導。本工具依公開醫療指引（NHS 111 Wales）公布的每公斤體重每日 150–200 ml 範圍，以體重與每日餵食次數算出每日總量與每餐分配，全程標示來源與「僅供一般參考、不是醫療建議」的聲明。

MVP 範圍。體重（公斤）輸入、每公斤每日奶量係數（預設 150、可在指引範圍 150–200 內調整）、每日餵食次數，每日總量以整數 ml 四捨五入、每餐分配餘數由最早的餐次依序吸收 1 ml 使加總恰好相等。選填月齡只用於標示與適用範圍提醒，不改變係數。非目標為依月齡調整係數（引用來源未公布月齡對照表）、每日上限、每餐胃容量警示帶、盎司換算、直接哺乳量推估、成長曲線或任何診斷建議。

首個可觀察案例。4.55 kg、係數 150、每日 7 餐：未捨入總量 682.5 ml 恰在 .5 進位點，總量釘版為 683 ml，且 683 除以 7 除不盡，前 4 餐各多 1 ml（`remainder-split-half-up-tie`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
