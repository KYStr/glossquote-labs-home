# 薪資換算 / Salary Converter — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-salary-converter-20261109`

求職者同時談月薪制正職與時薪制兼職、上班族核對薪資單上的時薪、或談年薪（含年終獎金月數）時反推月薪落點，手上通常只有一個已知金額，卻要在月薪、日薪、時薪、年薪之間反覆手算，還常因各通路算法與捨入不同而兜不攏。本工具以單一基準輸入一次換算全部金額，並把台灣常見換算慣例明寫揭露。

MVP 範圍。四種基準（月薪／日薪／時薪／年薪）任選其一輸入，加上年終獎金月數，依固定慣例（日薪＝月薪÷30、時薪＝月薪÷240、年薪＝月薪×（12＋獎金月數））一次算出月薪、日薪、時薪、年薪（不含獎金）、獎金金額、年薪（含獎金），每個金額由未捨入月薪一次換算、四捨五入至整數元。非目標為加班費倍率、勞健保與所得稅扣繳、退休金提撥、薪資單產製、外幣與最低工資查詢。

首個可觀察案例。月薪 40,000、年終 2 個月（`monthly-basic`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
