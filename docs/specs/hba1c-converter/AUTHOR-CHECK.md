## 來源核實（皆於 2026-11-21 查閱）

- eAG mg/dL 式：Nathan et al., ADAG Study, Diabetes Care 2008;31:1473–1478（PMCID PMC2742903）：「AGmg/dl = 28.7 × A1C − 46.7, R² = 0.84, P < 0.0001」，n=507。ADA eAG/A1C Conversion Calculator（professional.diabetes.org/glucose_calc）同式，mg/dL 對照表 9 列（6–10% 每 0.5）與本規格公式在 0 位小數完全一致（126／140／154／169／183／197／212／226／240）。
- eAG mmol/L 式：同論文 Table 1 註腳「Linear regression eAG (mmol/l) = 1.5944 × A1C − 2.594」（即 mg/dL 式 ÷18）。本規格以此式為準。
- IFCC 式：NGSP/IFCC 主方程式 IFCC (mmol/mol) = (A1c% − 2.15) × 10.929；反函數 A1c% = IFCC ÷ 10.929 + 2.15。個別次要來源（如 Wikiwand glycated hemoglobin 條目）寫成減 2.14，本規格依主方程式釘為 2.15。
- 分級帶：ADA Standards of Care 診斷切點：<5.7% 正常、5.7–6.4% 糖尿病前期、≥6.5% 糖尿病範圍；一般目標 <7.0%（多數非懷孕成人）只見 FAQ，不進結果物件。

## 兩種推導（手算 → 獨立重算）

方法一（手算）：逐案以紙筆算術由 §5 公式推導，unrounded 中間值保留 4 位以上小數，再依 §5 精度 ROUND_HALF_UP 顯示。方法二（獨立重算）：Python `decimal.Decimal` 精確十進位算術腳本，直接讀 fixtures.json、由 input 重算全部 10 筆核心 expected 並逐欄比對；另以同一腳本比對 ADA 對照表 9 列的三種候選 mmol/L 規則。

手算稿（unrounded → 顯示）：

- `a1c-7-percent`：IFCC (7−2.15)×10.929 = 4.85×10.929 = 53.00565 → 53；eAG 28.7×7−46.7 = 200.9−46.7 = 154.2 → 154；mmol/L 1.5944×7−2.594 = 11.1608−2.594 = 8.5668 → 8.6；7.00 ≥ 6.5 糖尿病範圍。
- `a1c-6-5`：IFCC 4.35×10.929 = 47.54115 → 48；eAG 186.55−46.7 = 139.85 → 140；mmol/L 10.3636−2.594 = 7.7696 → 7.8；糖尿病範圍。
- `a1c-5-7-boundary`：IFCC 3.55×10.929 = 38.79795 → 39；eAG 163.59−46.7 = 116.89 → 117；mmol/L 9.08808−2.594 = 6.49408 → 6.5；5.70 糖尿病前期下限。
- `ifcc-53-reverse`：A1c = 53÷10.929+2.15 = 4.84948+2.15 = 6.99948 → 7.00；eAG 28.7×6.99948−46.7 = 154.185 → 154；mmol/L 1.5944×6.99948−2.594 = 8.566 → 8.6；糖尿病範圍。
- `eag-mgdl-126-reverse`：A1c = (126+46.7)÷28.7 = 172.7÷28.7 = 6.01742 → 6.02；IFCC 3.86742×10.929 = 42.267 → 42；mmol/L 1.5944×6.01742−2.594 = 7.000 → 7.0；糖尿病前期。
- `eag-mmol-8-5-reverse`：A1c = (8.5+2.594)÷1.5944 = 11.094÷1.5944 = 6.95810 → 6.96；IFCC 4.80810×10.929 = 52.548 → 53；eAG 28.7×6.95810−46.7 = 152.997 → 153；mmol/L 回推 8.500 → 8.5（往返一致）。
- `a1c-4-low`：IFCC 1.85×10.929 = 20.21865 → 20；eAG 114.8−46.7 = 68.1 → 68；mmol/L 6.3776−2.594 = 3.7836 → 3.8；正常。
- `a1c-12-high`：IFCC 9.85×10.929 = 107.65065 → 108；eAG 344.4−46.7 = 297.7 → 298；mmol/L 19.1328−2.594 = 16.5388 → 16.5；糖尿病範圍。
- `a1c-3-min`：IFCC 0.85×10.929 = 9.28965 → 9；eAG 86.1−46.7 = 39.4 → 39；mmol/L 4.7832−2.594 = 2.1892 → 2.2；正常。
- `a1c-20-max`：IFCC 17.85×10.929 = 195.08265 → 195；eAG 574−46.7 = 527.3 → 527；mmol/L 31.888−2.594 = 29.294 → 29.3；糖尿病範圍。

獨立重算結果：10/10 核心案例逐欄一致。重算腳本亦確認分級切點（5.69 正常、5.70 前期、6.49 前期、6.50 糖尿病範圍）與端點顯示值。

## 寫作中發現並修正之處

1. 手算初稿把 7% 的未捨入 eAG 寫成 154.0（28.7×7 = 200.9，200.9−46.7 = 154.2，不是 154.0）；Decimal 重算抓出，顯示值不變（154），mmol/L 不變（8.6）。同類檢查確認 10% 未捨入值為 240.3（顯示 240）。
2. 獨立重算抓出 `eag-mmol-8-5-reverse` 分級誤寫：A1c 6.96 ≥ 6.5，應為 `diabetes-range`，初稿誤寫 `prediabetes`；已修正為 `diabetes-range`，重算後 10/10 通過。
3. mmol/L 規則抉擇（來源衝突，非概念筆記錯誤）：ADA 對照表的 mmol/L 欄無法由任一已發表公式在小數 1 位完整重現。腳本實測 9 列符合數：1.59 簡式（1.59×A1c−2.59）3/9；mg/dL ÷18.0182 5/9；ADAG 論文原式 1.5944×A1c−2.594 7/9。依「跟來源走」釘論文原式；殘差兩列（A1c 8.0%：本工具 10.2、對照表 10.1；8.5%：本工具 11.0、對照表 10.9）已在 SPEC §5 與 FAQ 揭露，不改公式湊表。
4. IFCC 常數 2.14 vs 2.15：次要來源有 2.14 寫法，主方程式為 2.15，已釘 2.15 並記錄。
