## 常數查證（2026-11-09，作者親查）

- **1 坪 = 400/121 m²**：日文維基「坪」條目載明依度量衡法定義為 400/121 m²，源於 1 尺 = 10/33 m、邊長 6 尺；台灣財政部稅務入口網的官方換算用 1 m² = 0.3025 坪，與 121/400 一致。概念筆記寫的 3.305785 是 400/121 的捨入小數——SPEC 釘精確分數，分數優先（屬釐清，非更正）。
- **1 ft² = 0.09290304 m²**：國際英尺 1 ft = 0.3048 m 精確定義的平方，145161/1562500 為其分數形。
- **1 畳 = 1.62 m²**：日本「不動産の表示に関する公正競争規約施行規則」規定房源廣告以畳數表示居室廣さ時，1 畳須為 1.62 m² 以上——即廣告換算慣例（下限），非實物尺寸。條文經多個不動產公正取引協議會相關與業界來源一致引述核對。實物尺寸由作者以 cm 邊長自算：京間 191×95.5 cm = 1.82405 m²、中京間 182×91 cm = 1.6562 m²、江戸間 176×88 cm = 1.5488 m²、団地間 170×85 cm = 1.445 m²，均與各來源所載約值相符。SPEC 已把畳釘為標示概略的次要單位。

## Fixture 數值雙重推導

原稿的字面值由作者以分數手算與 Python `fractions.Fraction` 獨立重算。維護者用相同精確常數推導新增的 100 坪案例。

手算要點（分數化簡＋長除法）：

- 1 坪 =(6×10/33)² =(20/11)² = 400/121 m²。
- 30 坪 m²：12000/121 = 99 + 21/121 = 99.17355… → 99.17。ft²：12000/121 × 1562500/145161 = 18,750,000,000/17,564,481 ≈ 1067.49524 → 1067.50。用 3.3058 作係數亦顯示 1067.50。畳：12000/121 × 50/81 = 600000/9801 ≈ 61.2188 → 61.2。
- 100 坪精度案例：40,000/121 m² 乘 1,562,500/145,161，得到 3558.31749… ft²，顯示 3558.32。若以 100 × 3.3058 m² 換算，則為 3558.33350… ft²，顯示 3558.33。其餘精確結果為 330.58 m² 與 204.1 畳。
- 100 m² → 坪：100 × 121/400 = 121/4 = 30.25（整數，無捨入）。
- tie 兩案：2 m² → 坪 = 242/400 = 0.605 整數 → half-up 0.61；1.701 m² → 畳 = 1701/1620 = 1.05 整數 → half-up 1.1。兩案皆為精確 .5 尾，能區分 half-up 與銀行家捨入／截斷。
- 1000 ft² → m²：1000 × 0.09290304 = 92.90304 → 92.9；→ 坪：92.90304 × 121/400 = 28.1031696 → 28.1。
- 速查表抽查列（手算）：2 坪 = 800/121 ≈ 6.6116 → 6.61；3 坪 = 1200/121 ≈ 9.9174 → 9.92；10 坪 = 4000/121 ≈ 33.0579 → 33.06；100 坪 = 40000/121 ≈ 330.5785 → 330.58；第 30 列與 `example-thirty-ping` 的 m2／ft2 一致（99.17／1067.50），第 100 列與 `hundred-ping-precision` 一致（330.58／3558.32）。

原稿的 23 筆核心及 100 列速查表由 Python 分數運算重算。維護者用離線 Node 整數驗證器重算修訂後全部案例，含 100 坪精確與近似比較、速查表交叉比對及 30 坪下載。
