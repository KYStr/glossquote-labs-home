# 窗簾同花位落剪 / Curtain Pattern Cuts 製作簡報

預案 `spec-curtain-repeat-cut-20261109` · 文件待獨立審查

縫紉者手上有一卷全幅花布，要依既定順序剪窗簾片。成品頂邊要落在同一花樣位置，即使每片摺邊不同，也能在下剪前算出逐片起訖、跳花耗料與差量。

桌面依樣品標出直向花距和布頭相位，抄下每片成品高度與上下摺邊，核對整卷是否足夠。

手機放在裁布檯，從同一布頭讀每片起剪與終剪位置。結果以短清單保留裁剪次序，留白及不足在每輪重新量測後更新。

主要操作「列出同花位剪線 / Plan matching cuts」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
布頭與花距／片序表   |   連續剪線標尺＋逐片清單

窄畫面（由上而下）
布頭相位 → 片序 → 列出剪線 → 起／訖與短缺
```

首個貫通案例用 `curtain-repeat-cut.matched`。花距 320 mm，布頭在相位 80 mm。兩片成品頂緣都對相位 0，第二剪線起點為 2,110 mm。

一卷單向全幅直裁，逐片獨立摺邊、共同可見頂邊花位、可算素布。輸出每片跳過長度和整卷所需。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/curtain-repeat-cut/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
