# 包裹計費重核對 / Parcel Billable Weight 製作簡報

預案 `spec-parcel-billable-weight-20261109` · 文件待獨立審查

出貨者已量數個包裹及找到服務給出的除數、進位及尺寸限制，想在交寄前逐件核對實重、材積重與計費重。

包裝桌旁用寬畫面並列各服務的包裹結果，核對哪些尺寸過門檻、哪一件造成該服務不能得到完整總重。

秤旁用手機逐件輸入毫米及克。結果先按服務，打開件列時同時看三邊、材積及尺寸檢查。

主要操作「核對各服務計費重 / Compare billable weights」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
包裹外量測／服務規則   |   服務與包裹對照，附超界理由

窄畫面（由上而下）
包裹 → 服務條件 → 核對計費重 → 選服務查看各件
```

首個貫通案例用 `parcel-billable-weight.two-services`。300×200×100 mm、1,000 g、除數 5,000、500 g 級距，材積重 1,200 g，計費重 1,500 g。

1–12 件長方體外包裝及 1–4 組自填服務規則。支援整件量測上限、最低計費重與向上級距。尺寸或實重超界逐件列明。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/parcel-billable-weight/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
