# 露點模型來源勘誤 — 2026-11-10

本紀錄由主統籌新增，不是原作者當時已完成的查證。原規格 PR #230：`8b89efbe27da257c130bea8f70d5e4abc8865232`；數值核心和 fixtures 保持原版本。

- 澳洲氣象局 [Thermal Comfort](https://www.bom.gov.au/info/thermal_stress/) 明列指數係數 17.27/237.7，水氣壓前係數 6.105。本工具保留原近似模型的 6.112（相對差約 0.115%）；兩者不應宣稱逐字同式。壓力正規化影響絕對濕度，不影響目前露點反解。
- [University of Miami humidity calculator](https://mrg.rsmas.miami.edu/Humidity.html) 採另一組 17.625/243.04。不同係數是不同近似選擇，不能因與既有測例不同就判斷替代式錯誤。
- Lawrence 2005 原始論文的可讀副本首頁刊載 17.625 勘誤；本輪出版社入口 403，未完成原文全部精度限制覆核。因此撤回原 SPEC 的「−45…60 °C 約 ±0.4 °C」及 AUTHOR-CHECK 的替代式「±0.05 °C」精度背書，不移植另一公式的適用域。原歷史陳述保留並標明撤回。
- −50…60 °C 是程式接受範圍，並非實測精度證據。0 °C 以下仍為過冷水露點而非霜點；低濕與極端值只供近似參考。不用作醫療、建築防潮或儀器校正依據。
- 本輪不改係數、不自動刷新 fixtures；後續若要宣告誤差上限，需固定完整一級來源與參考模型、跨整個溫濕度域的獨立比較，再單獨修訂契約。
