# 倉儲空間估算 / Storage Unit Estimator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-storage-unit-estimator-20261121`

搬家或裝修前要租倉儲單位，先確認東西總共多大：逐列加入家具、家電與箱子（每件體積依釘版體積表），算出總體積與含走道預留的需要體積，再推薦最小的合適倉儲單位尺寸。

MVP 範圍。物品清單（最多 30 列）、21 件釘版體積表、自訂物品長寬高輸入、總體積合計、25% 走道與堆疊空隙預留、6 檔釘版倉儲單位尺寸表（5×5 至 10×30 ft，8 ft 高）與最小合適單位推薦、佔用率、超量時的多間建議。非目標為箱數與包材估算、實際裝載圖、價格或租金試算、即時空位查詢、品牌或業者推薦。

首個可觀察案例。單人床＋衣櫃＋中箱＋洗衣機（`studio-basics`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
