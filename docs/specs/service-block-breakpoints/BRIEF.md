# 工作室次數費用交會表 / Studio Visit Fee Breakpoints 製作簡報

預案 `spec-service-block-breakpoints-20261109` · 文件待獨立審查

共用工作室使用者已知兩個方案的固定額、包含次數、分段每次價格或整包價格，希望查看預計使用次數從少到多時，何時出現同額或高低互換。

用桌面輸入兩套條件，並列查看兩者每個次數的金額、及結論相同的連續範圍。

在工作室用手機先看交會區間，可展開具體使用次數，確認整包進位如何變動。

主要操作「比較各使用次數 / Compare visit counts」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
兩方案費用及包含次數   |   交會區間＋每次數金額

窄畫面（由上而下）
最高次數 → 方案 A → 方案 B → 比較區間 → 展開金額
```

首個貫通案例用 `service-block-breakpoints.multiple-crossings`。整包每兩次 600，另一方案每次 350。1 次 B 低、2 次 A 低、3 次 B 低、4 次 A 低。

同一期間、同一最小計價單位的兩方案。每方案採邊際級距或整包計量。列出 0 到指定最大次數的金額與連續比較區間。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/service-block-breakpoints/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
