# 德州撲克勝率 / Poker Odds Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-poker-odds-calculator-20261121`

玩家在牌桌上拿到兩張手牌、看到公共牌後，想知道自己現在是什麼牌、還差幾張 outs 能成牌、下一張與接下來兩張的命中率、對上 N 位對手的勝率／平手率／權益，以及底池賠率下該跟注還是棄牌。

MVP 範圍。輸入手牌 2 張、公共牌 0／3／4／5 張、對手 1–9 人、底池與跟注額（選填）。輸出：目前最佳成牌、outs（依成牌轉換規則由牌面算出，不由使用者自填）、下一張命中率、兩張命中率、2/4 法則近似值（僅供參考，明確標示為近似）、勝率／平手率／敗率／權益（情境數 ≤ 2,000,000 時精確枚舉，否則 100,000 次種子蒙地卡羅）、最終成牌分布、底池賠率與跟注／棄牌提示。非目標為對手手牌範圍建模、下注額建議、資金管理、讀取即時牌局、真錢投注建議。

首個可觀察案例。同花聽牌（`flush-draw-flop`）：A♠ K♠ 對 Q♠ 7♠ 2♣，9 張 outs，下一張命中率 19.15%，兩張命中率 34.97%，2/4 法則近似 18%／36%，對 1 位對手精確枚舉 1,070,190 種情境，勝率 72.32%、權益 72.68%。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
