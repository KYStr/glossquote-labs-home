## 雙重推導（每一個數字）

方法 A（手算推導的機械化）：按 SPEC 釘死的公式逐項代入——年金公式求月付、等比級數求租金、冪次求房價與機會成本、逐月分攤求餘額；以 Python Decimal（精度 50）執行，整數先乘後除再四捨五入。
方法 B（獨立重算）：另寫的實作，全程精確有理數（`fractions.Fraction`），整數 half-up 公式 `(2p+q)//(2q)`，單次遍歷逐月模擬並即時彙整年度快照，結構與方法 A 不同。
兩法對 9 筆有效核心案例的每一個數字（含全部逐年列）逐位一致後，才寫入 fixtures.json。

### 方法 A 曾經出錯、被方法 B 抓到的一處

初版方法 A 以 Decimal 近似月利率 `i ≈ 0.00208333…`（50 位）直接相乘取整，在 taipei-typical 第 195 個月算錯 1 元：當時餘額 4,432,080 元，精確利息 = 4,432,080 / 480 = 9,233.5 元，正確 half-up 為 9,234 元；Decimal 近似值略小於 9,233.5，取成 9,233 元，之後各年餘額全差 1 元、30 年總額差 1 元。此錯誤已修正：方法 A 改為整數先乘（`B × rate_scaled`）再一次 Decimal 除法取整；租金／房價／機會成本亦改為整數分子除以 10000 的冪次。修正後兩法逐位一致。本案已寫進 SPEC implementation 節作為建置者的明確禁令：不得以二進位浮點數的近似月利率直接相乘後取整。

## 手算驗證（字面算術，非腳本輸出）

- `zero-rate-zero-growth` 全案手算：L = 1,200,000 − 240,000 = 960,000；n = 36；M = 960,000 / 36 = 26,666.67 → 26,667。第 1 年：租金 120,000；房貸 12 × 26,667 = 320,004；餘額 960,000 − 320,004 = 639,996；權益 1,200,000 − 639,996 = 560,004；買房淨成本 240,000 + 320,004 − 560,004 = 0；差額 120,000。第 2 年餘額 319,992、淨成本 0、差額 240,000。第 3 年：B35 = 960,000 − 26,667 × 35 = 26,655，最後一月付 26,655，全年房貸 11 × 26,667 + 26,655 = 319,992，餘額 0、淨成本 0、差額 360,000。與 fixtures 逐位一致。
- `taipei-typical` 第 1 年手算：i = 2.5% / 12 = 1/480；(1+i)^360 ≈ 2.115349；M = 8,000,000 × (1/480) / (1 − 2.115349^−1) = 16,666.67 / 0.527314 ≈ 31,609.67 → 31,610。第 1 個月利息 = round(8,000,000 / 480) = round(16,666.67) = 16,667，本金 14,943，餘額 7,985,057。第 1 年買房淨成本 = 2,000,000 + 379,320 + 60,000 − (10,000,000 − 7,818,611) = 257,931，差額 240,000 − 257,931 = −17,931。閉式餘額 B12 = 7,818,610.96，與逐月分攤的 7,818,611 差 0.04 元（每月四捨五入的累積，方向正確）。與 fixtures 逐位一致。
- 交叉年聚合手算：taipei-typical 第 5 年差額 −12,192、第 6 年 +9,424（故 breakevenYear = 6）；late-crossover 第 11 年買房淨成本 = 2,000,000 + 11 × 404,736 + 768,468 − (10,000,000 − 5,856,260) = 3,076,824、第 12 年 3,332,391（故 breakevenYear = 12）。皆與 fixtures 逐位一致。
- `one-year-horizon`：M 精確值 606,519.84 → 606,520；最後一月付 606,519（= 7,278,239 − 11 × 606,520），與 fixtures 一致。

## 概念筆記 vs 釘死的規則

- 概念筆記只列輸入與產出，未規定機會成本的歸屬、月付取整、最後一月結清與損益平衡的首次交叉定義；本 SPEC 全部釘死：機會成本計在買房一側（租屋側不另扣減，比較結果相同）、金額整數元 half-up、最後一月精確結清、breakevenYear 為首次差額 ≥ 0 的年份。
- 概念筆記未提稅費等成本；本 SPEC 明列為非目標，並把試算聲明逐字釘死為非財務建議。
- 無與主要來源衝突而需更正之處（本案公式為標準年金與複利，無外部法令表可引用）。
