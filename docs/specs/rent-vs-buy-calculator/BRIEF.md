# 租屋 vs 買房試算 / Rent vs Buy Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-rent-vs-buy-calculator-20261121`

準備買房的人，先輸入租金、房價、頭期款、房貸利率與三個年增率假設，看到第幾年買房開始比租屋划算，以及逐年的總成本比較表，再決定要不要繼續租。

MVP 範圍。固定年利率、固定年增率的年度模型：等額本息月付（內部逐月分攤）、租金按年複利成長、房價按年漲跌、頭期款機會成本按年複利。非目標為稅費／仲介費／裝修／維修／管理費、負擔能力審核（DTI）、逐月還款表顯示、即時利率查詢、多物件比較、賣房成本、把結果當財務建議或銀行報價。
