# 兒童身高預測 / Child Height Predictor — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-child-height-predictor-20261109`

家長想快速知道孩子成年後大概會長多高，手邊只有爸爸和媽媽的身高。輸入父母身高（公分）與孩子性別，立即以 Tanner 父母身高中值法（mid-parental height）得到預估成年身高與 ±8.5 公分目標區間，不必註冊、不必輸入孩子的任何資料，資料不離開目前頁面。

MVP 範圍。單一公式模型：男孩 (父 + 母 + 13) / 2、女孩 (父 + 母 − 13) / 2（公分），目標區間為預估值 ±8.5 公分；輸入僅公分、結果一位小數（round-half-up，只捨入一次）、固定格式報告下載。非目標為依孩子目前年齡／身高／體重的生長百分位或 Khamis-Roche 法、骨齡或其他醫療評估、英呎英吋輸入、回歸至平均數校正、任何資料儲存或追蹤。

首個可觀察案例。父 178、母 165、男孩：預估 178.0 公分，區間 169.5–186.5 公分。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。本工具僅為統計估計，不是醫療建議，也不是對任何一位兒童的成長診斷或保證（完整聲明見 SPEC.md）。
