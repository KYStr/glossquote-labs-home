# 百分比計算機 / Percentage Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-percentage-calculator-20261109`

行政助理小琪月底對帳，手上有一疊發票和部門預算表，在手機與桌面之間反覆回答三種問題：這筆金額的 5% 是多少、這筆支出佔預算百分之幾、本月比上月增減了幾 %。她不想為這種小算式開試算表，也不要遇到除以零時拿到 Infinity 或被默默四捨五入掉的結果。最後她要拿到一句講清楚的結果，和一份可下載的報告，方便貼進對帳紀錄。

MVP 範圍。三種模式（百分之幾的值、佔比、變化率）、兩個十進位運算元、精確十進位運算、顯示捨入到 2 位去尾零、除零固定錯誤。非目標為反推原值、百分點差、折扣／稅率預設、多筆統計、紀錄儲存與分享。

首個可觀察案例。百分之二十的 150 等於 30（`percent-of-basic`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。

先完成核心／狀態測試，再交雙語靜態頁、匯出、build/check、同一候選的九面向證據。目標 `tools/percentage-calculator/`，固定分支與 PR 交驗。
