## goal

設計或前端同事拿到版面標註值，想知道每筆量測最接近哪個設計間距 token，並交付超出可接受偏差的列。

- 桌面。桌面貼 token 表和量測表，依照報告回稿面修正相應元件。
- 行動。手機在設計評審核對幾個 gutter 與 gap，讀出差距和門檻。

使用情境為設計假設。資料只保留在目前頁面草稿。

## scope

兩份使用者提供的名稱與 px 表，數值近鄰與偏差分級。排除擷取設計工具資料、讀 CSS、套用樣式、換 rem 或百分比、猜規格或建構設計系統。

已與 registry r807 的 130 份預案比對，最相近者的實質差異如下。

- 比較 padding、border 的盒尺寸。此處量測值對既有 token 表，輸出 nearest token 和偏差。 [spec-css-box-model-sizing-20261101](https://github.com/KYStr/glossquote-labs-home/blob/fa3685b2dab979f5afb84d127c82864c2040cbb6/docs/specs/css-box-model-sizing/SPEC.md)
- 依視窗推導流式字體。本工具沒有 viewport 換算或 CSS 產生。 [spec-fluid-typography-20261031](https://github.com/KYStr/glossquote-labs-home/blob/50932c6c24035426a07632003437c044d71d0658/docs/specs/fluid-typography/SPEC.md)

判定規則由本文定義，無線上資料或外部服務依賴。

## userFlow

採 Gloss Tools Product App。遵守設計系統的 paper/ink、間距、焦點和斷點。寬版以輸入與結果相鄰，結果擁有最多空間。窄版依輸入、主操作、狀態、結果直排。首屏見主工作和常用設定，詳細格式用一層 disclosure。

- 欄位或說明「設計 Token 與 px / Design tokens and pixels」
- 欄位或說明「量測名稱與 px、容許偏差 / Measurement labels and pixels, with tolerance」
- 「對照間距 Token / Match spacing tokens」是主要操作。「載入範例 / Load example」填入 [fixtures.json](fixtures.json) 第一個合成案例，明示範例並等待手動執行。
- 「匹配與超差列 / Matches and out-of-tolerance rows」先摘要再列細節，長表在有 label 的區域捲動。超過 25 列採 25 列分頁、上下頁可鍵盤操作，完整匯出不截斷。成功才顯示「下載報告 / Download report」。文字可手動選取。

| 狀態 | 操作與結果 |
| --- | --- |
| empty | 初載／重設，無結果，提示輸入或載入範例。 |
| dirty | 任一輸入、選項、來源或範例改變，立即撤銷舊結果和下載。顯示「輸入已變更，請重新執行 / Input changed. Run again.」。 |
| busy | 明確執行時處理快照，顯示「處理中 / Working」及「取消 / Cancel」。無下載。編輯終止舊工作並回 dirty。 |
| success | 報告對應目前快照。空結果有說明。若含待修列，以文字及符號提示。 |
| error | 保留草稿，沒有結果。顯示本地化錯誤、欄位及適用列號。只有提交失敗才移焦首錯欄。 |
| cancelled | 保留草稿，終止並告知「已取消，可重新執行 / Cancelled. You can run again.」。舊結果仍無效。 |

「重設 / Reset」停止工作，復原預設 `{"tokens":"","measurements":"","tolerance":"1"}` 並聚焦首來源欄。標籤不可只用 placeholder。用 aria-busy 和 polite 回報狀態，以 aria-describedby/aria-errormessage 連結錯誤。語言連結旁揭露切語或離頁會失去草稿。沒有登入或權限要求。頁面載入後可離線計算，Worker 失敗保留草稿供重試。

## inputsOutputs

核心 `run(input)` 為同步純資料轉換。參數含下列確切欄位的普通物件，只讀 own data。未知、缺欄、錯型別、accessor 皆 SCHEMA，field,row=null。JSON fixture 即介面。textarea 以 DOM 的 LF 值為準。明示檔案欄才處理原始 bytes。

- tokens/measurements: string，各最多 8,192 UTF-16 單元，LF、去一個尾 LF。tokens 1–64 列，measurements 1–100 列。每列 name HT px。name [A-Za-z][A-Za-z0-9_-]{0,31}，同表不得重名。
- px 與 tolerance 均為 0–2,048 的無符號 ASCII 十進數，文法 (0|[1-9][0-9]{0,3})(\.[0-9]{1,3})?。不 trim，無 px 後綴、空格、逗號、指數或單位推測。tolerance: string，預設 1。

先容量、再 surrogate、再該欄文法，跨欄和逐列順序依下文。未另外指明時容量 INPUT_LIMIT、缺內容 EMPTY、超列 ROW_LIMIT、不成對 surrogate UNICODE。整份失敗回 `{ok:false,error:{code,field,row}}`，field 為欄位名或 null，row 為明示 1-based 來源列／操作序號或 null。成功僅為 `{ok:true,result}`。資源或 Worker 失敗用固定 INTERNAL/WORKER_ERROR，不回傳堆疊。

1. 先 tolerance（TOLERANCE），再 tokens、measurements（大小、Unicode、空、列數）。每列欄數／name 語法 ROW_FORMAT，重名 DUP_NAME，px 文法或範圍 PIXELS，row 為實際來源列。
2. 以 BigInt 千分之一 px 轉 token、measurement 和 tolerance。每筆量測線性找絕對差最小的 token。平手先取 px 較小者，數值相同再取 token 原表較前列。量測依原表次序，不以超差排序。delta=measurement−token 值。delta=0 時 exact，其餘 abs(delta)≤tolerance 為 within，否則 outside。
3. 結果 {rows,outsideCount}，每列 {label,px,token,tokenPx,delta,status}，px、tokenPx、delta 為 ASCII 標準小數，不捨入或補無效零。等距時顯示取小者，報告只提出符合產品規則的比對，不自動寫回。

固定下載 `spacing-token-audit-report.json`。內容為 result 的 compact JSON、object own keys 按 UTF-16 code units 升序遞迴排列，array 順序不改，末尾一個 LF、UTF-8 無 BOM。字串用 JSON 字面轉義，不呼叫輸入的 toJSON。報告上限 2,097,152 bytes，超過 OUTPUT_LIMIT 並停用所有產物。其他副本只依上列精確規則。機器值不隨 locale 改。

## implementation

使用原生 HTML/CSS/ESM 與 Node 24 built-ins，零 runtime／建置依賴。候選目標 `tools/spacing-token-audit/`。src/core.mjs 放純驗證、推導、格式化。src/controller.mjs 管草稿、工作世代及資源。src/app.mjs 用安全 DOM API 綁表單。public/index.html 和 public/en/index.html 為兩個靜態入口。Node scripts 只建置工具 allowlist，不取線上檔、不發布。

- 工作開始先使舊結果失效並遞增世代號。Node 建置時從固定 source bytes 嵌入純核心及固定訊息處理器，頁面載入後從該固定字串建立 module Worker Blob URL。禁止使用者內容參與程式、eval、new Function 或動態 import。測試 import 同一份核心。
- Worker 每次只收目前快照及世代號。取消、換來源、重設、替換或 pagehide 時 terminate 並釋放結果及 URL。只收目前世代且 busy 的結果。成功後也停止 Worker。bfcache 回來重設。不能取消的 File.arrayBuffer 晚到也丟棄。明確點下載才建 Blob URL，30 秒內撤銷，結果失效即提早撤銷。
- 表格與預覽用 textContent/value。輸入不當標記、style、selector、href、src 或檔名。禁 fetch、XHR、WebSocket、beacon、analytics、遠端字型、上傳、帳號、剪貼簿、持久 storage、service worker。工作內容不進 URL、history、console、日誌或執行證據。離頁丟棄引用，無安全抹除承諾。
- 正式與預覽均用同源靜態資產。CSP default-src none、script-src self、style-src self、worker-src blob:、img-src self、connect-src none、object-src none、base-uri none、form-action none、frame-ancestors none。self/none 加單引號。另設 nosniff、no-referrer 並拒絕 camera/microphone/geolocation 權限。語言和首頁連結是固定導航。

## tests

驗收輸入見 [fixtures.json](fixtures.json)。7 個字面核心案例與 3 個 controller 案例。對每個 expected 深度比對，下載用獨立序列化驗 bytes 和 SHA-256。不得用產品程式產生 expected。

| 案例 ID | 驗證行為 |
| --- | --- |
| `tie-and-threshold` | 等距取小，剛好等門檻仍 within |
| `same-value-alias` | 同值 token 按輸入先後 |
| `zero-tolerance` | 零容許差僅 exact 符合 |
| `upper-bound` | 最大 px 可輸入 |
| `out-of-range` | 拒絕超過最大值一個刻度 |
| `duplicate-name` | 同表標籤唯一 |
| `bad-unit` | 拒絕未支援的長度單位 |
| `state-dirty-error` | 先產出真結果，再改為無效輸入，舊結果及所有下載立即失效。 |
| `state-cancel-late` | 延遲成功後取消，舊回傳不能復活，重設回預設值。 |
| `state-replace-late` | 新工作失敗後收到上一份工作的成功，保留目前錯誤。 |

狀態測例使用可控制完成時間的假 Worker。state-dirty-error 先 run initial，再 edit 成 edit 並重新執行。state-cancel-late 先 run draft、在回傳前取消、注入舊世代 lateResult，最後重設。state-replace-late 先掛起 olderDraft，再以 newerDraft 啟動新工作，先令新工作出錯，再注入舊世代 olderLateResult。每個 expected checkpoint 分別檢查畫面與下載。

另測合法上限、剛好超限、錯型別、額外欄、單獨 surrogate、惡意字串、快速改值及晚到訊息。測 exact、等距、重複數值的不同 token、相等容許差及超過 0.001 px、0/2,048 和 2,048.001、100/101 量測列。所有返回項驗絕對差最小及平手規則。
