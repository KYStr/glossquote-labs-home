## 公式與定義域的一手來源核對（2026-11-09）

- 風寒：Environment Canada 與美國 NWS 2001 年共同公式 `13.12 + 0.6215T − 11.37v^0.16 + 0.3965T·v^0.16`（T 為 °C、v 為 km/h、10 公尺高度風速），定義域 T ≤ 10 °C 且 v > 4.8 km/h（即 50 °F、3 mph）。概念筆記的常數與定義域與來源逐字一致，無修正。
- 熱指數：NOAA Weather Prediction Center「The Heat Index Equation」刊載的 Rothfusz 迴歸（NWS SR 90-23）九項係數與兩項調整（低濕 R < 13 且 80–112 °F 減去 `((13−R)/4)·√((17−|T−95|)/17)`；高濕 R > 85 且 80–87 °F 加上 `((R−85)/10)·((87−T)/5)`）逐字一致。概念筆記的工具定義域 T ≥ 27 °C、RH ≥ 40% 是本工具的釘版取捨（NWS 圖表實務上約自 80 °F 起用），已在 SPEC scope 明示。
- 一個查證後刻意不採的差異：加拿大環境部的作業實務是在 T ≤ 0 °C 才發佈風寒，並對 v < 5 km/h 另有低風速公式。本工具依概念筆記與聯合公式自身的有效域（T ≤ 10 °C、v > 4.8）釘版，低風速變體列為非目標，理由是同一工具不應混用兩套發佈慣例；已記錄於此供審查者判斷。
- Steadman 簡式預檢的省略有證明：NWS 程序在迴歸前先算簡式並與氣溫取平均，平均 < 80 °F 才用簡式。該平均對 TF、R 皆單調遞增，定義域內最小值在角落（TF=80.6、R=40）：簡式 = 0.5×(80.6＋61＋12.6×1.2＋40×0.094) = 80.24，平均 = (80.24＋80.6)/2 = 80.42 ≥ 80，故定義域內預檢恆選迴歸分支，省略不影響任何結果。低濕調整同理由（定義域 RH ≥ 40 > 13）永不觸發，仍保留於公式定義。

## Fixture 推導（手算＋獨立重算）

每個 expected 先依 SPEC 釘版規則逐步手算，再以一份獨立撰寫的腳本（另行實作驗證順序、模型選擇與兩公式）重算全部 16 個核心案例，結果 16/16 完全一致。兩個錨點的手算過程：

- `wc-classic`（T=−15、v=20）：v^0.16 = 20^0.16 ≈ 1.61497。WC = 13.12 − 0.6215×15 − 11.37×1.61497 − 0.3965×15×1.61497 = 13.12 − 9.3225 − 18.3622 − 9.6053 = −24.1700 → r = −24.2；delta = r(−24.1700＋15) = r(−9.1700) = −9.2。與已發表的同一範例（−24.17 °C）吻合。
- `hi-classic`（T=30 °C → TF=86、R=70）：九項逐步相加（中間值取 4 位小數）：−42.379 ＋176.2153 ＋710.0332 −1353.0276 −50.5726 −268.6041 ＋636.143 ＋359.379 −72.118 = 95.069 °F（腳本精算 95.0684，手算中間捨入差 0.001）；無調整觸發；換算 (95.0684−32)×5/9 = 35.038 → 35.0；delta = 5.0。
- `hi-high-rh-adjustment`（TF=82.4、R=90）：迴歸 92.7458 °F，高濕調整 ((90−85)/10)×((87−82.4)/5) = 0.5×0.92 = ＋0.46 °F，HI = 93.2058 °F → 34.0 °C，delta 6.0。調整值 0.46 是整數式手算可 exact 核對的設計點。
- `hi-corner`（27 °C、RH 40%）：HI = 80.3537 °F < TF 80.6，feelsLikeC 26.9、deltaC −0.1。此為迴歸擬合的真實性質，SPEC 釘版不夾擠並於 FAQ 說明，避免審查時被誤報為實作錯誤。
