# Object-fit Geometry Explorer — brief

## User problem and success
A frontend author has a raster's width/height and a fixed CSS content box, but cannot predict letterboxing, crop or alignment. Enter those dimensions, choose contain/cover and horizontal/vertical percentages, Generate, read the visible source rectangle and manually select deterministic CSS. No photo or URL is requested. Success means all geometry, explanation and output describe the same snapshot, not a promise about visual image quality.

## Bounded scope
Four integer dimensions1–4096; two integer percentages0–100; contain/cover only. Exact rational arithmetic, explicit half-away rounding, one proportional SVG schematic plus complete HTML values/fractions, zh-Hant/en, native controls, manual selection. No file/URL decoding, pixel crop/export, clipboard API, persistence, animation, arbitrary CSS or deployment. Native CSS corroboration is a future finite fixture check, not a claim that the schematic is native rendering.

## Distinction
This is not Image Resizer (actual file conversion), Print Size (physical/PPI), Contact Sheet (many images), Image Overlay (pixel comparison), Box Fit (3D packing), Grid (page cells), Fluid Typography, Elliptical Corners or Transform-Origin (rotation/scale around pivot).
