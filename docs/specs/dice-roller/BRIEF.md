# 骰子模擬器 / Dice Roller — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-dice-roller-20261109`

桌遊、TRPG 或程式測試要擲骰時，常見工具不是介面塞滿機率圖表，就是每次結果無法重現、無從核對。本工具只做一件事：把使用者輸入的骰式（`NdM`，可加 `±K` 修正）用釘版的種子化 mulberry32 逐顆擲出——每顆結果依擲出順序列出，附修正值與總和；同一種子永遠得到同一組結果，任何人都能事後重現核對。種子留空時由 app 以密碼學隨機填入並顯示，核心永遠不自產種子。

MVP 範圍。單一骰式欄位加一種子欄位、決定性擲骰（每顆恰取一次 PRNG）、逐顆結果與總和、固定 JSON 報告下載。非目標為機率分布／直方圖（理論分布由既有 `dice-sum-distribution` 規格負責）、平均／最大／最小等統計顯示、擲骰動畫、多組骰式或混骰、爆骰／保留最高等進階規則、歷史紀錄或儲存。

首個可觀察案例。一般擲骰（`example-2d6`）：骰式 `2d6`、種子 `42`，逐顆擲出 4、3，總和 7。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
