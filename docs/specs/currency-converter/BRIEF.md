# 匯率換算 / Currency Converter — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-currency-converter-20261109`

出國旅遊、海外網購或收付匯款時，使用者手上通常已經有一個實際匯率：銀行 App 的牌告價、匯款服務商的報價。一般匯率網站給的是市場中間價，跟他真正成交的數字不一樣，所以他需要的是把「自己那個匯率」輸入、金額在兩種幣別之間來回換算核對的工具，而不是另一個報價來源。本工具不提供任何匯率：正向乘匯率、反向精確除匯率，附 6 位有效數字的反向匯率顯示與 1／10／100／1000 快速對照表，並在頁面逐字常駐「匯率由你輸入、實際交易請向銀行確認」的免責聲明。

MVP 範圍。單一使用者輸入匯率、兩枚自由 3 字母幣別代碼（不對照 ISO 4217 清單驗證，清單會變動、誤拒風險大於效益）、兩方向換算、反向匯率與固定階梯對照表；全程整數 micro／分精確有理數運算，只在輸出捨入一次。非目標為取得或暗示即時匯率、多幣別連鎖換算、歷史匯率、手續費與價差建模、幣別符號與千分位格式。與舊作 unit-converter 的差異：該作五類皆物理單位、集合固定、無匯率概念；此處的匯率是使用者資料、方向語義是核心。
