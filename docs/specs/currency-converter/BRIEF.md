# 匯率換算 / Currency Converter — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-currency-converter-20261109`

出國旅遊、海外網購或收付匯款時，使用者可用銀行 App 的牌告價或匯兌服務商的報價，在兩種幣別之間換算核對。匯率欄初載及重設時留空。使用者可手填，或按「載入範例 / Load example」填入合成的 31.5。表單、成功結果與下載報告均標記匯率來源。使用者改填匯率後，來源切換為手填。本工具不取得或提供即時匯率。

MVP 範圍。單一手填或主動載入的合成匯率、兩枚自由 3 字母幣別代碼（不對照 ISO 4217 清單驗證）、兩方向換算、6 位有效數字的反向匯率與 1／10／100／1000 對照表。全程整數 micro／分精確有理數運算，只在輸出捨入一次。非目標為取得或暗示即時匯率、多幣別連鎖換算、歷史匯率、手續費與價差建模、幣別符號與千分位格式。與舊作 unit-converter 的差異在於本工具以匯率決定兩個方向的換算。

主動載入合成範例後，USD、TWD、匯率 31.5、金額 100 正向換算得 3150.00 TWD，顯示逆率為 0.031746（`default-forward`）。另以金額 30000、匯率 3 驗證反向精度，精確相除應為 1000000 分，顯示逆率 0.333333 若被拿來回乘會得到 999999 分。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
