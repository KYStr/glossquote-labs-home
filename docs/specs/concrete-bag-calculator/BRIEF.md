# 混凝土用量計算機 / Concrete Bag Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-concrete-bag-calculator-20261109`

假日自己鋪後院地坪、立圍籬柱的屋主站在建材行貨架前，手上有捲尺量好的長、寬、厚度（或柱子直徑與高度，單位公分）和要做的數量，卻不知道該搬幾包預拌混凝土：買少了中途不夠、接縫冷接，買多了整包退不了又重。本工具選形狀（平板／條形基礎／圓柱）、填公分尺寸、數量與損耗率（預設 10%），一次算出淨體積與含損耗體積（m³ 與 yd³），並列出 40／60／80 lb 三種預拌袋裝各需要幾包，讓他照最大包數那一列直接採購。

MVP 範圍。單一形狀、公制公分輸入、體積與三種固定袋裝產量的包數換算。非目標為鋼筋、級配或強度設計，拌合水量，多形狀混合加總，公制公斤袋裝（20／25 kg），價格估算，儲存或分享結果。

首個可觀察案例。平板預設範例含 10% 損耗（`slab-default-waste`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
