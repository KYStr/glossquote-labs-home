# 試織花樣針數表 / Knit Gauge Pattern Planner 製作簡報

預案 `spec-knit-gauge-planner-20261109` · 文件待獨立審查

織作者已有自己的試織片，想把矩形作品做到接近指定寬高，且邊針與圖樣重複必須完整。工具比較目標兩側最近的可行整針與整行。

桌面可在紙本圖樣旁核對試片密度、邊針與重複規則，並列查看較小／較大兩個成品尺寸。

手作桌邊只用手機，短列輸入試片後，結果直接顯示可起針數、應織行數和估計尺寸。

主要操作「找出可行針數與行數 / Find stitch and row counts」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
試片／目標與圖樣條件   |   針數與行數各自的近鄰尺

窄畫面（由上而下）
試片 → 作品 → 圖樣重複 → 最近針／行與兩側選項
```

首個貫通案例用 `knit-gauge-planner.repeats`。每針實測約 5 mm，兩側各 2 針、橫向重複 6。目標 103 mm 時相鄰可行 16、22 針，較近為 22 針。

用一個使用者實測的矩形試片估寬高。水平包括兩側邊針和至少一個圖樣。垂直只算整個行重複。每方向最大 10,000 針／行。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/knit-gauge-planner/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
