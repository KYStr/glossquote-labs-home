# 桌遊牌套庫存分配 / Card Sleeve Stock Fit 製作簡報

預案 `spec-card-sleeve-fit-20261109` · 文件待獨立審查

桌遊玩家已量不同卡族的外尺寸，手上有不同內尺寸與剩餘數量的牌套。想看怎麼分配才能覆蓋最多張卡，以及每族還少幾張。

桌面抄量尺與現有牌套袋數，並列查每種卡的套法、每種套的餘量。

在分裝桌用手機開啟某卡族，直接看應取哪個牌套、各幾張和缺口。

主要操作「分配現有牌套 / Allocate available sleeves」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
卡族／牌套庫存與餘隙   |   卡族分配與套庫存

窄畫面（由上而下）
卡尺寸 → 套尺寸 → 餘隙 → 分配 → 卡族與套餘量
```

首個貫通案例用 `card-sleeve-fit.reassign`。A 卡可用 S1 或 S2，B 卡只可用 S1，各只有一個。重新分配後 A 使用 S2，B 使用 S1，覆蓋 2 張。

1–8 種卡及 1–8 種牌套，固定寬高方向。每軸依同一最小及最大餘隙判斷相容。以整數容量分配最大已覆蓋張數。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/card-sleeve-fit/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
