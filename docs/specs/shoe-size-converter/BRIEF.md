# Shoe Size Converter — preparatory BRIEF v0.1

Specification documentation only; no product claim, readiness event or implementation. Full normative contract is SPEC.md.

## 1. Goal
Buying shoes from another country's store means translating a size label between systems that share no zero point and no unit — US, UK, EU and JP — and the web is full of conversion tables that disagree with each other and with the shoes that arrive. This tool converts through the one quantity all systems ultimately describe: foot length, in Mondopoint millimetres. The user picks a category (men, women, kids), then either enters a foot length in centimetres or a size in any one system, and reads the equivalent label in every system from a single table row. Its defining discipline is provenance: the tables ship as a data file transcribed from one named published source (the ISO/TS 19407-based conversion tables), with the source, row counts and a SHA-256 of the data file recorded alongside, verified at build time, and spot-checked by the independent reviewer — no row is ever hand-typed from memory, and the page says plainly that brands vary and trying on still matters. Success: the fixtures — taken from the cited source table, not from memory — reproduce exactly, in-between foot lengths round UP to the next size step (the ISO convention, so a converted size is never too small), and every conversion can be traced to one identified row of one identified table. No account, nothing stored.

## 2. Scope and functional distinction
Pinned in the SPEC: three categories (men, women, kids), each a table keyed by Mondopoint foot length in 5 mm steps; the adult table is the 22-row (215–320 mm) ISO/TS 19407-based table transcribed from the cited source (columns: Mondo, EUR, UK, US men, US women), and the kids table is transcribed from the same source article's children's tables under the same gate. Inputs: foot length 10.0–35.0 cm (0.1 steps), or a size label chosen from the active category's rows in any system (US / UK / EU / JP, where JP is the Mondopoint length in cm by definition). Lookup rule (normative): a foot length selects the smallest row whose Mondo is ≥ the length (round up); a label selects its own row exactly; all outputs come from that one row — never a formula, never interpolation. Out-of-table results are stated as out of range for the category, not extrapolated. Excluded: width fittings, brand-specific charts (the page states brands differ), half-system quirks beyond the table's own rows, and any fit guarantee.

Existing tools: Unit Converter converts bare quantities between units by formula; shoe sizes are not quantities — they are labels in offset systems, which is why this tool is table-driven with a cited source instead of arithmetic. No other catalog entry, reserved specification or registry task converts shoe sizes; fresh registry/path/draft check remains mandatory before admission. All fixtures are transcribed from the source table fetched at drafting (Wikipedia "Shoe size", Mondopoint conversion table, accessed 2026-11-02): foot exactly 270 mm, men → EUR 42.5, UK 9, US 10, JP 27.0; foot 263 mm rounds up to the 265 row → EUR 41.5, UK 8.5, US 9.5, JP 26.5; women's US 8 is the 245 row → foot 24.5 cm, EUR 38.5, UK 6, JP 24.5; men's EUR 44 is the 280 row → UK 10, US 11, foot 28.0 cm; foot 325 mm is beyond the adult table and reports out of range. Kids' labels are deliberately NOT asserted from memory anywhere in the fixtures: the kids table is verified at production review against the cited source, row by row counts and spot checks, as SPEC section 4 requires.
