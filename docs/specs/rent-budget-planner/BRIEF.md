# 租屋預算規劃 / Rent Budget Planner — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-rent-budget-planner-20261109`

在台中工作的 26 歲上班族，實領月薪 45,000 元，晚上用手機在租屋平台看套房，看到 12,000 到 15,000 元的物件不知道自己到底負擔得起哪一間，更不知道簽約當天要一次拿出多少現金——第一個月租金之外還有押金和仲介費，常聽說加起來是好幾個月租金。他手邊只有薪資數字和物件標價，需要立刻得到兩個答案：以他選的租金比例（25%、30%、三分之一或自訂）來看，租金上限是多少；以及對某間候選物件，簽約搬入要準備的總現金和每月繳完房租後還剩多少。

MVP 範圍。單一月收入、單一候選物件、整數新台幣。算出比例租金上限、候選租金占收入比、是否超標及超出額、搬入現金堆疊（第一個月租金＋押金月數＋仲介費月數）與每月餘額。非目標為多物件比較與排序、合租分攤、水電管理費估算、貸款或購屋試算、儲存或跨裝置同步、實際媒合或簽約。

首個可觀察案例。30% 比例下的標準情境（`standard-p30`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
