## 情景

跑者、教練、學生與體適能教練常在田徑場做兩種實地測驗：Cooper 12 分鐘跑（在固定時間內
盡量跑遠）與 1.5 英里計時跑（在固定距離內盡量跑快）。兩者都有公開、歷史悠久的公式可以
把成績換算成最大攝氧量（VO₂max，單位 ml/kg/min）——這是心肺適能最常被引用的單一指標。
這個工具讓使用者選一種測驗、填入成績，並可選擇性地填入年齡與性別，把估算值對照
Cooper Institute 的年齡／性別常模得到體適能分級。分級表是近似常模，工具必須誠實標示
這一點；公式在不合理的輸入（例如 12 分鐘只跑 500 公尺）下會給出非正值，工具必須明確
回報而非顯示 0 或負數。

## MVP 範圍

- 兩種測驗模式：`cooper12`（Cooper 12 分鐘跑，輸入距離，公尺）與 `mile15`
  （1.5 英里跑，輸入時間）。Cooper 公式
  **VO₂max =（距離 − 504.9）/ 44.73**（Cooper 1968）；1.5 英里公式
  **VO₂max = 483 / 時間（分鐘）+ 3.5**（ACSM 發布形式）。公式與常數在
  [`SPEC.md`](./SPEC.md) §1/§4 完整釘死並附出處。
- 結果四捨五入（半數進位）至小數 1 位，只捨入一次；分級查詢使用捨入後的值。
- 可選的年齡＋性別成對輸入：兩者都提供時，依年齡帶與性別查 Cooper Institute 常模
  六級分級表（very poor … superior）;兩者都不提供時分級為 `null`；只提供一個時回報
  成對必填錯誤。分級表逐格釘死在 [`SPEC.md`](./SPEC.md) §4 並標示為近似值。
- Cooper 結果捨入後 ≤ 0 時回報 `BELOW_RANGE` 欄位錯誤（距離 504.9 公尺恰好給出 0；
  距離 505 公尺捨入後同樣為 0.0），不顯示無意義的 0 或負數。
- 釘死的欄位順序、逐欄驗證順序（容量 → 未成對代理字元 → 必填 → 文法 → 範圍）、
  跨欄成對檢查與錯誤碼；非作用中模式的欄位只檢查容量與字元合法性，內容忽略
  （沿用 race-time 的既定規則）。
- 標準草稿／運算狀態機、固定下載 `vo2max-report.json`、中英雙語（zh-Hant 預設 + en）、
  靜態無後端、無追蹤；真實瀏覽器證據只標示狀態，不回填。

## 第一個可觀察案例

預設／範例草稿為 Cooper 12 分鐘跑、距離 `2400` 公尺、無年齡性別：公式給出未捨入值
42.3675…，捨入後 VO₂max = **42.4** ml/kg/min，分級為 `null`（見
[`fixtures.json`](./fixtures.json) 中 `cooper-basic`）。另有錨點：距離 2800 公尺 →
51.3；1.5 英里 12:00 → 43.8（43.75 的精確 tie，半數進位）。
