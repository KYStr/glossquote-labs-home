# Classical Cipher Lab — preparatory BRIEF v0.1

Specification documentation only; no product claim, readiness event or implementation. Full normative contract is SPEC.md.

## 1. Goal
Classical ciphers are how most people first meet the idea of encryption — in puzzle books, history classes and capture-the-flag warm-ups — and the fastest way to understand them is to work them: shift a Caesar cipher by hand, watch all 25 possible decryptions line up, see Atbash mirror the alphabet, run the textbook Vigenère example and get the textbook answer. This tool is that workbench, and it is honest about what it is: a permanent banner states these are classical ciphers, broken trivially by modern standards, for learning and puzzles only — never for protecting anything. Success: every fixture, including the canonical Vigenère example from the literature, reproduces letter-for-letter; the Caesar brute-force table shows all 25 candidate decryptions so the user — not the tool — judges which is the plaintext; and the transformation rules (only ASCII letters transform, case is preserved, the Vigenère key advances only on letters) are stated exactly, so two implementations cannot quietly differ. No account, nothing stored, text never leaves the page.

## 2. Scope and functional distinction
Pinned in the SPEC: four operations over a text of at most 10,000 characters — Caesar with shift 0–25 and encrypt/decrypt direction (ROT13 is the shift-13 preset of the same engine, not a fifth cipher); Atbash; Vigenère with a key of 1–64 ASCII letters (normalised to uppercase; any non-letter in the key field is refused, not stripped silently); and the Caesar brute-force table (for a Caesar ciphertext, all 25 non-trivial decrypt shifts with their candidate texts, each row labelled by shift). Transformation rules (normative): only A–Z and a–z are transformed; case is preserved letter by letter; digits, spaces, punctuation and all non-ASCII characters (including CJK) pass through unchanged; the Vigenère key index advances only when a letter is transformed. Excluded: any modern cipher (AES, RSA — named in the banner as what this is not), cryptanalysis beyond the Caesar table (no frequency scoring that declares a winner — rows are unranked), file encryption, and passwords of any kind.

Existing tools: Password Generator creates secrets with a CSPRNG and scores their strength — it produces randomness to keep; this tool deterministically transforms text the user supplies, with a key the user must remember themselves, and warns it protects nothing. JWT Decoder and the UTF-8 Base64 codec inspect modern data formats without any keyed transformation. Morse Code Translator maps characters to a signalling code with no key and no secrecy pretence. No other catalog entry, reserved specification or registry task implements classical ciphers; fresh registry/path/draft check remains mandatory before admission. All fixtures — Caesar shift 3 "Hello, World!" → "Khoor, Zruog!"; ROT13 "Hello" → "Uryyb" and twice-back to "Hello"; Atbash "Abc XyZ" → "Zyx CbA"; Vigenère key LEMON "ATTACKATDAWN" → "LXFOPVEFRNHR"; Vigenère key KEY "HELLO, WORLD" → "RIJVS, UYVJN" (comma and space do not consume key); and the brute-table row for "Khoor" at shift 3 reading "Hello" — are re-derived by script during drafting.
