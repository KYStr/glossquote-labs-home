## goal

資料工程師在切分資料處理責任、掃描門檻或連續索引區段前，想核對整個定義域內有沒有漏段或重複工作，並指回原列。

- 桌面。桌面貼起訖欄，檢查覆蓋表與有缺口的實際區間。
- 行動。手機在討論中查看兩個相接的區段是否被錯算成重疊。

使用情境為設計假設。資料只保留在目前頁面草稿。

## scope

同一單位的有限十進數半開 [lo,hi) 區段。輸出域內的整段覆蓋、缺口、交疊及來源，不做離散含端點計數、PDF 頁面、時間日曆轉換、估計曲線或擅自裁切越界段。

已與 registry r807 的 130 份預案比對，最相近者的實質差異如下。

- 操作離散 PDF 頁及檔案。此處無檔案，以半開數值域報長度和來源。 [spec-pdf-page-tools-v1](https://github.com/KYStr/glossquote-labs-home/blob/8b5927312de2410de298f43f7f6fbe05184597da/docs/specs/pdf-page-tools/SPEC.md)
- 用時間空檔求交集。此處連續十進數分割，可有負數，需報全域缺口、所有 active rows 和重疊長度。 [spec-34-meeting-overlap](https://github.com/KYStr/glossquote-labs-home/blob/be197ea30d909b1353e7f77bdf16b1811ac41f71/coordination/local/2026-10-29/specs/34-meeting-overlap/SPEC.md)

判定規則由本文定義，無線上資料或外部服務依賴。

## userFlow

採 Gloss Tools Product App。遵守設計系統的 paper/ink、間距、焦點和斷點。寬版以輸入與結果相鄰，結果擁有最多空間。窄版依輸入、主操作、狀態、結果直排。首屏見主工作和常用設定，詳細格式用一層 disclosure。

- 欄位或說明「覆蓋域起點與終點 / Domain start and end」
- 欄位或說明「區間起訖（Tab 分隔） / Interval endpoints, separated by Tab」
- 「檢查區間覆蓋 / Audit coverage」是主要操作。「載入範例 / Load example」填入 [fixtures.json](fixtures.json) 第一個合成案例，明示範例並等待手動執行。
- 「缺口、覆蓋與重疊來源 / Gaps, coverage and overlap sources」先摘要再列細節，長表在有 label 的區域捲動。超過 25 列採 25 列分頁、上下頁可鍵盤操作，完整匯出不截斷。成功才顯示「下載報告 / Download report」。文字可手動選取。

| 狀態 | 操作與結果 |
| --- | --- |
| empty | 初載／重設，無結果，提示輸入或載入範例。 |
| dirty | 任一輸入、選項、來源或範例改變，立即撤銷舊結果和下載。顯示「輸入已變更，請重新執行 / Input changed. Run again.」。 |
| busy | 明確執行時處理快照，顯示「處理中 / Working」及「取消 / Cancel」。無下載。編輯終止舊工作並回 dirty。 |
| success | 報告對應目前快照。空結果有說明。若含待修列，以文字及符號提示。 |
| error | 保留草稿，沒有結果。顯示本地化錯誤、欄位及適用列號。只有提交失敗才移焦首錯欄。 |
| cancelled | 保留草稿，終止並告知「已取消，可重新執行 / Cancelled. You can run again.」。舊結果仍無效。 |

「重設 / Reset」停止工作，復原預設 `{"start":"0","end":"10","intervals":""}` 並聚焦首來源欄。標籤不可只用 placeholder。用 aria-busy 和 polite 回報狀態，以 aria-describedby/aria-errormessage 連結錯誤。語言連結旁揭露切語或離頁會失去草稿。沒有登入或權限要求。頁面載入後可離線計算，Worker 失敗保留草稿供重試。

## inputsOutputs

核心 `run(input)` 為同步純資料轉換。參數含下列確切欄位的普通物件，只讀 own data。未知、缺欄、錯型別、accessor 皆 SCHEMA，field,row=null。JSON fixture 即介面。textarea 以 DOM 的 LF 值為準。明示檔案欄才處理原始 bytes。

- start、end: string，十進數文法 -?(0|[1-9][0-9]{0,9})(\.[0-9]{1,3})?，無前後空白、加號或 exponent。範圍 -1,000,000,000…1,000,000,000，start<end。預設 0、10。
- intervals: string，最多 16,384 UTF-16 單元，0–200 個 LF 列，可去一個尾 LF，空字串為零區間。每列恰 lo HT hi，兩數同域文法，lo<hi 且 start≤lo<hi≤end。

先容量、再 surrogate、再該欄文法，跨欄和逐列順序依下文。未另外指明時容量 INPUT_LIMIT、缺內容 EMPTY、超列 ROW_LIMIT、不成對 surrogate UNICODE。整份失敗回 `{ok:false,error:{code,field,row}}`，field 為欄位名或 null，row 為明示 1-based 來源列／操作序號或 null。成功僅為 `{ok:true,result}`。資源或 Worker 失敗用固定 INTERNAL/WORKER_ERROR，不回傳堆疊。

1. 先驗 start（ENDPOINT）再 end（ENDPOINT）。域順序錯 DOMAIN_ORDER，field=end。再檢查 intervals 容量、Unicode、列數。逐列欄數 ROW_FORMAT、數值 ENDPOINT、lo≥hi INTERVAL_ORDER、越出域 OUTSIDE。沒有交換端點或裁切。
2. 所有端點轉 BigInt 千分位，負零變零。事件含端點起始加 row、結束移除 row。域兩端也納入排序。由小到大走相鄰不同端點 x<y。先在 x 批次移除到期再加入從 x 起始者，對 [x,y) 擷取 active rows 升序。相接端點沒有零寬段且不同來源不會同時計入。
3. 結果 {spans,covered,uncovered,overlapped}，spans 為 {from,to,depth,lines}，由小到大，depth=lines.length。若相鄰 spans 的 lines 完全相同則合併。depth≥1 的長度計 covered，depth=0 的計 uncovered，depth≥2 的另計 overlapped，每個位置不因 depth>2 多計。端點與長度皆標準 ASCII 小數字串，去不必要前導及尾零、無負零，無四捨五入。
4. 結果標示使用者自定單位和右端不含。長度值代表連續差值。任何合法域 covered+uncovered=end−start。行號依 intervals 的物理列從 1 起算。

固定下載 `range-coverage-audit-report.json`。內容為 result 的 compact JSON、object own keys 按 UTF-16 code units 升序遞迴排列，array 順序不改，末尾一個 LF、UTF-8 無 BOM。字串用 JSON 字面轉義，不呼叫輸入的 toJSON。報告上限 2,097,152 bytes，超過 OUTPUT_LIMIT 並停用所有產物。其他副本只依上列精確規則。機器值不隨 locale 改。

## implementation

使用原生 HTML/CSS/ESM 與 Node 24 built-ins，零 runtime／建置依賴。候選目標 `tools/range-coverage-audit/`。src/core.mjs 放純驗證、推導、格式化。src/controller.mjs 管草稿、工作世代及資源。src/app.mjs 用安全 DOM API 綁表單。public/index.html 和 public/en/index.html 為兩個靜態入口。Node scripts 只建置工具 allowlist，不取線上檔、不發布。

- 工作開始先使舊結果失效並遞增世代號。Node 建置時從固定 source bytes 嵌入純核心及固定訊息處理器，頁面載入後從該固定字串建立 module Worker Blob URL。禁止使用者內容參與程式、eval、new Function 或動態 import。測試 import 同一份核心。
- Worker 每次只收目前快照及世代號。取消、換來源、重設、替換或 pagehide 時 terminate 並釋放結果及 URL。只收目前世代且 busy 的結果。成功後也停止 Worker。bfcache 回來重設。不能取消的 File.arrayBuffer 晚到也丟棄。明確點下載才建 Blob URL，30 秒內撤銷，結果失效即提早撤銷。
- 表格與預覽用 textContent/value。輸入不當標記、style、selector、href、src 或檔名。禁 fetch、XHR、WebSocket、beacon、analytics、遠端字型、上傳、帳號、剪貼簿、持久 storage、service worker。工作內容不進 URL、history、console、日誌或執行證據。離頁丟棄引用，無安全抹除承諾。
- 正式與預覽均用同源靜態資產。CSP default-src none、script-src self、style-src self、worker-src blob:、img-src self、connect-src none、object-src none、base-uri none、form-action none、frame-ancestors none。self/none 加單引號。另設 nosniff、no-referrer 並拒絕 camera/microphone/geolocation 權限。語言和首頁連結是固定導航。

## tests

驗收輸入見 [fixtures.json](fixtures.json)。7 個字面核心案例與 3 個 controller 案例。對每個 expected 深度比對，下載用獨立序列化驗 bytes 和 SHA-256。不得用產品程式產生 expected。

| 案例 ID | 驗證行為 |
| --- | --- |
| `gap-and-overlap` | 同時有一個重疊及一個空段 |
| `negative-touch` | 負小數跨零，相接不重疊 |
| `duplicate-interval` | 同區間兩列保持 depth 2 |
| `triple-depth` | 重疊長度不依深度重複相加 |
| `no-intervals` | 空清單顯示全域缺口 |
| `outside` | 超過域端點，禁止裁切 |
| `zero-length` | 零長度區間拒絕 |
| `state-dirty-error` | 先產出真結果，再改為無效輸入，舊結果及所有下載立即失效。 |
| `state-cancel-late` | 延遲成功後取消，舊回傳不能復活，重設回預設值。 |
| `state-replace-late` | 新工作失敗後收到上一份工作的成功，保留目前錯誤。 |

狀態測例使用可控制完成時間的假 Worker。state-dirty-error 先 run initial，再 edit 成 edit 並重新執行。state-cancel-late 先 run draft、在回傳前取消、注入舊世代 lateResult，最後重設。state-replace-late 先掛起 olderDraft，再以 newerDraft 啟動新工作，先令新工作出錯，再注入舊世代 olderLateResult。每個 expected checkpoint 分別檢查畫面與下載。

另測合法上限、剛好超限、錯型別、額外欄、單獨 surrogate、惡意字串、快速改值及晚到訊息。驗證相接端點、完全相同列、三層 overlap、空清單、負小數跨零與小數末位精確。covered+uncovered 守恆，overlapped≤covered。測絕對值上界、1,000,000,000.001、200/201 列。
