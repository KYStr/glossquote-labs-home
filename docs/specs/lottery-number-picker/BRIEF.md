# 樂透選號器 / Lottery Number Picker — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-lottery-number-picker-20261109`

用自己記得住的種子，為大樂透、威力彩、今彩539 產生可重現的選號：同一個種子永遠產生同一組號碼，每種組合出現的機會都相等。

情境。一位上班族每週買一張大樂透，習慣自己選號，不想用投注機的電腦快選——快選無法重現，下週對獎或想沿用同一組時叫不回來。他在超商排隊時用手機打開本工具，手上有三樣東西：自己定的種子（例如生日數字）、想買的組數、以及一串不想出現的號碼（全家人的生日號碼）。卡住的是：自己隨手選容易重複、容易偏在低號碼，又沒辦法驗證「換個種子就是另一組」。可用結果是：輸入種子、組數與排除號碼後，得到排好序、可直接抄上投注單的號碼組，同種子下次還能原樣重現。

MVP 範圍。三種遊戲固定規則（大樂透第一區 6/49；威力彩第一區 6/38＋第二區 1/8；今彩539 5/39）、固定種子的決定性產生器（mulberry32，逐位固定）、1–10 組、第一區排除清單、升序顯示、複製與文字檔下載。非目標為開獎結果查詢、對獎、號碼統計或熱門分析、任何預測或提高中獎率的宣稱、購買彩券、儲存與帳號。

首個可觀察案例。大樂透種子 42 產生 3 組（`lotto649-basic`），證明 PRNG 串流跨組連續。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
