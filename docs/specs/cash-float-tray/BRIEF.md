# 收銀盤留款清點 / Cash Float Tray 製作簡報

預案 `spec-cash-float-tray-20261109` · 文件待獨立審查

攤位收攤時已有各面額的實點件數，需要從同一盤留出指定現金額，再照件數移出其餘現金。結果逐列告訴人員留幾件、移出幾件，以及湊不到指定額時的差額。

桌面使用者可依面額多列輸入後，由大至小核對留盤／移出。適合在紙本班次紀錄旁比較清點。

在現場面額格旁用手機輸入，每列的兩種件數放在同一可讀項，避免左右滑動讀錯欄。

主要操作「算出留盤與移出 / Split the cash tray」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
目標與實點面額列   |   留盤／移出雙欄件數與金額

窄畫面（由上而下）
單位說明 → 目標 → 實點件數 → 留盤與移出分列
```

首個貫通案例用 `cash-float-tray.exact`。6×1、4×2、3×3，留款 10。留 6 和 4 各一件，移出 13。

清點 1–8 種使用者自填面額，固定同一最小計量單位。給定留盤額，優先找最接近且不高於目標的組合，同額時件數最少，再以高面額數量作固定決勝。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/cash-float-tray/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
