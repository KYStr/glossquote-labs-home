# 加價率與毛利率換算 / Markup & Margin Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-markup-margin-calculator-20261109`

小商家或賣家定價時最常混淆的一組數字：同一筆利潤，除以成本是加價率、除以售價是毛利率，兩個百分比不一樣，反推售價的公式也不同。本工具把三個方向一次講清楚並算到底：成本＋售價 → 加價率與毛利率；成本＋目標加價率 → 售價；成本＋目標毛利率 → 售價。

MVP 範圍。三種求解模式，共用整數分與千分之一百分比的精確有理數運算（沿用分帳計算機的 BigInt 先例），百分比顯示至小數點後兩位。目標毛利率 ≥100% 時沒有有限售價，釘版為語意狀態 NO_SOLUTION，不是範圍錯誤；售價低於成本照常報表（負值），不是錯誤。非目標為多商品或價目表批次計算、含稅價換算（屬含稅未稅換算範圍）、損益平衡數量（屬損益平衡點範圍）、折扣促銷價（屬折扣計算範圍）、币別換算與歷史價格儲存。

首個可觀察案例。成本 80.00、售價 100.00 → 加價率 25.00%、毛利率 20.00%（`report-basic`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
