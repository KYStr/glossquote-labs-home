- 尺寸表取捨（概念筆記的 JP／UK 欄有多個互相矛盾的版本，作者查證後固定如下，並記錄理由）：
  - 內圍／美圍／歐圍：採國際通用珠寶商轉換表（以 ISO 8653 內圍為準）的一致欄位。2026-11-09 以公開來源交叉確認錨點：美圍 3 = 44.2 mm、5 = 49.3 mm、6 = 51.9 mm、7 = 54.4 mm、8 = 57.0 mm、13 = 69.7 mm，歐圍 = 內圍四捨五入至整數。
  - 英圍：公開表在整字母（F、H、P…）與半字母（F½、H½、P½…）間不一致；作者採與錨點一致的半字母欄——美圍每進半號、英圍進一個字母，自 F½ 起，US 5 = J½、6 = L½、6.5 = M½、7 = N½、13 = Z½ 均經至少兩家公開轉換表確認。概念筆記原稿的 UK 欄（如 57.0 → R½）跳字母不連續，未採用。
  - 日圍：各家表差異最大（同一美圍 9 有 18／19／20 三種說法），不抄單一商家表。改依 JIS S 4700 直徑定義（1 號內徑 13.0 mm、每號 +1/3 mm）由內圍反推，JP = round(3 × 內徑 − 38)，並把 21 列結果逐列寫死在 SPEC；錨點 US 5→9、6→12、6.5→13、7→14、9→19 與公開轉換表多數值一致。US 8 本公式得 16，部分商家表作 17（其作法多為「歐圍 − 40」近似），規格已在固定文案明示品牌可差一號、購買前實測。
  - 概念筆記「40–70 mm、0.5 mm 步進主表」與本批固定作法（21 列美圍半號表＋連續換算）的差異：主表改以公開轉換表的美圍半號列為字面資料；內圍／內徑／歐圍／日圍仍全域連續計算，不受列表步進限制，正規窗維持 40.0–70.0 mm。

- π 捨入邊界驗證（作者窮舉，支持 SPEC 的 inputsOutputs 主張）：正規內圍 circH 遍歷 4000–7000 時，日圍公式量距最近 .5 邊界最小 1.5e-4（circH 6545）、內徑顯示量最小 1.4e-5（circH 5325）；內徑輸入 diaH 遍歷 1280–2220 換內圍時最小 3.8e-3；日圍輸入 n 遍歷 1–28 換內圍時最小 3.8e-3。全部遠大於 IEEE-754 double 誤差（約 1e-12），故規格以實數語意定義、實作以 double 計算，結果恆一致。
