# 單車齒比與展開表 / Bicycle Gear Rollout Table 製作簡報

預案 `spec-bicycle-gear-table-20261109` · 文件待獨立審查

騎乘者或單車維護者已實測輪子轉一圈的距離，想看現有前齒盤與後飛輪各組的齒比、每踩一圈的前進量、指定踏頻的理論速度，並辨識重複齒比。

在維修桌用桌面抄齒數並用齒比表比較跨度。同齒比併一列，仍能看到原齒組。

手機旁量輪周，輸入後依比值順序逐列讀取，不必掃整個齒輪矩陣。

主要操作「列出齒比與前進量 / Compare gear rollouts」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
實測輪周與踏頻／齒數   |   齒比升序及相同組合

窄畫面（由上而下）
輪周／踏頻 → 齒數 → 展開表 → 比值與所有同組合
```

首個貫通案例用 `bicycle-gear-table.group-ratios`。前齒 40、20 和後齒 10、20 形成 1、2、4 倍。40/20 和 20/10 同列，80 rpm 時該組顯示 20.2 km/h。

最多 3 個前齒數、16 個後齒數，列出全部理論組合、精確同齒比分組。只使用使用者輸入的輪周與踏頻。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/bicycle-gear-table/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
