# 折扣計算機 / Discount Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-discount-calculator-20261109`

消費者在百貨週年慶拿著促銷傳單：會員八折、再享九折，還有一張滿額折價券，含稅與否寫得不清。他想用手機當場算出這件商品最後到底付多少、是不是真的省到三成。手上只有吊牌價、傳單上的折扣與券額，以及店員說的稅率。口算把 20%＋10% 當成 30% 就估錯了；稅在折扣前或折扣後計，也差一截。

MVP 範圍。單一商品：原價、最多兩重百分比折扣、定額折價券、折扣後計稅、數量；輸出逐步價格明細、最終單價與總價、共省金額、有效折扣 % 與約幾折。非目標為多商品購物車、跨商品或單位價格比價、運費／分期／點數回饋、讀取電商頁面、判斷促銷是否真實或划算。

首個可觀察案例。兩重折扣疊加與折扣後計稅（`stacked-discounts-with-tax`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
