# 債務清償規劃 / Debt Payoff Planner — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-debt-payoff-planner-20261121`

同時背著多筆債務（信用卡、信貸、店內分期）的人，填上每筆餘額、年利率、最低還款與每月能多還的金額，比較雪球法與雪崩法各自要幾個月還清、總利息差多少。

MVP 範圍。1–12 筆債務的固定月還款模擬，兩種策略各算一次：雪球法（餘額由小到大）與雪崩法（年利率由高到低），輸出還清月數、總利息、每筆還清月份與逐月彙總表。非目標為單一貸款攤還表、即時利率查詢、費用／稅務、債務協商推薦、儲存檔案，以及任何「銀行會用相同捨入」的宣稱。與單卡試算（`tools/credit-card-payoff-calculator`）的差異：此處是多筆債務的整體規劃與策略比較，單卡只是退化為一筆時的特例。

首個可觀察案例。雪球法與雪崩法排序不同、利息不同（`snowball-vs-avalanche`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
