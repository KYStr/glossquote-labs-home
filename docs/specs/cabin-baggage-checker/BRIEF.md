# 手提行李規定檢查 / Cabin Baggage Checker — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-cabin-baggage-checker-20261109`

旅客阿哲在台中家裡打包，準備去東京，手邊是網購頁面標示 55×35×22 cm 的登機箱，裝滿後家用秤量到 6.5 kg。他可能搭長榮，也可能改訂虎航或 ANA 的班次，現在卡在：同一只箱子到底在哪幾家能直接登機、哪一家會被擋、是尺寸差一點還是重量超標。他打開手機上的這個工具，填入三邊與重量（個人物品先不帶），一次得到六家逐家判定：五家符合、只有台灣虎航因長邊上限 54 cm 不合格，差距 −1.0 cm，一目了然，不必逐家翻官網。

MVP 範圍。一件主行李＋一件選填個人物品，對寫死的六家航空公司（長榮、中華、星宇、台灣虎航、全日空、日本航空）經濟艙國際線規定逐家比對：三邊排序後逐邊比較、重量依主行李制或合計制判定、個人物品尺寸（有公告者）判定，逐家列 pass/fail 與差距，總覽「符合所選 M 家中的 N 家」。規定表查核日期 2026-11-09 寫死在規格內。非目標為托運行李、商務／頭等艙、國內線與小機型規定、三邊總和替代判定、超額費用、即時連線查詢與行李箱推薦。
