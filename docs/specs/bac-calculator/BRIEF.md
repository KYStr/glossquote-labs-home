# 酒精濃度估算 / BAC Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-bac-calculator-20261109`

聚餐或應酬後，使用者想知道自己喝下的酒量大約對應多少血液酒精濃度、離台灣酒駕的行政與刑事門檻還有多遠、估計還要多久才會代謝到門檻以下。本工具以 Widmark 公式推估，輸入性別、體重、一到多杯飲料（容量 ml × 酒精濃度 %）與距開始飲用的經過時間，輸出推估血液酒精濃度（g/L 與 %）、吐氣酒精濃度換算值、對照的法定區間，以及代謝到門檻以下與歸零的推估分鐘數。

MVP 範圍。單一時間點的 Widmark 推估：全部飲料視為在開始飲用時一次攝入，之後以固定速率線性代謝。非目標為逐杯時間軸、分段吸收模型、呼氣或血液檢測、醫療診斷、執法判定、把推估值當作可以安全駕駛的依據。結果旁常駐強聲明：僅供推估、個體差異大、喝酒不開車。

首個可觀察案例。一瓶 350 ml、5% 啤酒，70 kg 男性，剛喝完（經過 0 分鐘）：推估濃度 0.290 g/L、吐氣換算 0.145 mg/L，未達行政門檻但接近。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
