# 損益平衡計算 / Breakeven Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-breakeven-calculator-20261109`

小攤商、工作室或接案者手上有每月固定成本、單位售價與單位變動成本，要算出至少賣幾件、做到多少營收才打平，並在給定預期銷量時看到安全邊際與預期利潤；售價不高於變動成本時，工具說明為何無法提供以正貢獻攤平固定成本的唯一銷售門檻，並依售價和固定成本說明何時會打平或虧損。

MVP 範圍。單一產品、單一幣別；固定成本／單位售價／單位變動成本三個金額輸入（整數分精確運算），輸出單位邊際貢獻、邊際貢獻率、損益平衡銷量（理論值＋無條件進位的整數單位值）、損益平衡營收（理論值＋整數單位值）；選填預期銷量時加安全邊際與預期利潤。非目標為多產品組合、階梯定價、稅費、折現、非線性成本、圖表、歷史紀錄。

首個可觀察案例。非整數理論銷量的進位與兩個營收數字（`ceil-rounds-up`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
