# 完賽時間預測 / Race Time Predictor — BRIEF

**既有工具升級提案，產品檢查 NOT_RUN** · `spec-race-time-predictor-20261109`

跑者比完一場 10K 後想知道「照這個狀態，全馬大概跑多久」，或反過來用一場全馬成績回推 5K 實力。手邊只有一筆完賽成績（距離＋時間），需要的是一張用具名公式算出、連同等值配速一起列出的跨距離預測表，而不是訓練計畫或即時定位。

預測流程範圍。單筆已知成績輸入，Riegel 公式 `T2 = T1 × (D2/D1)^1.06`（指數 1.06 釘版），輸出 5K、10K、半馬、全馬四個標準距離加一個選填自訂目標距離的預測時間與每公里等值配速。非目標為配速／時間／距離三欄求解、分段配速表（split table）、英里單位、GPS／地圖輸入、海拔或天氣修正、訓練計畫、成績保存或分享。

既有 Running Pace Calculator 已可直接輸入時間與距離，並以 Riegel 1.06 預測四個標準目標。本提案聚焦一個選填自訂目標距離，以及簡化使用既有預測的流程。詳見 [SPEC.md](SPEC.md) scope 節。

首個可觀察案例。10K 40:00 推全馬（`classic-10k`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。

後續以獨立任務整合到既有 Running Pace Calculator，再於同一候選交驗核心／狀態、雙語頁、匯出、build/check 和九面向證據。
