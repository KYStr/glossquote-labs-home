# 完賽時間預測 / Race Time Predictor — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-race-time-predictor-20261109`

跑者比完一場 10K 後想知道「照這個狀態，全馬大概跑多久」，或反過來用一場全馬成績回推 5K 實力。手邊只有一筆完賽成績（距離＋時間），需要的是一張用具名公式算出、連同等值配速一起列出的跨距離預測表，而不是訓練計畫或即時定位。

MVP 範圍。單筆已知成績輸入，Riegel 公式 `T2 = T1 × (D2/D1)^1.06`（指數 1.06 釘版），輸出 5K、10K、半馬、全馬四個標準距離加一個選填自訂目標距離的預測時間與每公里等值配速。非目標為配速／時間／距離三欄求解、分段配速表（split table）、英里單位、GPS／地圖輸入、海拔或天氣修正、訓練計畫、成績保存或分享。

與 Running Pace Calculator 的區隔。兩者都支援自訂已知距離，並以 Riegel 1.06 預測四個標準距離的時間與配速。本工具提供直接從已知成績執行預測的流程，以及一個選填的自訂目標距離。詳見 [SPEC.md](SPEC.md) scope 節。

首個可觀察案例。10K 40:00 推全馬（`classic-10k`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。

先完成核心／狀態測試，再交雙語靜態頁、匯出、build/check、同一候選的九面向證據。目標 `tools/race-time-predictor/`，固定分支與 PR 交驗。
