# 串珠花樣用量與順序 / Bead String Pattern 製作簡報

預案 `spec-bead-string-pattern-20261109` · 文件待獨立審查

串珠者有一段固定顏色花樣，打算反覆或交替鏡像串起來。想在上線前確認每個珠位、各色用量、剩餘，以及第一個會缺的珠位。

桌面並列花樣、顏色存量與逐段展開，可比較要重複幾組才用到手上的顏色。

手作桌上逐格讀短名與編號。每顆珠用文字區別，同色也能辨識位置，不需拖曳。

主要操作「展開串珠順序 / Lay out the bead order」。工作區採 Product App。頁面中優先呈現以下工作物。

```text
寬畫面
顏色庫存／花樣編輯   |   珠位長條＋用量與缺色

窄畫面（由上而下）
顏色 → 花樣次序 → 重複／端珠 → 展開 → 珠位清單
```

首個貫通案例用 `bead-string-pattern.mirrored`。前後各 K 一珠，R、G、B 鏡像兩組，得到 K/R/G/B/B/G/R/K。G 只有 1，位置 6 缺。

1–12 色、1–16 珠花樣、1–32 組、可加前後端珠。展開直複或奇偶組交替倒序，以位置標示各色缺料。

產品界線與輸入、算法、九面向、測試、交接以 [規格](SPEC.md) 為準。起手先將 [字面案例](fixtures.json) 固定在 Node 24 離線測試，再接兩語操作。完成後固定 `tools/bead-string-pattern/` 候選及 open PR head，將真實檢查結果交主責。這份簡報的產品、瀏覽器、正式站 gate 全為 `NOT_RUN`。
