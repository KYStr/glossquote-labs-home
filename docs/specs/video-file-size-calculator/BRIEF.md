# 影片檔案大小估算 / Video File Size Calculator — BRIEF

**文件草案，產品檢查 NOT_RUN** · `spec-video-file-size-calculator-20261109`

週末要拍家庭活動的阿哲，手邊只有一張 64 GiB 記憶卡，相機選單在 1080p30、1080p60 與 4K30 之間。他想在出門前先確定：照習慣的設定錄，這張卡裝得下幾小時？另一種日常情境是剪完片要上傳或備份前，先估 10 分鐘 4K 成品大概多大，免得傳到一半才發現空間或流量不夠。

MVP 範圍。兩種互逆的估算：(1) 檔案大小模式——片長 ×（視訊位元率 × 編碼係數 + 音訊位元率）÷ 8，同時給十進位（MB/GB）與二進位（MiB/GiB）大小；視訊位元率來自寫死的解析度預設表（標明為 H.264 常見經驗值）或自訂 Mbps。(2) 可錄時長模式——給目標容量，反推在相同位元率設定下最長可錄的整秒數與實際占用、剩餘空間。非目標為讀取真實影片檔、量測實際位元率、轉檔/編碼、串流碼率規劃、容器封裝分析；預設位元率與編碼係數是經驗值，不是任何相機或平台的保證值，固定揭露於結果旁。

首個可觀察案例。預設 1080p30 錄 10 分鐘（`preset-1080p30-basic`）。字面資料與預期見 [fixtures.json](fixtures.json)，契約以 [SPEC.md](SPEC.md) 為準。
