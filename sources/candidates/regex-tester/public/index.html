正規表示式測試與取代

本工具使用瀏覽器內建的 ECMAScript（JavaScript）RegExp 引擎——你在這裡驗證的，就是你的 JavaScript 程式會做的事；不同 regex 風格（PCRE、Python、Java、.NET）的行為並不相同，樣式不可直接互換。全部運算都在你的裝置上進行，樣式與測試文字不上傳、不儲存、不寫入網址。

注意：病態樣式（例如巢狀量詞配上大量文字）可能讓這個分頁凍結，因為 JavaScript 的正規表示式無法中途喊停。本工具不提供「逾時」或「安全模式」；輸入長度上限（樣式 500 字元、文字 50,000 字元、取代字串 1,000 字元，皆以 Unicode 碼點計）是唯一的緩解措施。

  • 支援回顧斷言（lookbehind）與具名群組 (?<name>…)。
    • 
      
  • 不支援佔有量詞、原子群組、平衡群組與 \G。
    • 
      
  • \d 只符合 ASCII 數字，即使開啟 u 旗標也一樣。
    • 
      
  • . 不符合換行等行終止符，除非開啟 s 旗標。
    • 
      
  • 符合上限為 1,000 筆，達到上限會明說並標示清單為部分結果。
    • 
      
  • 未參與的群組與符合空字串的群組分開標示，不會混為一談。
