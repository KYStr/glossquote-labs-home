JWT 解碼與主張檢視

在本機瀏覽器中解碼。簽章未經驗證——任何人都能偽造這些內容。絕不要貼上你不願意給同事看的 token。

貼上三段式 token（標頭.酬載.簽章），即在本機解碼標頭與酬載的 JSON，把 exp、nbf、iat 等時間主張換算成本機時間，並對照裝置時鐘陳述狀態。本工具只解碼、不驗證：不連網、不儲存、不把 token 寫入網址；離開或重整分頁，token 即消失。

狀態只陳述時間主張與裝置時鐘的關係——簽章未經驗證。

    使用說明與限制
    
    
      
  • 本工具解碼三段式 token；五段式輸入是 JWE（加密的 JWT），本工具不解密。
    • 
      
  • 時間狀態以這台裝置的時鐘為基準：裝置時鐘錯誤，讀數就錯誤。
    • 
      
  • alg 只照實顯示：alg=none 與任何其他 alg 值相同看待，不特別信任。
    • 
      
  • JSON 物件內若有重複的鍵，依 JSON.parse 語意以最後一個為準；漂亮列印無法同時顯示兩者。
    • 
      
  • 輸入上限為 16,384 個字元；超過即拒絕，不截斷。
    • 
      
  • 文件與測試中的範例 token 皆為合成資料，其簽章段是假字串，不是真正的 HMAC。
