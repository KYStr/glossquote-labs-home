JWT Decoder and Claims Inspector

Decoded locally in your browser. The signature is NOT verified — anyone can forge these contents. Never paste a token you would not show a colleague.

Paste a three-part token (header.payload.signature) to decode its header and payload JSON locally, translate the exp, nbf and iat time claims into local times, and read a time status stated against the device clock. This tool decodes only — it never verifies: nothing is uploaded, stored, or placed in the URL, and leaving or reloading the page discards the token.

    Help and limits
    
    
      
  • This tool decodes three-part tokens; a five-part input is a JWE (an encrypted JWT), which this tool does not decrypt.
    • 
      
  • Time readouts use this device's clock as the reference: a wrong device clock yields a wrong readout.
    • 
      
  • alg values are reported, never judged: alg=none is displayed like any other alg value and receives no special trust.
    • 
      
  • Duplicate keys inside a JSON object follow JSON.parse semantics (last wins); the pretty printer cannot show both.
    • 
      
  • The input limit is 16,384 characters; longer input is rejected, not truncated.
    • 
      
  • The sample token in the documentation and tests is synthetic; its signature segment is a dummy string, not a real HMAC.
