How to use it and its limits

The integer range is 1 to 3999. Roman numerals have no zero, so 0 is not a conversion result but an error that explains why; values from 4000 on need overline (vinculum) notation, which is out of scope and likewise refused with an explanation rather than improvised.

The Roman field accepts at most 15 characters (the longest canonical form, 3888 = MMMDCCCLXXXVIII, is exactly 15). Lowercase input is treated as uppercase; a space inside the field is an invalid character and its position is named. While a field is invalid, the other field and the breakdown stay at their last valid values, marked out of date, and the copy buttons are disabled so a stale conversion can never be copied as if current.

Traditional clock faces often write 4 as IIII as a design convention; this tool reports the canonical form IV only and offers no IIII mode.

Taking entries from the top down, as many times as each fits, is exactly how the canonical form is generated; the breakdown comes from the same process, so it can never disagree with the displayed string.

What counts as canonical

There is one test: read the input symbol by symbol into its loose value (subtract a symbol when a larger one follows, otherwise add), then regenerate that value with the greedy table. The input is canonical only if the regenerated string is identical. The familiar corollaries follow from this definition and are explanation, not extra checks: I, X, C and M repeat at most three times; V, L and D never repeat; subtraction appears only in the six table pairs (IV, IX, XL, XC, CD, CM).

Frequently asked questions

Why is IC not 99?
Because subtraction may only use the symbol one step below: 99 splits into 90 + 9, that is XC + IX = XCIX. IC skips a step, so it is a non-canonical string whose loose value happens to be 99.
Why is there no zero?
The Roman system has no symbol for zero and no positional empty place. “None” can only be written in words, not in these symbols.
Why do clocks often show IIII for 4?
That is a traditional clock-face design convention (often explained as visual balance with the VIII opposite it). Convention aside, the canonical form is IV, and this tool reports only the canonical form.
Can it convert 4000 or more?
No. Historically, values from 4000 on put a bar over a symbol to multiply it by 1000; that is a separate notation and out of scope here. Entering 4000 shows the ceiling explanation instead.
