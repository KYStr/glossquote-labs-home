Supported subset and deviations (complete list)

Supported: ATX headings (1–6), paragraphs, fenced code blocks, blockquotes, unordered/ordered/task lists, thematic breaks, pipe tables with column alignment, code spans, emphasis, strong, strikethrough, inline links and images, full reference links, angle autolinks, backslash escapes, and hard breaks from two trailing spaces or a trailing backslash.

Deviations from full CommonMark (complete list): setext headings are unsupported; raw HTML is escaped, never executed; collapsed [text][] and shortcut [text] reference links are unsupported; bare URLs are not autolinked; HTML entities pass through only for the named set &amp; &lt; &gt; &quot; &#39; &nbsp; and numeric character references — other &name; sequences render literally.

Note: image URLs in a draft are requested by your browser when previewed (the preview sets no-referrer on images). Remove sensitive image URLs before previewing a draft.
