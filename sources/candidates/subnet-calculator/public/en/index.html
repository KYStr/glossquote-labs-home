How the rules work

  • A /31 is an RFC 3021 point-to-point link: both addresses are usable; the "total minus two" rule does not apply.
  • A /32 is a host route: network, broadcast and the usable address are the address itself.
  • Leading zeros in an octet (e.g. 192.168.01.1) are an error, not a guess: historically they meant octal, so this tool refuses them outright.
  • A netmask must be contiguous (some 1 bits, then only 0 bits). A mask like 255.255.0.255 is an error, not a mode.
  • Classification and historical class are different things: classification follows special-purpose ranges (private, loopback, documentation…), while the historical class only looks at the first octet and no longer describes routing.
  • Split lists show at most the first 256 children, but the total count is always shown as an exact integer.
