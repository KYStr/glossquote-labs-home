HTML 實體編碼器與解碼器

依 WHATWG HTML 標準的字元參照規則在本機轉換文字：編碼可選只處理五個必要字元或連非 ASCII 一併轉換，解碼附逐筆變更清單與無法解析清單。解碼只是讓你看懂文字內容，不會讓標記變得可以安全插入；把文字編碼後顯示，不等於淨化（sanitisation）。本工具不支援省略分號的舊式寫法（例如沒有分號的 &），這類輸入會保持原樣。

運作方式與限制
  • 命名表是完整的 WHATWG 命名字元參照集（2,231 條，含 2,125 個分號形式），以資料檔 vendored 進本頁面，來源與雜湊記錄在 repo 的 PROVENANCE.md；解碼只查分號形式。
  • 數字參照照標準規則：數值 0、代理對範圍、超過 U+10FFFF 都換成替代字元 U+FFFD；0x80–0x9F 經 C1 表對照。缺少分號的數字參照仍會轉換，但會在變更清單標明。
  • 變更清單的位置以字碼點計算（不是 UTF-16 單位），星平面字元不會推移後面的位置。清單最多顯示前 500 筆並註明總數，轉換本身不受顯示上限影響。
  • 輸入上限 100,000 字元，超過直接拒絕並顯示字數，不會偷偷截斷。
  • 輸入與輸出只以文字呈現，從不被當成標記解析；什麼都不儲存、不連網。
