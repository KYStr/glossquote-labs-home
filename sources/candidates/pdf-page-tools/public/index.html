PDF 頁面工具

合併、分割、擷取與旋轉 PDF 頁面，全部在你的瀏覽器裡完成：檔案不離開你的裝置，不上傳任何伺服器、不儲存，關閉分頁就消失。產生之前會先顯示完整的輸出計畫（頁面順序、群組、旋轉角度），產生後可以在任何 PDF 閱讀器核對頁數與順序。

重要：本工具不是遮蔽（redaction）工具——移動或擷取頁面不會移除內容，輸出的頁面可能仍含有來源檔案的隱藏圖層與中繼資料。請勿把處理過的檔案當成已消毒的檔案分享。另外，來源 PDF 的大綱／書籤與內部連結不保證在複製頁面後保留，這是已知限制，不是故障。受密碼保護的檔案會被拒絕（不要求密碼、不嘗試解密）。

        限制與說明

        • 單一檔案 ≤ 200 MB；合併最多 20 個檔案、總大小 ≤ 200 MB、總頁數 ≤ 2,000 頁；其他模式 ≤ 2,000 頁。超限會以具名錯誤指出，不會靜默截斷。
        • 輸出頁面是複製原頁（文字仍是文字，不會被轉成圖片）；輸出的 Producer 固定為 GlossQuote Labs PDF Page Tools，來源文件的標題／作者等中繼資料不會被複製過去。
        • 同一組輸入重複產生，頁面順序與旋轉會相同（結構確定）；PDF 檔案位元組本身可能不同，因為寫入器會嵌入文件 ID 與時間。
        • 本工具可離線從靜態主機執行；直接以 file:// 開啟時，瀏覽器的 File API 限制可能影響選檔，這是瀏覽器的限制。
