PDF Page Tools

Merge, split, extract and rotate PDF pages entirely in your browser: files never leave your device, nothing is uploaded to a server or stored, and closing the tab discards everything. Before generating you see the exact output plan (page order, groups, rotations); afterwards you can verify page counts and order in any PDF reader.

Important: this is not a redaction tool — moving or extracting pages does not remove content, and output pages may still contain the source file's hidden layers and metadata. Never treat processed output as sanitised. Outlines/bookmarks and links internal to a source PDF are not guaranteed to survive page copying; that is a stated limitation, not a bug. Password-protected files are rejected (no password prompt, no decryption attempt).

        Limits and notes

        • Per file ≤ 200 MB; merge ≤ 20 files, ≤ 200 MB total, ≤ 2,000 pages total; other modes ≤ 2,000 pages. Violations are named errors, never silent truncation.
        • Output pages are copies of the originals (text stays text; nothing is rasterised). The output Producer is the fixed value GlossQuote Labs PDF Page Tools, and source document metadata (title/author) is not copied over.
        • Repeating the same operation on the same inputs gives the same page sequence and rotations (structural determinism); the PDF bytes themselves may differ because writers embed document IDs and timestamps.
        • The tool runs offline from any static host; when opened via file://, browser File API restrictions may apply — that is a browser limitation.
