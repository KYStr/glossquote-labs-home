UUID 產生器與檢查器

依 RFC 9562 在本機產生版本 4 與版本 7 的 UUID，或把任何 UUID 貼進檢查器，看它的格式、版本、變體，以及（v1 / v7）它編碼的時間。所有亂數都來自這台裝置的加密亂數來源；不連網、不儲存，重新整理就全部消失。

產生器

    UUID 是識別碼，不是密碼或權杖，不應用來保護任何東西。點任一筆結果，會把它載入下方檢查器驗證。

    檢查器

    運作方式與限制
    • 只產生 v4 與 v7：v1 會內嵌裝置識別資訊與可猜測的時間；v3 / v5 是名稱雜湊，屬於雜湊工具的範圍；v6 是舊系統的重排 v1；v8 由各家自訂。檢查器仍可辨識全部版本。
    • 同一毫秒內產生的 v7 會共享相同的時間前綴，只差在隨機位元；本工具不保證同一批內的排序。
    • 檢查採嚴格規則：只接受 36 字元含連字號形式或 32 字元純十六進位形式；{ } 大括號與 urn:uuid: 前綴不支援，會被拒絕。
    • 檢查結果只說「格式正確」：一個格式正確的 UUID 可能是任何人偽造的，本工具不驗證真實性或身分。
    • v6 的時間欄位有重排，本工具辨識版本但不解碼它的時間。
    • 產生的批次與檢查的值只存在於記憶體，不進網址、不寫入任何儲存。
