Password Generator and Strength Checker

Passwords and passphrases are generated locally with the browser's cryptographic randomness (crypto.getRandomValues) — never uploaded, never stored, gone when the tab closes. Strength figures are estimates from the model published on this page, not a guarantee; keep generated passwords in a reputable password manager, because this tool stores nothing. Note that a screenshot or a shoulder-surfer can still see a password while it is on screen.
