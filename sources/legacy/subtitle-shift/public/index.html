格式與使用限制

SRT 支援為本工具明列的子集合，並非所有方言。國會圖書館的 SubRip 格式介紹。

檢查可接受的 SRT 格式
  • 每列依序為索引、時間行及一至十行字幕文字；區塊間需有空白分隔行。只有 ASCII 空格或 tab 的行也算分隔。
  • 索引為一至六個 ASCII 數字，數值 1 至 999999，需嚴格遞增。允許前置零與跳號，輸出不重編號。
  • 時間格式為 00:00:01,000 --> 00:00:02,500；箭頭兩側至少一個 ASCII 空格或 tab。小時兩位 00 至 99，分、秒為 00 至 59，毫秒三位；不可加整行周圍空格或設定。起點需早於終點。
  • 每行文字最多 1,000 個 Unicode 字元。保留文字兩端空格與看似 HTML 的字面文字。文字中的「數字索引行後接時間行」組合不支援，請檢查是否漏分隔行。
  • 原始輸入最多 1,048,576 個 UTF-16 單位及 1,048,576 UTF-8 bytes，含 BOM 與原始換行。拒絕 NUL 或不完整 Unicode 字元。只移除一個開頭 BOM，CRLF／CR 正規化為 LF。
  • 保留索引與輸入順序，允許重疊與非時間排序。輸出箭頭兩側各一個空格、區塊間一個空白行，結尾恰一個 LF。
如何平移 SRT 字幕時間？

貼上符合本工具格式的 SRT，選提前或延後並輸入秒數，然後檢查完整結果。

可以平移多少？

秒數可為 0 到 3,600 秒，最多三位小數；移動後所有時間仍須位於 00:00:00,000 到 99:59:59,999。

為什麼整份字幕被拒絕？

本工具只接受明列的 SRT 子集合；若格式不符或任一 cue 超出時間範圍，整份不輸出部分結果。

會讀取影片或上傳字幕嗎？

不會。貼上的文字在本頁記憶體處理，沒有影片、音訊或雲端處理。首次開啟仍需下載網站檔案；本版不保存資料，不保證完整離線。

能修正逐漸累積的不同步嗎？

不能。本工具只做每個 cue 完全相同的時間平移，不轉錄、不轉 VTT、不推測秒數，也不保證與特定影片同步。
