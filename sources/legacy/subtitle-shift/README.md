# 字幕時間平移

M0 產品與實作規格

字幕時間平移協助使用者修正整份 SubRip（SRT）字幕中一致偏早或偏晚的時間。使用者貼上 SRT 文字，選擇提前或延後並輸入秒數，檢查完整結果，再下載 UTF-8 SRT。工具只處理文字與時間碼。

這是明確界定的 SRT 子集合，不宣稱完整符合所有 SRT 慣例。SubRip 沒有完整的正式規範；本資料夾的解析規則才是產品契約。子集合以外的檔案整份拒絕，不猜測修補。美國國會圖書館說明 SubRip 是文字字幕格式：https://www.loc.gov/preservation/digital/formats/fdd/fdd000569.shtml

## 使用者結果

貼上 SRT、選提前或延後、輸入 0 到 3,600 秒，再提交。成功後顯示完整正規化 SRT，以及字幕列數和原輸入順序中第一列、最後一列的原始與平移時間。使用者可以檢查唯讀全文或下載完整檔案。工具不截短、刪除、重排或默默重編任何字幕列。若任一列平移後早於 00:00:00,000，或晚於 99:59:59,999，整次操作失敗並指出字幕列序號。

## 產品範圍

- M1 只接受貼上的文字；不提供本機檔案選擇器，也不呼叫剪貼簿 API。使用者可在本站以外用文字編輯器開啟檔案，再貼入內容。
- 工具不讀取影片或音訊、不轉錄、不使用 AI、不改播放速度、不校正累積漂移、不轉換 VTT，也不推測平移量。
- 沒有日期、時區、遠端服務、帳號、遙測、儲存、網址草稿或外部資產。
- 輸入與輸出只存在記憶體。編輯草稿會立即使可見結果失效；離開頁面會清除文字與結果。
- 繁體中文與英文使用各自頁面：繁中為 /index.html，英文為 /en/index.html。切換語言會先提醒目前草稿會遺失。

## Runtime 與發布階段

應用程式是靜態雙語 HTML/CSS/ESM 網站。開發與測試可使用 Node.js 24 和內建模組；禁止新增 runtime dependency。M1 本機預覽只綁定 127.0.0.1:4216。主代理明確放行 M2 後，才可在 127.0.0.1:5216 產生獨立的正式候選版 dist-production/。預覽輸出 dist/ 維持 noindex。預定網址為 https://subtitles.glossquote.com，目前不代表已上線。

主代理負責 M3 部署、共用首頁與發布整合。通過 M2 gate 後，公開原始碼目標為 KYStr/glossquote-labs-subtitle-shift。M1 證據不得在目前焦點事件期間冒稱瀏覽器驗收完成；受影響的 UI 檢查必須記為 NOT_RUN_USER_FOCUS_INCIDENT。
