檔案 SHA-256 校驗

選擇檔案後計算校驗碼，也可貼上來源提供的 64 位 SHA-256。比對能幫助確認內容一致，不能判斷檔案是否安全或證明發布者身份。

需要啟用 JavaScript 才能在本機計算。檔案不會上傳。

核對檔案內容

任意單一檔案，最多 128 MiB（134,217,728 bytes），包含空檔。按下計算後才讀取內容。

查看完整檔名

只貼上 64 位十六進位校驗碼；可用大小寫，不含前綴、檔名或內部空白。

選擇檔案，最多 128 MiB。

檔案留在這個瀏覽器

檔案內容由這個瀏覽器計算，沒有上傳、帳號或保存紀錄。網站的頁面與程式仍需從網站載入；完成初始載入後，運算不需要再下載相依程式。

清除或離開頁面會放棄工具持有的檔案與結果引用；不代表抹除作業系統記憶體，也不會刪除已複製或下載的內容。只有按下複製或下載才會輸出校驗碼。

常見問題

檔案會上傳嗎？

不會。檔案的原始 bytes 在本機瀏覽器處理。開啟網站仍會載入頁面資產，伺服器也會收到一般網站連線資訊。

為什麼上限是 128 MiB？

Web Crypto 需要把完整檔案讀入記憶體。這個工具的上限是 128 MiB，包含該邊界；不提供串流大檔。記憶體不足時可能計算失敗，請選擇較小檔案。

改名會改變校驗碼嗎？

不會，檔名、MIME 與修改日期都不參與計算。只有原始內容 bytes 參與；換行或一個 byte 變動都會影響校驗碼。

校驗碼相符就代表安全嗎？

不代表。請使用來自可信來源的校驗碼。這個工具只協助核對內容一致，沒有病毒掃描、簽章檢查或發布者身份驗證。
