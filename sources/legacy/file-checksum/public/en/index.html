Files stay in this browser

File contents are processed in this browser, without uploads, accounts, or saved history. The website still loads its pages and code; after the initial load, calculations do not need further dependency downloads.

Clearing or leaving the page drops the tool's file and result references. It does not erase operating-system memory or remove copied or downloaded content. Checksums are exported only when you choose Copy or Download.

Questions about checksums

Is my file uploaded?

No. The raw file bytes are processed in this browser. Opening the website still loads page assets, and the server receives normal website connection information.

Why is the limit 128 MiB?

Web Crypto needs the entire file in memory. This tool accepts up to and including 128 MiB and does not provide streaming for larger files. Low memory can cause a calculation to fail; choose a smaller file.

Does renaming a file change its checksum?

No. The name, MIME type, and modification date do not affect the calculation. Only the raw bytes count; a changed line ending or a single changed byte affects the checksum.

Does a matching checksum mean the file is safe?

No. Obtain the expected checksum from a source you trust. This tool checks content consistency; it does not scan for malware, check signatures, or verify the publisher's identity.
