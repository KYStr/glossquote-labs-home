# 公開來源範圍 — 0.1.0

此 repository 僅包含食材差額採買單自身的程式、測試、設定與可獨立閱讀的規格／交接。公開副本沒有其他工具、workspace 執行紀錄、帳戶資料、憑證、node_modules 或生成的網站產物。

M2B 僅授權公開來源；hosting、首頁與外部驗收由後續里程碑處理。已驗 runtime、CSP、資料處理行為與 M2A 固定來源相同。來源與版本的實際 commit 由 GitHub commit history 記錄，不在同一 commit 的文件中嵌入自己的 commit hash。

重現步驟見 [README](README.md)，狀態與保留限制見 [HANDOFF](HANDOFF.md)。原 [TASKS](TASKS.md) 為設計期 milestone 契約，歷史未執行項不因來源公開而通過。
