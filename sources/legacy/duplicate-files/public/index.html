    常見問題
    
      
    工具會刪除重複檔嗎？
    不會，只產生報告；你可自行決定是否處理來源檔。
    
      
    檔名相同就算重複嗎？
    不會。工具先按大小與 SHA-256 找候選，再逐 byte 比對內容。
    
      
    不同檔名但內容相同會找到嗎？
    會；名稱不參與判斷，報告用選取順序索引區分。
    
      
    空檔案會被忽略嗎？
    不會，空檔案可分組；重複空檔不會產生 bytes 節省。
    
      
    檔案會上傳嗎？
    不會，候選版在目前分頁本機分析。沒有帳號或背景上傳。下載的報告不會由本工具自動清除。
