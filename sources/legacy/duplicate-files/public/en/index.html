    Common questions
    
      
    Does the tool delete duplicates?
    No. It creates a report; you decide what to do with the source files.
    
      
    Do matching names count as duplicates?
    No. Candidates are grouped by size and SHA-256, then compared byte for byte.
    
      
    Can it find identical files with different names?
    Yes. Names do not determine matches; the report uses selection indexes to distinguish them.
    
      
    Are empty files ignored?
    No. Empty files can form a duplicate group, though removing one saves zero bytes.
    
      
    Are files uploaded?
    No. The candidate analyzes files locally in the current tab. There are no accounts or background uploads. Downloaded reports are not cleared automatically.
