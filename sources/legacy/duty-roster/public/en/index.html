    Using this tool

    Choose a date range to rotate duty days through your member list. Data stays in this page. The site files must load once; this version does not save roster data.

    One person is assigned per duty date. This tool does not plan multiple shifts, optimize workload fairness, or make labor-law decisions.

    How are members selected?

    Starting at the first member in the current list, the tool processes duty dates in order and scans forward for the first person available on that weekday. After an assignment it continues after that member. If nobody is available, the date stays unassigned and the rotation position does not move.

    What does an empty availability selection mean?

    That member is unavailable on every weekday. The page keeps this state visible; select available weekdays and generate the roster again.

    Does this make the workload fair?

    No. The tool rotates by list order and weekday availability. It does not optimize workload, hours, holidays, or other fairness conditions, and it does not make labor-law decisions.

    Are rosters saved or synced?

    No. Inputs and results stay in the current page’s memory. They do not return after reload, clearing, switching language, or leaving the page. You may explicitly copy or download a report.
