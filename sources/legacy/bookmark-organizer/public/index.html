整理書籤匯出檔

本機候選版；尚未部署

先檢閱重複連結與資料夾，再決定輸出內容。來源檔不會改動。

切換語言會離開此頁；未下載的書籤整理結果會遺失。

選擇書籤 HTML

UTF-8 · 最多 2 MiB · 3000 筆連結 · 12 層資料夾

只在目前分頁記憶體處理，不上傳、不開啟連結、不載入圖示。重新開始或離頁會清除頁面內的資料與下載暫存，不會刪除已下載檔案。

支援的匯出格式

接受列明的 Netscape 書籤 HTML：DL / DT / H3 / A 結構、常見外殼與 metadata。只允許不含帳密的絕對 HTTP/HTTPS 網址。不支援的標記會拒絕整份檔案，不會靜默略過項目。

不宣稱完整支援所有瀏覽器匯出變體。空資料夾可檢閱；HTML 依納入的書籤建立非空路徑。

檢閱書籤

所有書籤預設納入。建議保留只作提示；「只保留所選項」或取消納入時會先確認。搜尋與資料夾篩選只影響顯示，輸出仍以納入勾選為準。

資料夾樹

括號為直接位於此資料夾的筆數；選取資料夾也顯示子路徑。

填寫完整路徑，最多 12 層、每層 1–255 UTF-8 bytes。留空使用上方選項；選根目錄可移出資料夾。「/」可作名稱文字。

更名資料夾與所有子路徑

更新此資料夾下所有書籤與子路徑；相同路徑會合併。原路徑仍保留在 JSON。最多 12 層、每層 1–255 UTF-8 bytes；不能為空、.、.. 或含控制字元。

下載整理結果

產物只在你點擊下載後建立。結果沒有自動到期時間；修改後請重新下載。工具不會替你匯入瀏覽器。

使用前的幾個問題

工具會開啟書籤網站嗎？

不會。URL 只作文字檢查和完全相同字串分組，沒有網路請求。

網址只有 query 不同會合併嗎？

不會。query 不同是不同字串，也會保留為不同群組。

工具會自動刪除重複書籤嗎？

不會。預設全部納入，需由你明確排除後才會從 HTML 輸出移除；JSON 備份仍保留所有項目。

ICON 或 favicon 會載入嗎？

不會。匯出中的 ICON metadata 會忽略，不解碼、不顯示、不請求。

所有瀏覽器書籤檔都支援嗎？

本候選只接受列明的 Netscape profile。未支援的標記會拒絕整份，避免悄悄漏掉項目。
