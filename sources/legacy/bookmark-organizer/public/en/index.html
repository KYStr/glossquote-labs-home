Choose bookmark HTML

UTF-8 · Up to 2 MiB · 3000 links · 12 folder levels

Processed in this tab's memory. No upload, link opening, or icon loading. Starting over or leaving clears page data and temporary download URLs; downloaded files remain.

Supported export format

Accepts the documented Netscape bookmark HTML profile: DL / DT / H3 / A structure, common wrapper tokens and metadata. Only absolute HTTP/HTTPS URLs without credentials are accepted. Unsupported markup rejects the whole file without silently dropping entries.

This does not promise support for every browser export variant. Empty folders can be reviewed; HTML builds nonempty paths from included bookmarks.

Review bookmarks

All bookmarks start included. A suggested keeper is a hint; keeping only one entry or excluding entries requires confirmation. Search and folder filters change the view. Inclusion checkboxes determine the output.

Folder tree

Counts show direct entries. Selecting a folder also shows its descendants.

Enter the full path, up to 12 levels and 1–255 UTF-8 bytes per name. Leave blank to use the selection above. Choose Root to move out of folders. A slash can be part of a name.

Rename a folder and all descendant paths

Updates all bookmarks and descendant paths under this folder. Matching paths merge. JSON retains original paths. Up to 12 levels and 1–255 UTF-8 bytes per name; no empty names, . or .., or control characters.

Download organized bookmarks

Files are generated only when you click download. Results do not expire automatically. Download again after edits. This tool does not import into your browser.

Before you start

Will the tool open bookmark websites?

No. URLs are plain text for exact matching; no network request is made.

Are URLs merged when only the query differs?

No. Different query strings remain separate exact URL groups.

Does it automatically remove duplicate bookmarks?

No. All entries start included. You must explicitly exclude entries for HTML output; JSON keeps every entry.

Are icons or favicons loaded?

No. ICON metadata is ignored, never decoded, displayed, or requested.

Does it support every browser export?

This candidate accepts only the documented Netscape profile. Unsupported markup rejects the whole file rather than silently dropping items.
