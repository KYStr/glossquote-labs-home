# Contributor safety

Use Node 24+ ESM and built-in modules. Do not add dependencies or collect user data. Preserve exact schema validation, integer calculation, memory-only inputs, bilingual behavior, deterministic tests and documented NOT_RUN boundaries. Do not read credentials, change global/system configuration, enable telemetry, deploy, spend money or publish new releases without explicit authority. Test servers bind only to their documented loopback ports; preserve unrelated processes and changes. Read the product, technical, acceptance and release documents before scoped edits.
