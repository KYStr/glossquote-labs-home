先設定這次的期間

以觀測期間總用量估固定平均耗用；訂單假設在到貨天數結束時可用。到貨後涵蓋期另從到貨時起算。

1–365 天；對應每列的觀測總用量。
0–365 天；從現在到訂單可用。
1–365 天；不含到貨前天數。
計算方式與限制

目標量＝觀測總用量 ×（到貨天數＋到貨後涵蓋天數）÷ 觀測天數＋安全備量。扣掉現貨後，以每包單位數向上取整；包數最低為 0。計算保留精確整數比例，日均顯示四捨五入至三位小數。

到貨前短缺不計入本次新訂單。現貨可用整天數只看現貨與固定平均耗用，不扣安全備量；用量為 0 時無法估算可用天數。本版不處理在途訂單、多倉、單位換算或變動需求；這是估算，不是需求預測。

常見問題

這個工具怎麼算出建議補幾包？

先用觀測期間總用量估固定平均耗用，再計入到貨前天數、到貨後希望涵蓋的天數與安全備量，扣掉現貨，最後依每包單位數向上取整。它是依輸入假設的估算，不是需求預測。

如果觀測用量是 0，還會計算嗎？

會。用量為 0 時不估算現貨可用整天數；安全備量仍會納入目標，所以仍可能需要補貨。

在途訂單會扣進現貨嗎？

不會。此版只看目前現貨，不處理在途訂單或多倉庫；耗用改變時，固定平均估算也可能不符合實際情況。
