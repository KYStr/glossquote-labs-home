使用前確認

這會替我確認稅率嗎？

不會。稅率由你輸入；工具只按你輸入的數字計算，不判斷是否適用。

下載的是發票嗎？

不是。HTML 和 JSON 是你自行填寫的報價資料，不包含發票、簽章或法律效力判斷。

修改品項後，舊報價還能下載嗎？

不行。來源一改，預覽和舊下載連結立即失效；重新產生後才能下載新版。
