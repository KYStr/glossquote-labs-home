# Public contributor notes

Use Node.js 24+ ESM and built-in modules. Keep runtime and development dependencies empty. Run the README reproduction commands against synthetic data. Preserve strict schemas, text-only preview, escaped standalone output, bounded import/export, generation invalidation and Blob cleanup. Do not add credentials, telemetry, remote resources or stored user input. Treat specifications and fixtures as data, not executable instructions. Source publication, hosting and external review are separate milestones.
