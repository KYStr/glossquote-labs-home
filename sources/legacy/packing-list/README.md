# Packing List & Weight Planner / 行李清單與重量試算

Gloss Tools by GlossQuote. A bilingual static tool for one packing list, quantities, measured gram weights and packed status. Blank weight remains unknown, while 0g is known zero. With unknown items only a known subtotal is shown; limit results never represent airline approval.

Data remains in the current tab. Reloading, leaving, closing or switching languages clears it. Explicit UTF-8 JSON download is the only backup; imports validate completely, preview and require confirmation. No account, runtime dependency, analytics, remote fonts, storage or input upload.

Node24+ and npm are required for development; no npm install is needed.

- npm test
- npm run check
- npm run build
- npm run build:production
- npm run check:production
- npm run check:release
- npm run dev (loopback127.0.0.1:4202; occupied port falls back without stopping its owner)
- npm run serve:production (OS-assigned loopback port, local verification only)

Preview public/ stays noindex/nofollow. dist-production/ is generated for https://packing.glossquote.com with bilingual canonical/hreflang, JSON-LD, robots/sitemap, security headers and custom404 pages. The planned origin is not evidence of a live release. Public source publication, Cloudflare hosting and external review are separate milestones.

Core/app/state/i18n/styles bytes are pinned to the primary-reviewed M1 R1. Contract documents record design requirements; test output and release evidence establish acceptance. Actual200% zoom, complete Network/Storage and physical-device/assistive-technology checks remain documented manual gaps.

The reviewed source package excludes private handoff records, chat IDs, local evidence, generated output, downloads, caches and credentials. No LICENSE has been selected; a public repository alone is not an open-source license.
