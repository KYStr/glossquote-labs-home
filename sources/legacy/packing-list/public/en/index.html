About blank weights and backups

Does a blank weight count as zero?

No. Blank means unknown; 0 g is a known zero. With unknown weights, only a known subtotal is shown. If it already exceeds your limit, only a minimum excess is known.

Does this apply airline baggage rules?

No. You set the optional limit. The result is not boarding advice.

Will a refresh keep my list?

No. Download a JSON backup first. There is no automatic storage, and the tool does not upload your list. Switching languages leaves this page and clears the list.
