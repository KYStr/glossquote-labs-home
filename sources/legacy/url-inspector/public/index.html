網址參數檢視與整理

看清每個參數，保留想留下的部分。

貼入含 http:// 或 https:// 的網址。最多 65,536 個 UTF-16 碼元、256 列參數；勿貼入憑證。

僅在此瀏覽器處理；不會開啟輸入網址。

    使用方式
    貼入完整網址後，檢視重複的參數、原始編碼與解析值。只修改要改的列，或勾選移除；其餘片段與順序會保留。產生後再自行複製或下載。
    1. 貼入網址，按「檢視網址」。
    2. 編輯名稱或值、勾選移除，或新增參數。
    3. 按「產生新網址」，檢查結果後複製或下載。
    只接受 HTTP/HTTPS，不接受登入資訊或相對網址。無法解碼的列仍可保留或移除。修改後的列使用表單 query 編碼，空白為 +。
    會打開或縮短網址嗎？
    不會，只有字串處理。工具不造訪、預取或展開輸入連結。
    為什麼 + 會顯示成空白？
    query 的表單解碼規則將 + 視為空白；%2B 才表示加號。只解碼一次。
    刪除追蹤參數就安全了嗎？
    不保證。這裡沒有安全掃描，修改也可能使簽名或驗證連結失效。
    會改變重複參數或其他編碼嗎？
    保留原順序與未改片段；只重新編碼編輯或新增的列。把編輯恢復原值會恢复原始片段。
    資料與隱私
    工作內容只存在此頁記憶體，不寫入網站儲存空間或網址。只有按下複製或下載才輸出。切換語言或離頁會清除工具內容；清除不會抹掉已複製或下載的檔案。載入網站仍會連線取得靜態資產。
