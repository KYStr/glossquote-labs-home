    How to use this tool
    Paste a complete URL to inspect repeated parameters, original encoding, and browser-parsed values. Edit selected names or values, mark rows for removal, or add a parameter. Unchanged segments keep their spelling and order. Generate the new URL, check it, then copy or download it yourself.
    1. Paste a URL and choose Inspect URL.
    2. Edit a name or value, mark rows for removal, or add a parameter.
    3. Choose Generate URL, then check and copy or download the result.
    Only HTTP and HTTPS URLs are accepted, without login information or relative paths. Undecodable rows can be kept or removed. Edited rows use form query encoding, with + for spaces.
    Does it open or shorten links?
    No. It only processes text. It never visits, prefetches, or expands an input link.
    Why does + appear as a space?
    Form query decoding treats + as a space. %2B represents a plus sign. Decoding happens once.
    Does removing tracking parameters make a link safe?
    No. There is no safety scan, and edits may break signed or verification links.
    Are duplicate parameters or other encodings changed?
    Order and untouched segments are preserved. Only edited or new rows are re-encoded. Reverting an edit restores the original segment.
    Data and privacy
    Your work stays in this page’s memory and is not written to site storage or the page URL. Only Copy or Download exports it. Switching language or leaving the page clears tool content. Clearing does not erase copied text or downloaded files. Loading the site still connects to retrieve static assets.
