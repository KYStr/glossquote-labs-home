文字分段與字數限制

指定每段最多 code points，檢視完整分段；切出的片段串接後與輸入相同。

最多 100,000 UTF-16 code units；原文與片段只在本頁記憶體處理，不上傳。

可設定 1–10,000，最多產生 1,000 段。

這不是 emoji 圖形數，也不代表任何平台的字數限制。

優先換行只在目前上限內找最後一個 LF，並把換行留在前段；沒有 LF 就依上限切。

一個畫面上的 emoji 可能由多個 code points 組成；分段可能切開它或其他組合字元。

重新載入會清除文字和分段結果。

可複製的片段

貼上文字並選擇上限，再按分段。

    關於計數與原文

    它會依照某個社群平台的限制嗎？

    不會。上限由你設定，數的是 Unicode code points，不是任何平台的字數。

    emoji 算幾個字？

    本工具不按畫面上的 emoji 圖形計數。一個字形可能由多個 code points 組成，分段可能切開它。

    切段會保留換行嗎？

    會保留文字欄目前的來源，不加段號、分隔符或移除空白。瀏覽器可能在貼上時先把 CRLF 或 CR 換行正規化成 LF；本工具不還原貼入前的檔案位元組。優先換行只尋找 LF 切點。

    文字只保留在目前分頁。複製只在你選擇該段時執行。
