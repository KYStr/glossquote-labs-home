    Counting and preserving text

    Does this follow a social platform's character limit?

    No. You choose the limit, and this tool counts Unicode code points rather than any platform's character rules.

    Are emoji one character?

    A visible emoji can contain several code points and may be split. This tool does not count grapheme clusters or visible emoji shapes.

    Will line breaks stay the same?

    Chunks preserve the source currently in the text field. No numbering or separators are added, and whitespace is kept. A browser may normalize pasted CRLF or CR line endings to LF before the tool reads them. The tool does not recover pre-paste file bytes. Prefer line breaks looks for LF only.
